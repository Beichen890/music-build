## 编程化音乐制作（Agent 友好）

当需要批量生成、算法化编排或与非 DAW 工具链协作时：

| 工具 | 用途 |
|---|---|
| **mido**（Python） | MIDI 文件读写，PPQN 可精确对齐 DAW |
| **FluidSynth + SoundFont** | MIDI → 音频离线渲染，命令行可用 |
| **librosa**（Python） | 音频特征分析（BPM/调性/频谱） |
| **soundfile**（libsndfile） | 1.1.0+ 原生支持 MP3 读写，**无需 ffmpeg** |

> 安装提示：若 `pip install librosa` 报 "No matching distribution"，
> 换源重试（阿里云可用，部分镜像缺失 wheel）。
