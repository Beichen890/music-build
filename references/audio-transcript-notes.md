## 1. 声部分组与工程轨道顺序（DAW 落点）

【源】`BV13341147KF` 四川音乐学院《交响乐队乐器法与配器》第 1 讲，本地转写 `BV13341147KF.md`。
【验】与 `frame-notes.md` 抽帧画面、技能 `classic-arrangement.md` 的乐器音域总表一致。

> **本节只保留能直接落到工程轨道上的部分**。真实乐团人数、谱台数、各时期铜管配置人数
> 属排练组织信息，DAW 制作里没有执行价值，已略去。

### 1.1 四组 = 四个轨道文件夹，五声部 = 五条 MIDI 轨【事实 + 经验】

| 轨道分组（文件夹） | 内容 | 在 DAW 里的用法 |
|---|---|---|
| 弦乐组 | 第一小提琴 / 第二小提琴 / 中提琴 / 大提琴 / 低音提琴（**5 条 MIDI 轨**） | 全队基础：音色统一、音域宽、可长音不换气、奏法丰富；用同一套混响 send 保证同处一室 |
| 木管组 | 长笛家族（短笛 + 各类长笛）、双簧管家族（双簧管 / 英国管）、单簧管家族（小 / ♭B / A / 低音单簧管）、大管家族（大管 / 低音大管） | 个性鲜明，是音色宝库；每族单独一条轨，别混进一条 MIDI 轨 |
| 铜管组 | 圆号 / 小号 / 长号 / 大号 | 除打击乐外音量最大；注意与弦乐的 200–500 Hz 让位 |
| 打击乐组 | 有固定音高 / 无固定音高两类；最常用 20 余种；最重要是定音鼓 | 有固定音高的单独一轨，便于调音；钢琴、竖琴**不进这四组** |
| **色彩组** | 钢琴 / 竖琴 / **合成器 pad / bell / soft lead** | 与竖琴同列、单独计算；合成器垫在弦乐下方补 200–500 Hz，音量比弦乐低 6–10 dB |

> 特殊乐器（扬琴、吉他、曼陀林等）视作品另建轨。

### 1.2 总谱顺序 = 工程轨道排列顺序【事实】

`木管组 → 铜管组 → 打击乐组 → 钢琴 / 竖琴（+合成器 pad） → 弦乐组`

- 照这个顺序排轨道，能与管弦模板对齐，方便批量画 CC、按组调音量、分组导出 stems。
- 乐器名称常有意大利文 / 法文 / 德文 / 英文版本 → 查对照表，别靠猜。

### 1.3 落地到三件套 + 合成器

- **钢琴**归「色彩组」，承担和声骨架而不占弦乐声部；与竖琴 / pad 共用同一空间。
- **小提琴**在弦乐组里是「最自由、最显眼、加花最多」的声部 → 宏大叙事与悲伤的主旋律首选（见 `core-instruments.md`）。
- **手风琴**不在标准交响编制内 → 按「色彩 / 簧片」声部另建轨，别硬塞进木管组。
- **合成器**是合法音色来源：pad / bell / soft lead 归色彩组，只作色彩与空间层、不作舞曲骨架；
  吵闹电子舞曲用法见 `references/electronic-styles.md`。

## 2. 弦乐基础写法：三步 SOP

【源】`BV1jx411R7fG`《弦乐的基础写法》，本地转写 `BV1jx411R7fG.txt`（20.9 min，585 段）。
【验】与 `BV13341147KF` 的五声部编制、以及抽帧笔记里的音区划分一致。

### 2.1 概念澄清【事实】

- 编曲口语里的「弦乐」**通常专指提琴组**。
- 严格按发声方式分：擦弦（提琴、二胡）、拨弦（吉他、竖琴、古筝）、击弦（**钢琴也算**，靠木槌敲钢丝）。
- 写流行弦乐最常用奏法是**连弓**（legato）。

### 2.2 三步顺序【事实，照这个顺序做】

1. **写音符**：一律先写**和弦音**。例：钢琴走 Em，弦乐就写 E–G–B；钢琴走 Bm，弦乐就写 B–D–F。
2. **避错**：声部不超越、走向不同向（详见 2.4）。
3. **画表情**：先画 `CC11`，再画 `CC1`，最后才考虑 `CC7`（详见 2.5）。

> **连弓怎么触发**：相邻两个音符在钢琴卷帘里**重叠一小段**即可，重叠长短无所谓；不重叠听起来就是每音一次起弓。

### 2.3 五个声部的职责【事实 + 经验】

| 声部 | 主要音区 | 写什么 | 加花 |
|---|---|---|---|
| 大提琴 | 小字 1–2 组 | **和弦根音**，稳固 | 最少，不宜加花；一个和弦换一次根音 |
| 中提琴 | 小字 2–3 组 | 和弦**三音 / 五音**，尽量避开大提已占的根音 | 适度；无小提时可担主旋律 |
| 第一小提琴 | 小字 4 组为主（偶尔 3 / 5 组） | 和弦音为主 + 音阶 / 副旋律 | 最多、最自由，起主旋律作用 |
| 第二小提琴 | 围绕第一小提琴 | 常见为**下三度**，用于加厚、凸显一提 | 不要抢一提 |

> 进了一提之后，中提与大提的加花要**收**，否则整体变乱。
> 音区判据：音源界面蓝色 = 可发声区域，中间一块 = **主要音区**；不要长期贴着边界写。

### 2.4 两条硬约束【事实】

1. **声部不要超越**：大提别写到中提的主要音区，中提别写到小提的主要音区；越界会「打架」。
2. **尽量不要同向**（四部同向）：不要所有弦乐同时上行或同时下行；让大提与中提 / 小提形成反向，听感明显更好。讲者原话「初学者注意这两点就已经合格了」。

### 2.5 MIDI 表情控制器【事实，可直接抄】

| 控制器 | 讲者的定义 | 听觉效果 | 怎么用 |
|---|---|---|---|
| `CC11` | **情绪控制器** | 强弱、轻重、音量一起变 | **第一个画**；按「拉琴时的情绪」画，不要当成音量线；关掉对齐，用画笔反复画反复听 |
| `CC1` | **动态控制器** | 粗糙 ↔ 精细、稳定 ↔ 波动、也带音量变化 | **第二个画**；初学者当作音量**补偿**用：情绪上来但不想音量涨时，把 CC1 往下压；快速换音处把 CC1 凹下去，可衰减切换杂音 |
| `CC7` | **音量控制器** | 相当于麦克风收进来的音量 | 基本用不到；前两条画完仍要整体微调才动 |

> **力度（velocity）在弦乐音源里通常不改变音量**，多数是切换演奏法／起音强度，不要拿它当表情用。
> 顺序口诀：**先 CC11 → 再 CC1 → 最后 CC7**。

### 2.6 对情绪驱动编曲的价值

- `CC11` 是全技能里**最接近「情绪直接映射到参数」**的一条：悲伤含蓄 = 低平缓慢的 CC11；宣泄 / 宏大 = 大起伏、长爬升（见 `emotion-arrangement-recipes.md`）。
- 反向进行 + 声部不超越，是「厚重但不糊」的底层保障，直接服务宏大感 S02 / 悲壮感 S03（见 `scene-texture-recipes.md`）。

### 2.7 DAW 落地检查清单【按顺序做】

| 步 | 在 DAW 里的动作 | 判据 |
|---|---|---|
| 1 | 按 §1.2 建 5 个轨道文件夹、弦乐组建 5 条 MIDI 轨，全部指向同一个混响 send | 分组结构对了，后面批量画 CC / 导出 stems 才省事 |
| 2 | 钢琴卷帘里**先写和弦音**：钢琴走 Em 就写 E–G–B，走 Bm 就写 B–D–F | 大提根音、中提三/五音、一提和弦音 + 副旋律 |
| 3 | 检查**声部不超越**（大提别进中提主要音区，中提别进一提主要音区） | 音源界面蓝色 = 可发声区，中间一块 = 主要音区；别长期贴边界 |
| 4 | 检查**不要四部同向**：让大提与中提 / 小提形成反向 | 全同向会「塌陷」 |
| 5 | **连弓**：相邻两音在钢琴卷帘里重叠一小段（重叠长短无所谓） | 不重叠 = 每音一次起弓，听起来断 |
| 6 | 画 `CC11`：**关掉对齐**，用画笔按情绪反复画反复听 | 悲伤含蓄 = 低平缓慢；宣泄 / 宏大 = 大起伏长爬升 |
| 7 | 画 `CC1` 作音量补偿：情绪上来但不想音量涨时往下压；快速换音处凹一下 | 可衰减切换杂音 |
| 8 | 最后才动 `CC7`（整体微调），**别拿 velocity 当表情** | velocity 在弦乐音源里多数只切换奏法 / 起音强度 |
| 9 | 合成器 pad 若在，归色彩组、比弦乐低 6–10 dB、只补 200–500 Hz | 不抢前景，不作舞曲骨架 |

> 顺序口诀：**写和弦音 → 避错（不超越 / 不同向）→ 连弓重叠 → CC11 → CC1 → CC7**。

## 5. 中国风：五声 + 4566

【源】`BV1RJ411F7nd` 乐才派《中国风的作曲》，本地转写 `BV1RJ411F7nd.txt`。

### 5.1 五声音阶【事实】

- 宫 商 角 徵 羽 = **1 2 3 5 6** = Do Re Mi Sol La。
- 做法：从七声里**去掉 Fa(4) 与 Si(7)**，只用 1 2 3 5 6 写旋律。
- 讲者强调：五声「随意排列组合也容易好听」「乱写都挺好听」，所以这是初学者最省力的中国韵味入口。

### 5.2 一条可直接落地的进行【事实】

`4 5 6 6`，1=C 即 **F – G – Am – Am**（六级重复一次）。

讲者的现场制作顺序（可照抄）：

1. 写出 `4 5 6 6` 四个和弦块；
2. **加踏板**（延音）；
3. **加低音**；
4. **随机化力度**（避免机械感）；
5. 复制循环一次作为基底；
6. 在这个基底上，用 1 2 3 5 6 写主旋律，再微调时值。

> 与 §4 的《晚夜微雨问海棠》4566 属于同一型 → 这是中国风 / 古风与感伤流行的共用接口。
> 更系统的五声与偏音写法见 `chord-library.md`、`classic-arrangement.md` 的中国风章节。
