> **范围分流**：不默认做吵闹的电子舞曲风格（EDM / House / Techno / Trap / Dubstep / 鼓机 drop / riser / 泵感侧链 / supersaw lead），这类内容单独收在 `references/electronic-styles.md`，主线不混。
> **主用途**：情绪驱动 + 场景感双轴 + 钢琴 / 小提琴 / 手风琴三件套；合成器在这里是色彩与空间层（pad / bell / soft lead / 铺底），不是舞曲骨架。
> **用法**：数值是起点不是法则，以耳朵为准；与本技能既有硬规则冲突时，以技能规则为准。
> **情绪驱动**：按情绪查配方 `emotion-arrangement-recipes.md`、按情绪查和弦 `emotion-chord-index.md`、钢琴/小提琴/手风琴写法 `core-instruments.md`。

## 0. 范围、读法与接口实况

**本文件定位（事实）**：聚焦「频道 / 合集导航 + 视频内文字干货」两件事，**不做 973 条排行榜、不做分主题清单**——后者由主代理生成的技能目录 `references/bilibili-study-map.md` 承担，本文件既不重复也不改写该文件（技能目录内任何文件本任务均未写入 / 未修改）。表格里的播放量只是核实快照，不是排名。

**收录边界（事实）**：仅经典／传统编曲——古典、管弦、爵士、流行、摇滚、民谣、中国风、影视配乐等**真实乐器编制**。严格排除电子编曲：EDM / House / Techno / Dubstep / Trance / Future Bass / Trap / Phonk / 电音舞曲 / 鼓机 beat / 合成器音色设计。分P 大纲中若出现「合成器类详解」「流行 Lead 调制」「Type Beat / Drill」等条目，本文一律不摘录（例见 §4）。

### 3.1 逐段配器模板 ——《Avid》全编制翻奏（A：BV1bps6e2Eep）

### 3.2 音区让位与复调 ——《小镇里的花》小提琴钢琴重奏版（A：BV1jw4m1Q7Yk，改编 王佳诺）
- **前奏音色替代判断**：原曲前奏有编钟、吉他、箫。编钟可用**十五度音程模仿泛音**，吉他可直接转成低声部持续；箫柔美萧瑟的吹管音色钢琴难复刻，小提琴加弱音器也改变不大且会失去后文主旋律的新鲜感与主导地位 → 舍弃还原性，用概括性旋律保留钢琴旋律自洽的逻辑。
- **发声原理决定能否替代**：古筝 / 扬琴 / 琵琶更接近钢琴、音色更干脆 → 可直接用钢琴还原；吹管乐器可**持续发声**、包络与钢琴 / 弹拨 / 击弦不同 → 必须用不同演奏法区分：`3:05` 钢琴的 `#c` 用**震音**还原管乐持续发声与声音波动，同段管乐均如此，直到乐句将结束为收尾与推动才回到单个长音。
- **低音布局线索**：打击乐作为主歌持续低音（僧侣脚步声），其强弱变化带领改编低音部分的整体布局；低沉乐句处用钢琴**低 / 极低音区**强调鼓声，右手用**中–低音区交替**强调鼓声高低变化；第二大段**低音加八度**还原鼓声，并配合高声部管乐拉空间感。
- **高声部冲突取舍**：和声与管乐声部都主要在高声部、音区接近，必须区分取舍 —— 第一段主歌乐队薄、小提琴旋律是主角时**主旋的和声优先于编曲加花旋律**（钢琴右手主要保留和声）；第二段层次更丰富时**乐器声部优先于和声层**（钢琴右手主要保留不同乐器部分）。
- **放弃预制钢琴的理由**：原想提前在琴弦上做处理使音色更柔和，但后文需要正常音色时物品不方便快速去除，故放弃；改用钢琴高音区清冷音色对和声中似戏腔的音色起提亮作用。
- **副歌内部对比**：原曲高声部民乐奏双音 → 钢琴前半**去掉双音中的高声部、留在中音区**（营造漫长道路徐徐行走），后半重新加入高声部做对比。
- **复调推动**：第二遍副歌内声部保留第一遍副歌的音高节奏，上层加入**小号旋律与主旋律形成复调**，在主旋律基本相同的前提下增加推动力；钢琴用分声部层演奏，音区间隔小、音色区别小时靠**不同触键**区分声部并保持推动力。
- **尾奏频率丰满**：小号复调延续到结尾、乐器由钢琴变为小提琴；原本唢呐部分留给**钢琴八度**强调（唢呐旋律发声点更稀疏，更好保障内声部变换与密集节奏型）；尾奏鼓点律动变化体现在低声部，用**低音区加八度**凸显新律动，使各频率段在结尾高潮丰满而不失层次。

### 3.3 影视 / 宣传片管弦织体（A：BV1UU4y1e7CP）

### 3.5 专栏正文：对位法 / 复调 6 原则（B：read/mobile?id=22780《4-4和声》）
①两声部结合以协和音程为主，**三、六度应用最广、限制最少**；②避免尖锐 / 暧昧不协和音程（大七、小二、增四、减五）在**显著节拍**碰撞；③**斜向与反向进行**最突出声部线条独立性、最具复调意味，是声部运动主要形式；④平行与同向进行不易显现独立性，平行八五度与同向到达八五度应尽可能避免；⑤为旋律流畅短暂出现的**声部交错允许**，但不宜长时间过多使用；⑥**声部超越**干扰旋律线连贯，应尽量避免。
同篇定义：**严格对位** = 中古教会调式为基础、以音程进行为根据、在固定歌调上写各类对位曲调，规则严格繁多，多与 16 世纪合唱风格相关；**自由对位** = 大小调体系为基础、以和声进行为根据，不协和音处理 / 转调更接近 18 世纪器乐创作。

### 3.6 专栏正文：编制 / 四部和声 / 音色叠置（B 级）
- 单管 `木管各1 + 圆号2–3 + 小号1 + 弦乐 10/8/6/4/2`；双管 `木管各2 + 圆号4 小号2 长号3 大号1 + 14/12/10/8/6`；三管 `各2+1 变种 + 圆号4–6 小号3 + 16/14/12/10/8`；四管 `各3+1 变种 + 小号4 + 18/16/14/12/10`；改任一组数量其余组需同步增减以保持音量比（A：栗锦文 cv17584806）。
- 流行弦乐 `86442 / 64221 / 6422 / 1111 / 2222`；人数越多越宏大、越少越轻盈细腻；**歌曲中的弦乐声相可区别于管弦乐团，所有乐器向中间靠拢**，与吉他贝斯鼓配合更融合紧致（B：read/mobile/15114990）。
- 密集排列 = 上三部相邻 3 / 4 度；开放排列 = 相邻 5 / 6 度；低音与次中音距离不限（同度到两个八度）；I/IV/V 重复根音 > 五音 > 不重复三音；不重复导音（B：cv22767、cv6433812）。
- 贝斯定弦 `E A D G`；**先配好四部和声与鼓节奏，再跟四部和声低声部画根音**；重音跟底鼓或走底鼓间隙；一般弹根音，特殊时弹五音 / 三音（B：read/mobile?id=67320）。
- 音色叠置三组合：弹拨+拉弦 = 自然、音量相当；吹管+拉弦 = 旋律强有力；吹管+拉弦+弹拨 = 协调、坚实圆润丰满；**强拍用协和音程，不协和音程放弱拍过渡处**（B：cv20292333）。
