# 情感表达：让音符携带情绪的科学与手艺

> 定位：**先定情绪，再写音符。** 本文件回答两件事——
> ① 音乐为什么能让人产生情绪（机制）；② 每种情绪用什么配方做出来（手法）。
> 所有参数是起点不是法则，以耳朵为准。

## 1. 情绪工作流：先写情绪卡，再动笔

写纯音乐/编曲前，先填一张 3 行的**情绪卡**，贴工程开头：

```
情绪卡
1. 一句话情绪：如"克制的悲伤，不是嚎啕大哭"（越具体越好）
2. 情绪弧线：A → B → C，如"疏离 → 涌动 → 释然"（三个点，不是一条直线）
3. 参照锚点：一首情绪对位的参考曲 + 一个画面/记忆（可选但强烈推荐）
```

**为什么**：决定情绪的是"效价 + 唤醒"两个轴（见 §2），而 tempo/mode/音色/密度
都只是这两个轴的旋钮。情绪卡先锁死目标，后面每个编曲决策就有了裁判。
没有情绪卡的工程，99% 会沦为"技术正确但无感"的音轨堆砌。

## 2. 音乐情绪的科学框架

### 2.1 效价–唤醒模型（Valence–Arousal）

所有情绪都可以放进一个二维坐标，这是选择参数的**总地图**：

```
            低唤醒                      高唤醒
  正效价 | 宁静/治愈/温柔           | 欢乐/激动/ Triumph
  负效价 | 悲伤/忧郁/孤独           | 愤怒/紧张/恐惧
```

- **效价（valence）= 听上去正还是负** → 主要由**调式（大小调）**控制
- **唤醒（arousal）= 让人平静还是兴奋** → 主要由**速度（tempo）**控制

实验证据（Gagnon & Peretz 2003；Rigg 1940；Trochidis & Bigand 2013）：
- 快速度主要推高唤醒，不直接改变效价——**快的小调 = 紧张/愤怒，不是"开心的歌"**
- 大调主要提升效价——**慢的大调 = 宁静/温柔，不是"悲伤的歌"**
- 慢速 + 小调 = 悲伤；快速 + 大调 = 欢乐（两个经典象限）
- 速度对"欢快"判断的影响比调式更突出（tempo 是第一变量）

**制作结论：想调"痛不痛"动调式，想调"激不激动"动速度。两个别搞反。**

### 2.2 BRECVEMA：音乐触情的八条机制（Juslin & Västfjäll）

理解听众为什么会有情绪，才能对症下药。每条机制后面是**可直接使用的制作手法**：

| 机制 | 触发条件 | 产生的情绪 | 制作上的用法 |
|---|---|---|---|
| **B** 脑干反射 | 突然、大音量、不协和、快速音型 | 惊吓、警觉 | jump-scare 的 hit；突然的全乐队止音；不要滥用（会廉价） |
| **R** 节奏同步 | 清晰稳定的 pulse | 兴奋、律动、"想动" |  groove 要让人能踩准；kick 与 bass 锁死；clap/snare 的位置 |
| **E** 评价性条件反射 | 与某段经历反复配对 | 唤起原经历的情绪 | 风格锚定：用听众已建立联想的音色（如口琴=怀旧） |
| **C** 情绪传染 | 音乐本身"表演"出某种情绪 | 听众镜像感受 | 慢速小调下行旋律=悲伤传染；**演奏感比音高更重要** |
| **V** 视觉意象 | 音乐激活内心画面 | 沉浸、放松或特定叙事情绪 | 写纯音乐时主动想画面：雾、雨、旷野、夜航 |
| **E** 情景记忆 | 勾连个人记忆事件 | 怀旧、思念、自豪 | 用"有年代感"的音色（磁带饱和、老钢琴采样） |
| **M** 音乐期待 | 预期被**延迟/违背/确认** | 期待、焦虑、惊奇、释然、"起鸡皮疙瘩" | **最重要的一条，见 §2.3** |
| **A** 审美判断 | 听众主动欣赏技艺/美感 | 赞叹、满足、无聊 | 一个漂亮的转位、一次意外的配器值得一次聆听 |

**关键认知：八条机制并行叠加。** 一首歌可以同时踩中 R（groove）+ C（旋律传染）
+ M（期待管理）+ V（画面感）——这就是"有层次的情绪"的来源。

### 2.3 期待管理：M 机制的工程化（Meyer / Huron）

听众的大脑永远在预测下一个音。**情绪 = 预测与现实的差值。**

五种可复用手法：

| 手法 | 做法 | 效果 |
|---|---|---|
| **延迟解决** | 属和弦后挂 2–4 小节才回主和弦；或旋律停在 2 音（re）不回家 | 渴望、揪心；Zimmer 拖整幕不解 |
| **违背期待** | 该上行时突然下行；大调里塞一个 ♭VI | 惊奇、心一紧；电影"反转"音 |
| **阻碍终止** | 副歌最后一句换一个非预期的和弦收尾 | 意犹未尽、开放式余韵 |
| **确认期待** | 熟悉的乐句原样回归 | 归属感、释然、"回家了" |
| **推迟高潮** | 已铺满，临门一脚再收 2 小节再爆发 | 爆发力翻倍（先减后加原则的心理学版） |

**实践公式：一次"违背"必须配一次"确认"。** 通篇意外 = 难听；通篇确认 = 无聊。
经典配比：**70% 确认 + 30% 意外**，且意外要出现在乐句末尾（听完整句才有意义）。

### 2.4 鸡皮疙瘩（chills）的触发点

学术与业界共识，以下时刻最容易触发头皮发麻：

1. **闯入的新元素**：一段安静的曲子，一个原本没出现的音色/八度/和声层突然进入
2. **音区突跳**：旋律从中音区突然上跳一个八度（常用在 bridge 尾进 final chorus）
3. **动态骤变后的强收**：突然的全停 → 一个干净的单音
4. **期待已久的主题回归**：离场 60 秒以上的主旋律，以更满的配器回来
5. **人声/类人声进入**：纯音乐里一个合唱 pad、哼鸣、或呼吸声

**制作结论：全曲至少设计 1–2 个"chills 点"，写在哪、怎么进，先规划再写。**

## 3. 特征 → 情绪映射表（核心速查）

| 特征 | 参数 | 情绪指向 | 备注 |
|---|---|---|---|
| **速度** | <60 BPM | 沉重、仪式、宿命、送葬 | 太快会滑稽；慎用 |
| | 60–75 | 悲伤、抒情、独白 | 抒情曲黄金区 |
| | 75–95 | 叙事、温暖、中速摇摆 | lo-fi / soul 区 |
| | 95–120 | 稳健、行走、积极 | pop verse 常见 |
| | 120–140 | 舞曲、昂扬、愉快 | house / funk 区 |
| | 140–170 | 紧张、能量、推进 | DnB / 战斗场景 |
| | >170 | 狂热、混乱、极致张力 | 慎用，易疲劳 |
| **调式** | 大调（Ionian） | 明亮、稳定、喜悦 | 默认值；太"安全" |
| | Lydian（#4） | 梦幻、漂浮、史诗、未来感 | 电影与 dream-pop 的秘密武器 |
| | Mixolydian（♭7） | 布鲁斯、乡土、上扬的豁达 | 摇滚/乡村/funk |
| | Dorian（小调+6级） | 忧郁但**有希望**、酷、微醺 | jazz/funk；"悲而不伤" |
| | 自然小调（Aeolian） | 悲伤、严肃、经典小调 | 默认"悲伤" |
| | Phrygian（♭2） | 阴暗、西班牙、凶险、异域 | 弗拉门戈/金属；♥慎用 |
| | Locrian | 极度不稳定，几乎不可用 | 理论存在，实用极少 |
| **音区** | 高音区旋律 | 明亮、尖锐、脆弱、紧张 | 高频也刺耳，注意强度 |
| | 中音区 | 人声区、亲切、叙事 | 最"说话"的区间 |
| | 低音区 | 沉重、威胁、庄严、深邃 | 低频也糊，注意掩蔽 |
| **音量/动态** | 渐强 crescendo | 期待、逼近、不可避免 | 层级递进，别一步到位 |
| | 骤强 | 惊吓、胜利宣告 | brain-stem reflex |
| | 骤弱/骤停 | 震惊、空虚、专注 | **停顿是乐器**，见 §5.3 |
| | 极弱 pp | 亲密、私语、脆弱 | 留白让后面的大成立 |
| **演奏法** | Legato 连奏 | 温柔、连贯、悲伤、歌唱性 | 悲伤与柔情的载体 |
| | Staccato 断奏 | 紧张、愤怒、轻快、机械 | 恐惧/愤怒 > 连奏（Juslin 1997） |
| | 颤音 vibrato | 激动、成熟、紧张（快颤） | 慢宽颤 = 温暖；快窄颤 = 紧张 |
| | 拨奏 pizzicato | 俏皮、轻巧、不安 | 悬疑常用 |
| | 闷音/弱音器 | 压抑、遥远、诡异 | 弱音小号/闷音吉他 |
| **织体/密度** | 单薄（1–2 件） | 亲密、孤独、 fragile | 独奏钢琴是默认"脆弱"语言 |
| | 浓厚（全奏） | 宏大、沉浸、压迫 | "墙"的力量；别超 40% 时长 |
| | 干声（少混响） | 直接、近距离、真实 | 贴耳感 |
| | 湿声（长混响） | 空旷、梦幻、疏离、空间感 | ambient 的骨架 |
| **和声色彩** | 三和弦为主 | 朴素、稳定、经典 | 民谣/儿歌气质 |
| | 七/九/挂留和弦 | 成熟、都市、梦幻、怀旧 | 色彩和弦是情绪调味剂 |
| | 不协和/增/减和弦 | 紧张、不安、危险 | 悬疑标配；需解决 |
| |  pedal point（持续低音） | 宿命、推进、仪式感 | 上方和声怎么变都"逃不掉" |
| | 调式互换/借用和弦 | 意外、高级、情绪转折 | ♭VI、♭VII 最常用 |
| **节奏** | 平稳四分脉冲 | 安定、行走、理性 | ambient 的心跳 |
| | 切分/反拍 | 摇曳、期待、律动 | 把重音挪走的瞬间最骚 |
| | 附点/三连音 | 推进、滚动、骚动 | 军鼓滚奏是通用张力语言 |
| | 固定音型 ostinato | 执念、不可避免、催眠 | Zimmer 的引擎；Glass 的全部 |

## 4. 情绪配方表：要什么情绪，就抓什么药

每个配方按 **调式 / 速度 / 音区 / 织体 / 和声花招 / 配器 / 动态** 七栏给。

### 4.1 悲伤（Sadness）

- 调式：自然小调（或 Dorian 做"悲中有光"的变体）
- 速度：60–75
- 音区：中低；旋律以下行为主，乐句结尾往下收
- 织体：薄，独奏钢琴 / 独奏大提琴 + 极轻 pad
- 和声：i – ♭VI – ♭III – ♭VII（小调经典下行）；结尾停在 i，**但旋律停在 3 音或 5 音**，
  制造"没说完"的余韵
- 配器：felt piano（毛毡钢琴）、cello、cor anglais、口琴
- 动态：整体 pp–mp，全曲一个高点在 3/4 处，然后就让它慢慢落下去

### 4.2 渴望 / 思念（Longing / Yearning）

- 与悲伤同骨架，但：速度 70–85；和声里加 **maj7 / add9**；
  旋律**在高点停顿并重复一次**（欲言又止）；配器加一种"遥远"的东西
  （远处 synth pad、电话线滤波的人声哼鸣）
- 关键花招：**副歌前离调到关系大调，再落回小调**——"看见过光，又回到黑暗"

### 4.3 怀旧 / 治愈（Nostalgia / 治愈系）

- 调式：大调但多用 **IV – iv**（同主音小下属）或 ♭VII；
  速度 75–90；配器走"年代感"：磁带饱和、老 Rhodes 电钢、八音盒、马林巴
- 和声：IIm7 – V – Imaj7 循环（经典 J-pop 治愈进行）；sus4 → 3 音的缓慢解决
- 节奏：swing 或轻微 shuffle，**不抢拍**
- 整体目标：像"周日下午的阳光"，唤醒值压低、效价拉正

### 4.4 紧张 / 悬疑（Tension / Suspense）

- 调式：小调或 Phrygian；速度不必快，**80–110 的"不快但压人"最有效**
- 节奏：**ostinato 固定音型**（十六分音符重复的弦乐/脉冲 synth）+
  "滴答"元素（clock tick / rim click）
- 和声：持续不解决——属七挂住、减和弦爬行、小二度碰撞
- 配器：col legno（弦乐敲击）、低音铜管长音、金属打击乐、倒放混响
- 动态：整体不要响，**在 mp 附近持续加层不加量**——压迫感来自密度不是音量

### 4.5 壮阔 / 史诗（Epic / Triumph）

- 调式：大调或 Lydian；速度 90–120（行进感）；配器：铜管 + 定音鼓 +
  弦乐震音 tremolo + 合唱 pad
- 和声：I – V – vi – IV 的"上行大调"骨架，副部转 Lydian 提亮
- 结构：**crescendo architecture**——从单音/ drone 起步，每 8 小节加一个声部，
  连续 32–64 小节推到全奏；高潮只来一次
- 关键：**高潮前 4–8 小节必须减层**（先撤鼓与 bass），否则"大"不起来
- 低频纪律：定音鼓与 bass 分工，别在 60–120 Hz 顶牛

### 4.6 宁静 / 治愈 / 冥想（Calm / Ambient）

- 调式：大调或五声音阶（pentatonic 怎么弹都不刺耳）；速度 <70 或无脉冲
- 织体：长音 pad + 稀疏"事件"（每 4–8 小节一个钢琴音或铃声）
- 和声：sus2 / add9 为主，慢速移动（一个和弦 4–8 小节）
- 空间：长混响（RT60 3–5 s）+ 延迟；**没有 kick**，低频交给 sub sine 慢速起伏
- 目标：唤醒值最低；**"删到不能再删"是本风格的创作动作本身**

### 4.7 欢乐 / 明亮（Joy / Bright）

- 调式：Ionian 或 Lydian；速度 115–135
- 旋律：跳进多于级进，高点在乐句中前段（先给甜头）
- 配器：亮铜管/电钢/拨弦/clap；staccato 木管点音符
- 节奏：反拍 accent、clap on 2/4
- 警告：欢乐的敌人是"甜到腻"——保留一点点不协和（一个 maj7 挂住）或
  一句短小的对比句，防止糖精感

### 4.8 不安 / 诡异（Unease / Uncanny）

- 调式：Locrian 味道（♭2 + ♭5）或 Phrygian dominant；无稳定调性感
- 配器：音高不稳的来源——唱片噪音、弯音的 synth、 music box 走调、
  处理过的人声（倒放、共振峰偏移）
- 和声：三全音（tritone）悬而不解；小二度 drone
- 空间：异常短或异常长的混响（违反物理常识的空间=本能警觉，brain stem reflex）

### 4.9 孤独 / 虚空（Isolation / Void）

- 织体：**单旋律 + 大空间**。一件乐器，长混响，几乎没有低频
- 速度：<60 或自由速度（rubato）；节奏几乎不存在
- 配器：独奏 + 极远的 pad；可以用单声道中频段的音色制造"一个人在对岸说话"
- 动态：整体 pp；结尾不要渐强，让它自然消散

### 4.10 愤怒 / 战斗（Anger / Aggression）

- 调式：Phrygian 或小调；速度 140–170
- 节奏：双踩 / 十六分军鼓滚奏 / 全乐队同音（unison riff）
- 配器：失真吉他/失谐合成器、低音长号、强击打击乐
- 和声：**不解决**——半音摩擦、增和弦；结尾停在属，不给归宿
- 提醒：愤怒靠**密度与失真**不靠音量；响而不密 = 噪，不怒

## 5. 时间维度的情绪工程

### 5.1 情绪弧线（Emotional Arc）三段式

```
段一 铺垫（约 25%）：立情绪、立动机、留白多、唤醒低
段二 张力（约 50%）：加密度、加音区、和声变复杂、唤醒爬升
段三 释放/余韵（约 25%）：高潮 → 衰减 → 收束；或开放结尾
```

- **纯音乐没有歌词报幕，弧线全靠配器进出标记**——每段转换处必须
  有一个"听得出来的事件"（新音色进入/齐奏/全停/调性转移）。
- 相邻段的唤醒值必须不同（差 ≥1 个刻度），否则听众感知不到"事情在发展"。

### 5.2 高潮的稀缺性

- **全曲高潮（最大密度+最高音区+最响）只出现一次。** 出现两次以上，
  听众对"大"的感知会通胀，后面都不大了。
- 高潮时长 8–16 小节足够；撑得越久越泄气。
- 高潮之后**必须衰减**（breakdown 或 solo 收束），不要硬切下一段。

### 5.3 沉默是乐器

- **停顿的三种用法**：
  1. 句读——乐句之间的 1–2 拍空，让上一句被听见；
  2. 抽空——高潮前全体静音 1–2 小节，再进全奏（最便宜的"大"）；
  3. 结尾——尾奏后完全静默 1–2 秒再淡出，情绪自己会填满。
- 规则：**任何超过 8 小节没有"密度变化"的段落，插入一次停顿或减层。**

### 5.4 收尾的六种情绪

| 收尾 | 手法 | 情绪 |
|---|---|---|
| 完全解决 | 旋律回主音、大三和弦收 | 圆满、结束、告别 |
| 阻碍收尾 | 停在属/挂留和弦 | 意犹未尽、开放式、续集感 |
| 渐弱消散 | fade / 混响尾巴 | 梦境、逝去、余韵 |
| 骤停 | 全乐队同时收音 | 决绝、惊雷、定格 |
| 变奏再现 | 主题换音色孤独重现 | 回忆、事过境迁 |
| 转调升华 | 最后 4 小节升半/全音再现 | 超越、救赎（大团圆利器） |

## 6. 乐器音色情绪字典（配器速查）

### 6.1 弦乐

| 乐器/奏法 | 性格 | 适用情绪 |
|---|---|---|
| 小提琴 高音区长音 | 尖锐、悬置 | 紧张、恐惧（《惊魂记》式） |
| 小提琴 中音区 legato | 歌唱、热情 | 抒情、浪漫 |
| 弦乐震音 tremolo | 颤动、逼近 | 悬疑、恐惧、史诗铺垫 |
| 中提琴 | 鼻音、贵族气、内敛 | 沉思、阴郁、中年叙事 |
| 大提琴 | 最接近人声的器乐 | 悲伤、温暖、思念（默认"哭"的音色） |
| 低音提琴 | 沉稳/不祥 | 庄严或威胁，看上下文 |
| pizzicato 拨奏 | 轻巧、不安 | 俏皮、悬疑 |
| col legno 弓杆敲 | 干、机械、骨头感 | 不安、仪式、超现实 |

### 6.2 铜管

| 乐器 | 性格 | 适用情绪 |
|---|---|---|
| 圆号 French horn | 温暖、贵气、远方 | 史诗、回忆、黎明 |
| 小号 | 明亮、宣告 | 胜利、凯旋（弱音器=遥远/哀悼） |
| 长号 | 庄严/威胁两极 | 宗教感、反派、沉重力量 |
| 大号 | 地基 | 压迫、庄重 |
| 铜管齐奏 ff | 最强"宣告" | 高潮、加冕、终极对决 |

### 6.3 木管

| 乐器 | 性格 | 适用情绪 |
|---|---|---|
| 长笛 | 银光、轻盈、飘 | 童真、自然、梦幻 |
| 双簧管 | 鼻音、凄婉、乡土 | 思念、孤独、田园哀愁 |
| 单簧管 低音区 | 暗、木、丝绒 | 神秘、夜、爵士叙事 |
| 英国管 cor anglais | 双簧管的更暗版本 | **孤独与思念的头号音色** |
| 巴松 | 干、幽默/阴沉两极 | 滑稽或地底感 |

### 6.4 打击乐与色彩乐器

| 乐器 | 性格 | 用法 |
|---|---|---|
| 定音鼓 | 心跳、命运 | 推进、战斗、加冕 |
| 军鼓滚奏 | 通用张力语言 | 任何"逼近"场景 |
| 钹/cymbal swell | 引爆、开门 | 高潮点火；**swell 要早半拍进** |
| 钟琴/竖琴/钢片琴 | 闪光、魔法 | 童话、转场、星光（《胡桃夹子》糖梅仙子） |
| 太鼓 taiko | 地鸣、集体意志 | 东方史诗、行军 |
| 钢琴（常规） | 从私语到全奏 | 万能；**felt piano=脆弱，硬击=愤怒** |
| 电钢 Rhodes | 暖、都市、傍晚 | 治愈、lo-fi、neo-soul |
| 风琴 organ | 教堂、崇高、阴森 | 神圣或恐怖（同一音色两种情绪） |
| 合成器 pad | 无限可调的空间胶 | ambient/cinematic 的底色 |
| 锯齿/方波 synth lead | 电子、锐、现代 | 能量、未来感 |

### 6.5 电声与"不完美"音色

- **磁带饱和 / 黑胶噪音**：年代感、怀旧、体温
- **Lo-fi 滤波（降采样）**：遥远、回忆、 protectively 模糊
- **失谐 detune**：不安、庞大、群感（detuned supersaw 是电子"史诗"默认）
- **弓弦噪音/呼吸声/按键声**：人性、在场感——**纯音乐里这些细节就是"人味"**

## 7. 旋律与情绪的微操

| 手法 | 效果 |
|---|---|
| 乐句整体上行 | 希望、振奋、提问 |
| 乐句整体下行 | 屈服、悲伤、答案落地 |
| 级进为主+偶发跳进 | 亲切、口语化；跳进=情感迸发 |
| 高点位置在句中前段 | 先亮底牌、明亮直接 |
| 高点位置在句尾 | 憋住后释放、揪心 |
| 同音重复 | 执念、追问、机械感 |
| 长音悬停后解决 | 叹息、释然 |
| 旋律短+长音少（朗诵式） | 压抑、克制 |
| 旋律被和声"裹着"（长音对位） | 梦幻、疏离 |

## 8. 自检清单（情感版）

写完/混完，逐条问自己：

- [ ] 情绪卡上的三个词，闭眼听能对得上吗？对不上，问题在哪个轴（效价/唤醒）？
- [ ] 全曲至少有一个"chills 点"吗？它出现前有铺垫吗？
- [ ] 有没有连续 16 小节唤醒值没有变化？
- [ ] 高潮是不是只出现了一次？高潮前有没有减层？
- [ ] 有没有用到至少一次"沉默"或骤停？
- [ ] 结尾的情绪是设计过的，还是"弹到没素材了就停"？
- [ ] 有没有哪个音色的情绪与整体目标矛盾（如"悲伤"主题里一个太亮的 bell）？
- [ ] 小音量/手机喇叭上，情绪还成立吗？（细节丢了情绪就丢了 = 织体太依赖高频）
- [ ] 找一个没参与制作的人听，问"你想到什么画面/词"——答案和情绪卡偏差大就要改

## 9. 常见错误

1. **用"悲伤和弦进行"冒充悲伤**——i–♭VI–♭III–♭VII 是骨架不是情绪，
   速度、奏法、留白不做，照样寡淡。
2. **过早放大招**——前 30 秒就用满编+大混响，后面没有弹药。能量要省着花。
3. **全程一个动态**——从头到尾 mp，等于没有情绪，只有音。
4. **情绪标签与音色打架**——谱面写"宁静"，鼓做得比人声还硬。
5. **意外太多**——每句都转调都离调，听众放弃预测 = 放弃倾听。
6. **没有设计结尾**——fade out 当默认选项。fade 是"放弃决定"的声音。
7. **忽略空间感这个情绪杠杆**——混响/延迟的自动化（远近变化）是最便宜的
   情绪推移手段，很多人整曲一个 send 量不动。
8. **追求"正确"**——参数表只是地图；**耳朵是唯一裁判**。

## 10. 情绪驱动编曲的落地文件（按情绪分类，优先走这条）

本文件讲**情绪为什么成立**（效价–唤醒、BRECVEMA、期待管理、弧线）；
当用户已经说清情绪、要的是**可复用的整套编曲方案**时，改走下面三份：

| 要做的事 | 文件 |
|---|---|
| 按情绪拿一整套配方（BPM / 调式 / 和弦 / 密度曲线 / 段落弧线 / 混响动态 / 失败模式） | `emotion-arrangement-recipes.md` |
| 按情绪查和弦进行、把同一条进行换成另一种情绪 | `emotion-chord-index.md` |
| 情绪落到钢琴 / 小提琴 / 手风琴的音区、奏法、力度、voicing | `core-instruments.md` |

用户主做情绪驱动编曲，主体编制是**钢琴 + 小提琴 + 手风琴**，
常见目标为宏大叙事与悲伤；给建议时以这三件套为默认，不要先抛乐队四大件或吵闹电子舞曲模板；
**合成器作为色彩层可用**（pad / bell / soft lead / 铺底），全程在 DAW 里完成。
吵闹电子舞曲风格单独收在 `electronic-styles.md`，主线不混。
情绪与可调参数的量化对照见 `emotion-arrangement-recipes.md` 的「情绪 → 可调参数」映射表。
