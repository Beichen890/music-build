# 编曲哲学与编曲思维

> **来源**：B 站公开教程 / 专栏 / 测评整理（采集 2026-11-11，973 条去重视频、8 个课程视频下载抽帧）。逐条来源见文末「来源索引」，学习清单见 `bilibili-study-map.md`。
> **制作口径**：默认在 DAW 里作曲编曲（MIDI + 采样音源 + 合成器 + 自动化 + 混音）；真实乐器、采样、合成器音色都是合法音色来源，不做「原声 vs 电子」的出身审查。
> **范围分流**：不默认做吵闹的电子舞曲风格（EDM / House / Techno / Trap / Dubstep / 鼓机 drop / riser / 泵感侧链 / supersaw lead），这类内容单独收在 `references/electronic-styles.md`，主线不混。
> **主用途**：情绪驱动 + 场景感双轴 + 钢琴 / 小提琴 / 手风琴三件套；合成器在这里是色彩与空间层（pad / bell / soft lead / 铺底），不是舞曲骨架。
> **用法**：数值是起点不是法则，以耳朵为准；与本技能既有硬规则冲突时，以技能规则为准。
> **情绪驱动**：按情绪查配方 `emotion-arrangement-recipes.md`、按情绪查和弦 `emotion-chord-index.md`、钢琴/小提琴/手风琴写法 `core-instruments.md`。
> **标注**：【源】/【事实】= 可核实；【验】= 交叉验证；【经验】/【通用理论补充】= 惯例或未单条核实，可放心改。

## 1. 一句话信条

> **编曲不是"把音色填满"，而是"决定听众此刻该听谁，以及什么时候让他休息"。**

继伟音乐工作室专门做过一期《编曲思维与演奏思维有什么不同？》【出处 V5】，正是这个区分：演奏思维想"我怎么弹"，编曲思维想"听众该听到谁"。三条硬推论：

1. 任一时刻，能被耳朵清楚追踪的独立线条 **≤ 3 条**。
2. 全曲必须存在 1 个明确的「最厚点」和 1 个明确的「最薄点」，二者层数差 **≥ 3 层**。
3. 任何声部，若静音后歌曲不变差，就该删掉。【出处 S2 / T3 / V4】【归纳规则】

## 2. 听觉注意力与前景—中景—背景三层

### 2.1 三层的定义（有出处）

瓦西连柯《交响配器法》相关札记：**前景**＝作曲者最希望被听众听到、最突出的旋律；**中景**＝复调旋律或重要的对位材料；**背景**＝伴奏材料（和声型或音型化）；并强调配器者"必须首先划分清楚哪些旋律是前景、哪些是中景、哪些是背景"【出处 T1】。左轮吉他网把完整器乐合奏拆成 **旋律层 / 和声节奏层 / 低音层 / 噪音层**，指出"旋律层是全曲最先被听到的层次""低音的连接本身就是一段好听的旋律"【出处 S5】。Waves 那篇更直白："我首先会挑选出一首歌中最重要的一两个元素，让听者始终对它们保持关注"【出处 S10】。B 站up主「搞音乐的rua某」有整期《你会塑造编曲的层次感吗？》专讲此事【出处 V1】；塞瓦音乐研究所《流行弦乐编曲思路》把弦乐层次拆成"明暗音区 / 松紧排列 / 演奏技法"三个可操作维度【出处 V10】。

### 2.2 落成可执行规则

- **前景固定 1 条**（人声或主奏乐器），任何段落都不新增第二前景。【归纳规则】
- **中景 0–2 条**：须与前景在两处错开——音区错开 **≥ 8 度**、节奏密度错开一档。啾咪一只www 分析小提琴主旋律走八分音符、中提琴副旋律走十六分音符，正是「音区 + 节奏」双重区分。【出处 S1】【归纳规则】
- **背景 2–3 层**：低音 1 层、和声 1 层、节奏 / 打击 ≤ 1 层。**总层数**：主歌 3–4 层、副歌 6–8 层、间奏 / 桥段 2–3 层（常用配比，非定律）。【归纳规则 / 业界经验 T5】
- **能量守恒**：主奏为点状 / 弱奏音色（钢片琴、竖琴、古筝弱奏）时，和声不得用长音铺满，改用拨奏或断奏。啾咪一只www 举《糖梅仙子舞曲》：钢片琴主旋律配弦乐拨奏，避免被淹没。【出处 S1，规则化】

### 2.3 一条现场判定

把伴奏 riff 单独静音再放回，若主旋律"变清楚了"，说明 riff 抢了前景。米饭星MusicFan 提醒：即便音量没问题，伴奏的经过音在音高上、切分音在节奏上也会与主声"打架"。【出处 S2】

## 3. 留白与减法

**【出处】** "静默也是一个声部""繁忙的编曲不见得就是丰富的编曲"【T3】；"不要一味地堆砌—要挑选出最适合歌曲的素材""就算是特别棒的演奏，如果不能符合项目的方向……还不如放弃使用"【S2】；"让一切保持变化……乐器应该进进出出"【S10】；啾咪一只www 分析《Binary Star》第 17–20 小节撤掉钢琴柱式和弦、空置主律动，制造"停下来"的悬念感【S1】。阿靖lina 在《为什么你的编曲总是乱乱又脏脏？》里给出本专题最凝练的一句："**成熟的作品是做减法的过程，不断的向自己提问，确定每做一步的意义，不去做多余的事情**"【出处 V4】；留声纪音乐《编曲新手常犯的 8 个错误》把症状写成"要么乐器堆得像一锅乱炖，要么听起来单薄得像张白纸"【出处 V2】。

**【归纳规则】** 主歌层数 **≤ 副歌层数的 60%**；每 **8 小节**至少 1 次「减层」（撤 ≥ 1 条声部、持续 ≥ 2 小节）；全曲至少 1 处 **≥ 2 拍的近静默**（只留 1 条声部）；每段新增一件乐器前先回答"删掉哪一条"，**进一件，退一件**；减法检查动作＝逐轨静音，问"歌是不是变差了"，不变差就删【T3 的动作，规则化】。

**【业界经验】** "怕空"的典型症状是用长音铺底把缝隙填满。判据：若某轨从头响到尾、从不进出，它多半是底噪而非编曲。【出处 T5 / V2】

## 4. 对比与重复的比例

**【出处】** 曲式三大原则：**对比、变奏、重复**【T2】。啾咪一只www 给出本专题最硬的数值："常规的四句旋律（八小节）通常重复三遍就已经是极限了（8×3=24 小节），且**每次重复都应该有明显的织体变化**"；相连的同材料段"大致重复三遍（包括第一遍）就不太能继续重复下去"【S1】。同一材料若隔了别的段落，"间隔越长，呼应感越强"，长到极致就是只在前奏和尾奏出现（《Ever Eternity》纯钢琴主题）【S1】。

**【归纳规则】** 8 小节主题连续重复上限 **3 遍 = 24 小节**，第 2 遍起每遍必须换织体（换乐器 / 换音区 / 换节奏型，三选一以上）；4 小节循环乐段原样不动连续 **≤ 2 次**，第 3 次必须改；第二遍副歌相对第一遍至少 1 处可辨差异（啾咪一只www 记的实例：两个高潮段相连时撤掉 Crash、保留 Shaker，做到"有变化但不减厚度"）【S1】；重复段间隔 **≥ 1 个完整段落**时可考虑"完全不变"以换强呼应，间隔为 0 时**必须变**；把最有辨识度的动机只放在前奏与尾奏、中段不复现，可制造回归感与结束感【S1，规则化】。

**【业界经验】** "好歌会自己生长发展，让我们既有熟悉感，同时又能发现惊喜"【S10】；熟悉 : 惊喜 ≈ **7 : 3** 是常用配比。【归纳规则，非定律】

## 5. 动机发展与变奏

**【出处】** 变奏＝保留某些特征同时变化，"一方面仍可使人听出原型同时又有新鲜感"；简单变奏保留旋律轮廓、节奏型甚至和声只加装饰，稍复杂的会改变旋律、节奏、调式调性、织体、和声，甚至只取原材料某个因素发展【T2】。米饭星MusicFan 记录的低成本变奏：木吉他换曼陀铃、大贝斯替换电贝斯、Rhodes / Wurlizer 代替钢琴——"就算是很细微的变化也很有用"【S2】；同篇记录管弦乐传统的 **doubling**：长笛 + 双簧管、吉他 + 钢琴同音高演奏，泛音融合出单件乐器无法获得的音响【S2】。

**【归纳规则】** 每次变奏至少**保留 2 个识别特征**（轮廓 / 节奏 / 和声 / 音区 四选二保留），最多改 2 个，四个全改等于写新主题、失去呼应；同主题第 2 次出现优先改配器（成本最低），第 3 次改织体或音区，第 4 次改和声 / 调式或做发展；一个动机至少准备 3 种形态：**原型 / 简化 / 装饰**；主题—发展—再现三段式的发展段必须出现 1 个原型没有的新音程或新节奏，否则只是重复【S1 / T2，规则化】；情绪性质改变而厚度不变也算有效变奏——啾咪一只www 记《仙家独酌》二胡改长笛，厚度不变而情绪由"苍老悲伤"转"舒畅悠扬"【S1】。

## 6. 起伏曲线与信息量管理

**【出处】** "把编曲想成一张能量随时间起伏的图，有高峰有低谷，而不是一条始终顶着满音量的直线"【T3】；B 站学院课程要求听歌时"听并画出情绪曲线"作为作业【S7】；道器音乐-绍弦《编曲没有起伏？八招让你的副歌更明显得到升华！》整期专治"平的编曲"【V3】。啾咪一只www 把相邻段落的织体衔接分为**剧烈增厚 / 渐进增厚 / 渐进减薄 / 剧烈减薄**四类、风格走向分为**维持 / 偏移 / 剧变**三类，并把情绪进行分为**渐进**（表现力均匀、无特别突出段）与**剧烈**（有弱段也有极强段）【S1】；米饭星MusicFan 的「能伸能缩」警告：第一遍副歌就把整个乐队推上去，后面两三遍副歌会失去效果，应把最大能量留给 bridge / solo 与最后一次副歌【S2】。

**【归纳规则】** **先画曲线再编曲**：每段打 0–10 能量分，副歌 ≥ 主歌 + 3，全曲最高分**只允许出现 1 次**；最厚段落之前**必须**接一个减薄段（撤高频 / 撤鼓 / 撤和声层之一，持续 2–4 小节，啾咪一只www 记过渡段"把高频打击留空"好让副歌一进来就显著增厚）【S1，规则化】；打击组逐层推进固定顺序：**底鼓 = 极薄 → 正常**，**军鼓 / 镲 = 正常 → 极厚**【S1】；任一时刻独立节奏型 **≤ 3 种**（所有乐器同节奏＝信息量 1，是编制浪费）；每 **16 小节**至少 1 次「预期违背」。

**【业界经验】** "渐进进行不喜欢间奏，剧烈进行喜欢间奏"【S1】——据此决定要不要写间奏，不凭感觉。

## 7. 「编曲不是堆音色」

**【出处】** "不要一味地堆砌—要挑选出最适合歌曲的素材"【S2】；"会什么就往音乐里堆"是错误路径，正确是**「从大往小想，从小往大写」**：先定作品最终样子、情感、结构与动态、主要风格，再定参考曲、和弦、节奏型、乐器【S6】；"如果你只用一件乐器和人声表演它，它还是一首好歌吗？如果不是，再谈其他的都无所谓了"【S10】；"编曲本身就是一门艺术"【S2】。留声纪音乐、阿靖lina 两支视频分别从"8 个新手错误"和"乱乱又脏脏"切入，指向同一件事：问题在**叠加过多**，不在音色不够好【V2 / V4】。

**【归纳规则：判定顺序，不许跳】**

1. 先把曲子剥到「1 件和声乐器 + 人声 / 主奏」。这遍不好听，问题在曲不在编曲，**回去改旋律 / 和声，禁止加乐器遮丑**。【S10 / T3 / V4】
2. 骨架顺序（逐段、逐层）：鼓 + 贝斯 → 核心和声乐器（弹简单、不挡人声）→ 主旋律稳置最上层 → 逐段削薄 / 加厚 → **最后**才加填音、对旋律、装饰。【T3】
3. 「最后加色彩」：色彩层只在骨架立住之后写，且只在换气、句尾、间奏出现。【T3 / T5】
4. 数量判据：**3–4 件各司其职的乐器 > 10 件挤在一起的乐器**；每件乐器必须能回答"负责哪一层、哪一频段、哪一时段"，答不出就删。【业界经验 / T5 / V2】
5. **换音色 ≠ 换编曲**。只把钢琴换成 Rhodes 而声部、节奏、层数全不变，是同一编曲的两个音色版本，救不了"太单调"。【归纳规则；S2 的"细微音色变化"用于保鲜，不用于救结构】

## 8. 编曲与混音的职责边界

**【出处】** B 站专栏把流程排为：词曲 → demo → **编曲** → 乐队实录 → 演唱 → **混音**，定义"现代的编曲，其实包含了：为旋律编配和声，为旋律选择合适的乐器，为乐器编写织体旋律"，"当所有的环节确认无误以后，接下来就将所有任务交给混音师"【S9】；另一篇："混音是指将多轨素材整合成一轨立体声音频"，"编曲本质上就是给一首只有旋律的歌曲做上伴奏……每一个乐器的每一个音符都要编配出来"【S11】；顾焕金："作曲是搭建骨架，编曲则是丰满血肉"【T4】。

**【归纳规则：一张判定表】**

| 归编曲（要动音符 / 声部 / 乐器） | 归混音（只动已有素材的关系） |
| --- | --- |
| 选哪件乐器、几个声部 | 各轨音量平衡 |
| 每个声部写什么音符、什么节奏型 | EQ / 压缩 / 去齿音 |
| 声部在第几小节进、第几小节出 | 声像 pan 摆位 |
| 音区分配、织体厚薄、段落长度 | 混响 / delay 空间统一 |
| 和声编配、副旋律、对位 | 母带前的整体整合 |

**一条判定规则**：靠静音 / 独奏、调音量、改 pan、EQ、压缩能解决的是**混音问题**；必须删声部、改音符、换乐器、改进出小节、改段落长度的是**编曲问题**。**禁止用混音补编曲**：两件乐器挤同一音区或同节奏重叠，靠 EQ 切不出层次，应在编曲阶段改音区、改节奏型【S1 / S2 / T5】。

## 9. 段落叙事与情绪弧线

**【出处】** 啾咪一只www：段落定性三维度——**情绪厚度、主材料重复度、织体组成**；情绪厚度**不必然**靠织体厚（《Binary Star》第一遍副歌仅钢琴柱式 + Vocal，很薄却情绪高涨）；材料重复制造「期待感」——听过副歌第一遍后，对第二遍既期待重现又期待惊艳改动；间奏"常常是为了让听众暂时把主旋律给'忘了'，避免审美疲劳，同时让接下来重复主旋律变得合理"【S1】。南城住着一只猫《大流行桥段怎么编？一首歌的情绪转折点是如何设计的》专讲段落转折【V9】。

**【归纳规则】** 写段落前先填表，每段一行：`段落名 / 能量分(0–10) / 层数 / 前景是谁 / 主材料第几次出现 / 与上一段的织体变化(增厚·减薄·维持 + 风格维持·偏移·剧变)`，后两项直接套用 S1 的四分类与三分类。可直接套用的弧线（流行 / 摇滚）：前奏(2–3) → 主歌1(3) → 主歌2(4) → 预副歌(5) → 副歌1(7) → 间奏(3–4) → 主歌3(4) → 预副歌(6) → 副歌2(8) → 桥段(3) → 最后一次副歌(10) → 尾奏(2)，**最高点只在最后一次副歌出现 1 次**【参考 S2「能伸能缩」】；每次副歌回来至少改 1 处织体，最后一次副歌前必须有 1 个明显减薄的桥段；让主旋律「消失」一个段落再让它回来，比一直重复更耐听【S1，规则化】。

## 10. 参考曲学习法：怎么听、听几遍、记什么

**【出处】** B 站学院课程给出「音乐制作五大元素」听法：**听词曲 / 听演唱 / 听编曲 / 听录音 / 听混音母带**，每项都追问"为什么要这么做"，并要求"听并画出情绪曲线"【S7】；李昊霖："如果听音乐只是随便听听，是不会有任何效果的，**必须全神贯注的反复听，类似于'扒带'的感觉**"【S3】、"多听听那些优秀的编曲作品……要想想，他们是如何想的？如何编的？为什么要这么编曲"【S4】；Splice 建议一首歌至少完整听 3 遍、每周留 1 小时【T7】。B 站可参考的实拆类内容：搞音乐的rua某《林俊杰 可惜没如果 扒带分析》【V14】、音乐制作王某人《2分钟带你解析一首流行歌的制作过程》【V15】、装饰音《影视配乐总谱分析合集》【V16】、RolingStudio编曲学堂《总谱分析干货分享》【V17】。

**【归纳规则：固定 4 遍法】** 第 1 遍（不记笔记）只画 0–10 能量曲线、标出最厚点最薄点在第几小节；第 2 遍（分元素）按前景 / 中景 / 背景逐层记「什么乐器、什么音区、什么节奏型、第几小节进 / 出」；第 3 遍（结构）标段落边界（小节号）、每段层数、主材料第几次出现、与上段的织体变化；第 4 遍（为什么）对每处进出回答"为什么在这里进、去掉会怎样"，答不出的记入待扒清单。每次精听产出一张 **7 项卡片**：`BPM / 调性 / 编制清单 / 段落表(小节号) / 能量曲线 / 三层分配 / 3 个"为什么"及自己的答案`【参考 S7 / S3】。选曲顺序：先同风格 **3–5 首** → 再跨风格 **2 首** → 再回到目标曲；李昊霖建议多听 80 / 90 / 2000 年代金曲与"超越时间的金曲"【S3】；难度选"比现有能力高出一点"的作品，卡死就降难度【业界经验】。

## 11. 审美判断从哪来

**【出处·明确观点】** 李昊霖："熟悉的音乐越多，音乐的'品味'越好""做音乐的实力会与听音乐的数量成正比"【S3】；"所谓的'品味'就是代表编曲人所有用的'资料数据库'的量。也就是说，**听了多少音乐，又是怎样研究这些音乐的**"，并用"衣服款式多的人能按场合挑衣服"类比【S4】。啾咪一只www 自述经验来自"自己作曲、自己通过频谱仪等手段分析他人作曲"的自学路径【S1】。B 站另有几期直接讨论审美本身：默习《什么是审美兼容？》【V7】、做音乐的明明Mix《编曲里的"高级感"到底是什么？》【V6】、Suka_lazeri《审美有高下之分吗？》——其后者的描述点出关键："聊聊'我喜欢'和'它很好'之间，到底差了什么"【V8】；林久在作曲《配器到底学什么，怎么正确学》则给出学习路径层面的回答【V18】。

**【归纳规则：把"品味"变成可积累、可考核的量】** 建一个资料库，每首精听曲记录 §10 的 7 项卡片，**条目数就是可量化的"品味"**；目标：每周 ≥ 1 首完整精听，每季度 ≥ 1 个风格专题（≥ 10 首）。判断力训练：对每首曲**先**写下"我会怎么编"（3 条具体决定），**再**对照原曲记录差异与原因——这是把"听数量"转成"研究质量"的关键动作【S4 的"怎样研究"，规则化】。三分法自律：遇争议先看结论属于 `【出处】/【业界经验】/【归纳规则】` 哪一类，**不把个人偏好当定律**。审美不是玄学的可操作替代：两个方案选不出时用 §15 自检清单逐条打分，分高者胜；仍平手**选层数更少的那个**【T3"刻意地选择，而不是习惯性地一味加料"】。

## 12. 常见误区（6 个，各给一个数值化修正）

1. **全程满** → 第一小节所有乐器到齐，后面无牌可打。修正：第 1 小节层数 **≤ 全曲最厚层数的 50%**；每 8 小节至少 1 次减层。【S10 / V2 / 业界经验】
2. **四小节一循环不加变化** → 修正：原样重复 **≤ 2 次**，第 3 次必须改；8 小节主题重复 ≤ 3 遍且每遍换织体。【S1】
3. **所有乐器同节奏** → 信息量坍缩成 1。修正：同时并存的独立节奏型 **≥ 2 且 ≤ 3** 种，各层音区不重叠。【S1 / T5 / V4】
4. **高频堆叠 / 频段打架** → 多件乐器挤同一音区，浑浊。修正：低 / 中 / 高每层各 1–2 件；总层数主歌 ≤ 4、副歌 ≤ 8。【T5 / V4】
5. **怕空** → 用长音铺底填满所有缝隙。修正：全曲强制留 1 处 **≥ 2 拍**近静默，每段至少 1 次乐器"退出"。【T3 / S10 / V4】
6. **主歌副歌一个配置** → 听众分不出段落。修正：副歌层数 **≥ 主歌 × 1.6**，能量分差 **≥ 3**。【V3 / T5】

附：留声纪音乐《编曲新手常犯的 8 个错误》与阿靖lina《为什么你的编曲总是乱乱又脏脏？》是这两类误区的集中案例，可对照自检【V2 / V4】。

## 13. 可执行的训练法（4 类，各给步骤）

### 13.1 扒带（顺序不可跳）

`测速并对齐小节 → 检测和弦 → 按和弦走向 / 音区 / 情绪分段 → 给每段登记乐器清单 → 以一条乐器轨为线索从头扒到尾、扒完一条休息一次`【S8】；不要同时扒所有乐器（易听觉疲劳）。B 站专门讲此流程的有乐才派编曲课堂《如何通过扒带来学习编曲》【V11】、苏胖不靠谱《三个步骤学会扒带》【V13】；七线阁官方《别再错误的扒带了！》给出一条重要提醒——"**Midi 文件不等于扒带**"，拿到工程不等于练到耳朵【V12】。强化版：直接把「旋律 + 鼓组」两轨扒出并在宿主复刻，体会两者关系【S1】。

### 13.2 限制编制练习

同一段 8 小节旋律写 3 个版本：① 1 件和声乐器 + 人声；② 加贝斯 + 鼓；③ 允许再加 1 件色彩乐器。**第 ① 版不好听就不许进 ②**【S10 / T3 / T6】。检验句："只用一件乐器和人声表演它，它还是一首好歌吗？"【S10】

### 13.3 单轨重写

拿一首已完成编曲，只保留 1 条轨（建议贝斯或鼓），从零重写其余全部声部，再与原曲 A/B 对照，列出差异清单。训练"从骨架长出血肉"。【归纳规则，参考 T3 逐段编曲顺序】

### 13.4 A/B 对照

同一段落做两版（密集 / 稀疏）；逐轨静音判断"歌是不是变差了"【T3】；换 3 种设备各听一遍【T5】；两版间隔 1 天再盲听选一版【归纳规则】。**每周固定 1 小时**做「完整精听 + 以上任一练习」【T7】，比零散看 10 个片段有效【业界经验】。

## 15. 编曲自检清单（20 条，逐条可勾选的判断题）

- [ ] 1. 全曲能否用一句话说清"听众此刻该听谁"？
- [ ] 2. 任一时刻可追踪的独立线条是否 ≤ 3 条？
- [ ] 3. 前景是否始终只有 1 条（没有第二主奏抢戏）？
- [ ] 4. 中景与前景是否音区错开 ≥ 8 度、节奏密度错开一档？
- [ ] 5. 低音层是否写成了一条有线条的旋律，而非只弹根音？
- [ ] 6. 低 / 中 / 高每层是否各 1–2 件、没有两件乐器同音区同节奏？
- [ ] 7. 主歌层数是否 ≤ 副歌层数的 60%？
- [ ] 8. 副歌层数是否 ≥ 主歌 × 1.6、能量分差 ≥ 3？
- [ ] 9. 全曲是否只有 1 个"最厚点"，且出现在最后一次副歌？
- [ ] 10. 最厚段落之前是否接了一个持续 2–4 小节的减薄段？
- [ ] 11. 全曲是否至少 1 处 ≥ 2 拍的近静默？
- [ ] 12. 每 8 小节是否至少发生 1 次"减层"（撤 ≥ 1 轨、持续 ≥ 2 小节）？
- [ ] 13. 是否存在任何一轨从头响到尾、从不进出？（有则不合格）
- [ ] 14. 8 小节主题连续重复是否 ≤ 3 遍（24 小节）？
- [ ] 15. 4 小节循环乐段原样连续是否 ≤ 2 次、第 3 次已改动？
- [ ] 16. 每次主题 / 副歌回归，是否至少改了 1 处可辨织体？
- [ ] 17. 每次变奏是否至少保留 2 个识别特征（轮廓 / 节奏 / 和声 / 音区）？
- [ ] 18. 每件乐器是否都能回答"负责哪一层、哪频段、哪一时段"？
- [ ] 19. 逐轨静音检查后，是否删掉了所有"静音不变差"的轨？
- [ ] 20. 剥到「1 件和声乐器 + 人声」这一遍，是否仍然好听？

## 16. 卡住时的 10 个决策顺序（严格按序，不许跳）

1. **先定曲线**：给这一段打 0–10 能量分，确认全曲最厚点在第几小节。没画出曲线不动手。
2. **定前景**：这一段只留 1 条主奏 / 人声，其余全部静音。
3. **验骨架**：用「1 件和声乐器 + 前景」试听；不好听 → 回去改旋律 / 和声，**停止加乐器**。
4. **补低音**：贝斯写一条有线条的旋律（70% 根音 + 30% 经过音 / 五音 / 八度跳进），不弹根音机。【数值来自 T5，业界经验】
5. **补和声节奏层**：只选 1 种音型（柱式 / 半分解 / 分解），与前景节奏错开。
6. **分三层清点**：前景 1、中景 0–2、背景 2–3；同时独立线条 ≤ 3。
7. **查音区**：低 / 中 / 高每层各 1–2 件，无两件乐器同音区同节奏。
8. **画进出表**：每件乐器写明"第几小节进、第几小节出"，禁止任何轨常驻。
9. **做减法**：逐轨静音，删掉"静音不变差"的轨；再确认全曲有 1 处近静默、最厚点前有一个减薄段。
10. **做 A/B**：稀疏版与密集版隔天盲听；仍平手**选层数少的**。此后才交给混音，不再回改编曲。（第 4 步 70/30 为业界经验【T5】，其余为本文件归纳规则，落点见 §2–§9、§15。）
