# 可复用和弦进行库

> **来源**：B 站公开教程 / 专栏 / 测评整理（采集 2026-11-11，973 条去重视频、8 个课程视频下载抽帧）。逐条来源见文末「来源索引」，学习清单见 `bilibili-study-map.md`。
> **制作口径**：默认在 DAW 里作曲编曲（MIDI + 采样音源 + 合成器 + 自动化 + 混音）；真实乐器、采样、合成器音色都是合法音色来源，不做「原声 vs 电子」的出身审查。
> **范围分流**：不默认做吵闹的电子舞曲风格（EDM / House / Techno / Trap / Dubstep / 鼓机 drop / riser / 泵感侧链 / supersaw lead），这类内容单独收在 `references/electronic-styles.md`，主线不混。
> **主用途**：情绪驱动 + 场景感双轴 + 钢琴 / 小提琴 / 手风琴三件套；合成器在这里是色彩与空间层（pad / bell / soft lead / 铺底），不是舞曲骨架。
> **用法**：数值是起点不是法则，以耳朵为准；与本技能既有硬规则冲突时，以技能规则为准。
> **情绪驱动**：按情绪查配方 `emotion-arrangement-recipes.md`、按情绪查和弦 `emotion-chord-index.md`、钢琴/小提琴/手风琴写法 `core-instruments.md`。
> **标注**：【源】/【事实】= 可核实；【验】= 交叉验证；【经验】/【通用理论补充】= 惯例或未单条核实，可放心改。

### 0.2 一条通用声部纪律（贯穿全册，【经验】）

1. 相邻和弦**保留共同音不动**，其余声部走级进（≤2 半音）；低音可跳四/五度。
2. 转位优先让 **bass 成级进线条**（如 C–G/B–Am 的 `C–B–A`），不要用清一色原位和弦硬砸。
3. 重复音优先顺序：**根音 > 五音 > 三音/tension**；低音区音与音之间拉开距离，别把三音或延伸音塞进低音区。
4. pad 超过 5 音易浑浊，2–3 音更通透；120 Hz 以下保持 mono（`arrangement.md §3/§4`）。
5. 和弦起音错开 **5–30 ms** 做 strum，力度按 `workflow.md §4.1` 浮动 ±10–20，别全 127。

## 3. 一个平淡进行变高级：12 种改写手法

> 输入统一取最平的 `C–Am–F–G`（§1.2）。**每种给具体改动、MIDI 数值或顺序**，可叠加但一次别超过 3 种。

| # | 手法 | 怎么改（可执行） | 数值 / 顺序 | 坑 |
|---|---|---|---|---|
| 1 | 加七 | 三和弦→七和弦：`Cmaj7–Am7–Fmaj7–G7` | `60/64/67/71 → 57/60/64/67 → 53/57/60/64 → 55/59/62/65` | 别全曲突然只加一个，色彩不统一会"迷惑" |
| 2 | 加九 / add9 | `C→Cadd9`、`F→Fadd9`；或 `sus2` `Csus2=60/62/67` | add9 保留三音（有大小调色彩），sus2 替换三音（中性） | 9 音与旋律成小二度时删掉 |
| 3 | sus4 延迟解决 | `G→Gsus4→G`（`55/60/62/67 → 55/59/62/67`），C 音延留半拍再落 B | 延留 1/2–1 拍，落回在弱拍 | sus4 不解决就一直悬着，别挂在句尾 |
| 4 | 转位 / 分数和弦 | `C–G/B–Am–Am/G–F`，低音走 `C–B–A–A–G` | `G/B = B3 D4 G4 = 59/62/67`；`F/G`、`Dm7/G` 软化终止 | 低音区别塞三音/tension；重复音优先根音>五音 |
| 5 | 延伸音 | `Dm9=62/65/69/72/76`、`G13=55/59/62/65/69/76`；自然延伸音解决到大和弦、变化延伸音 `b9/b13` 解决到小和弦 | 先给 9th，11/13 单独加易被听成 sus4/六和弦 | 突然堆大量 tension 会糊，保持全曲一致性 |
| 6 | 延迟解决 | 该落的 `G7→C` 先插 `Gsus4` 或 `Am7`，把 C 推后 1–2 拍 | 强拍留悬、弱拍落地 | 延迟超过 1 小节会失去"回家"参照 |
| 7 | 切分 / 抢拍 | 下一个和弦提前到前一拍的 "and"（第 4 拍后半）触发 | 提前 1/8 或 1/16；bass 骨架仍对齐网格 | 只有和弦/comping 抢拍，bass 与鼓别一起抢 |
| 8 | 和弦外音 | 加经过音/倚音/辅助音/先现音；延留音"同音连线预备→级进下行解决" | 经过音落弱拍八分位；长音与乐句末音必须是和弦音 | 调外音=0；末音落外音是最常见翻车（`melody-revision.md §4`） |
| 9 | pedal point | 整段踩低音 C(48) 或 G(43)，上方跑 `C–F/C–G/C–C` | 持续 2–8 小节，结尾必须解决 | 撑太久不解决变单调；上方和弦要偶尔不含持续音 |
| 10 | 副属 / 分割属七 | `C–Am–F–G` → `C–E7–Am–A7–Dm–D7–G7–C` | 每个非主和弦前插它的 V7；`V7–I` 前插 `iim7` 变 `ii–V–I` | 旋律与副属 3/7 音撞小二度时不用 |
| 11 | 借用和弦 / 四度叠置 | `F→Fm`（`57→56` 半音），或插一个四度叠置 `C–F–Bb = 60/65/70` | 半音线条 `A→Ab→G` 放同一声部暴露 | 借用和弦是"香料"不是主菜，一段一个足够 |
| 12 | 同功能替代 / 恒定结构 | 同功能组互换：主 `C↔Am↔Em`、下属 `F↔Dm↔Am`、属 `G↔Em↔Bdim`（有 ≥2 共同音即可替）；重复 2 小节以上就换 | 见 `cv4901915` 共同音替代表 | 替代后别丢 bass 线条的方向 |

**推荐叠加顺序（【经验】）**：先 `4 转位` 把 bass 理顺 → 再 `1/2 加七加九` 上色 → 最后 `3/6 延留` 做呼吸。三步以内最稳。
