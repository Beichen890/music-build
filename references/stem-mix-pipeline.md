# 分轨混音流水线（无 DAW / 纯脚本）

适用场景：手上只有 MIDI 或整体渲染，要用脚本做出**真正的混音+母带**（而不是把整体渲染调调 EQ）。
纯音乐/器乐出版尤其适用——分轨处理能提升的空间远大于对成品做母带。

## 1. 为什么必须分轨

对整体渲染做母带只能改音色倾向；分轨之后才能改**主次关系**，而这才是"糊"的真正原因。

实测一例：某曲主旋律被铺底 Pad 盖住 —— Pad 音域与旋律完全重叠，电平只低 2.9 dB，
局部甚至高 9.2 dB。这种问题在整体渲染上**无解**，必须动分轨电平与 EQ。

**做法**：把 MIDI 里每条轨分别渲染成独立 wav（每条轨 + 单独的 tempo track），
渲染前**关掉合成器自带的混响/合唱**（FluidSynth：`-o synth.reverb.active=0 -o synth.chorus.active=0`），
否则你会在别人加的混响上再做混响。

## 2. 先体检，再动手

必须测的四项：

| 项 | 用途 |
|---|---|
| 各轨 peak / RMS | 谁比谁差多少 dB，立刻看出主次颠倒 |
| 各轨频段能量占比 | 找"糊"的来源（能量堆在哪个八度） |
| 左右相关度 | 判断该轨本身就是单声道（可以随意摆位）还是已经立体声 |
| **高频是内容还是噪声** | 决定能不能加"空气"。对比全曲与最安静段落（如留白段）在 8k/12k/16k 的电平：两者相同 = 那是噪声底，提它就是提嘶声 |

实测一例：某曲镲片在 8k 有 −7.4 dB、16k 有 −20.8 dB（**真实内容**，可以放心 +4 dB）；
而钢琴/Pad 在 8k 的 −33/−61 dB 与自身留白段的噪声底相同（**没有内容**，加搁架收益近乎为零）。

## 3. 送混响的轨决定混响的音色

混响是"源 × IR"，所以**源里没有的东西 IR 也变不出来**。
贝斯通常不送混响、Pad 送最多 —— 结果是混响返回天然偏中频，比干声亮。
这是正常的，不要去"修正"它；但如果返回比干声亮太多（实测出现 87% 能量挤在 500–2k），
说明 IR 本身有问题（见 §5）。

## 4. 饱和（tanh）最常见的哑炮

```python
# 错：小信号落在 tanh 线性区，等于什么都没做（只是轻微增益）
y = np.tanh(x * drive) / np.tanh(drive)

# 对：先归一到峰值再饱和，谐波才真的产生
p = np.abs(x).max() + 1e-12
y = np.tanh(x / p * drive) / np.tanh(drive)
out = x * (1 - mix) + y * p * mix
```

## 5. 程序生成混响 IR 的三个坑

**① 按峰值归一会被早期反射主导** → 改按 RMS 归一。

**② 用未限带白噪声做早期反射**：白噪声 94% 的能量在 2.5 kHz 以上，
即使做了低频/高频分频，**IR 的能量仍 80% 来自高频段** —— 结果不是混响，
是一记明亮的高频拍击（实测：2-16kHz 占 IR 能量 55%，前 50 ms 占 31.5%）。
修法：**分频后各自归一**，再给高频段额外压 6–8 dB。

```python
lo = sosfilt(butter(2, 2500/(SR/2), 'low',  output='sos'), nz)
hi = sosfilt(butter(2, 2500/(SR/2), 'high', output='sos'), nz)
lo /= np.std(lo); hi /= np.std(hi)          # ← 关键，别省
ir = lo * env_slow + hi * env_fast * 0.45   # 高频衰减快 = 空气吸收
# 早期反射务必限带（4kHz 低通）+ 低电平
```

**③ 起振平滑别写成高斯**：`exp(-(t/(damp_rt/3))**2)` 这种写法会把 0.3 秒之后全乘掉，
2.8 秒的 IR 实际只剩 0.3 秒，**慢衰减的低频尾巴被切光**，只剩白噪声拍击。
用 `np.clip(t/0.002, 0, 1)` 线性淡入即可。

## 6. 声部叠奏的两种性质，别改错

改旋律/改编排前，先判断其他轨与主旋律"同位置起音"的音是什么关系：

- **完全同音高** → 通常是故意叠奏（加倍），要跟着改
- **同位置但音高不同** → 先看它是否构成**和弦三和弦**（例如旋律 A4 处 Pad 弹 A4 C5 E5，
  旋律 F4 处弹 F4 A4 C5）→ 那是**按小节和弦走的和声铺底**，由和声驱动，
  **不能跟着旋律改**，改了反而破坏和声
- **八度关系** → 多为巧合（贝斯根音、鼓的音高数值与和声无关）→ 不要动

判断依据是"**是否含该小节的和弦音**"，而不是看音高数值差。

## 7. 用客户已有的成品做音色参照

如果客户已有同曲的另一版混音，**直接量它的频段占比作为参照**，
比自己拍目标曲线靠谱。但注意：参照物本身可能有病（实测某参照在 250–500Hz 占 28%、
8k 以上只有 0.2%），要**带着判断用**——削掉堆积、补上清晰度，而不是把病复制过来。

## 8. 逐级测量定位问题

调完整体发现频段跑偏时，别猜。在每一级后面打印频段占比：

```
逐轨后 → 加混响 → 总线压缩 → 总线饱和 → 母带EQ → 分频动态 → 限幅
```

实测过两次，都一眼定位：
- "加混响后 1–2k 从 9% 跳到 29%" → 是 IR 的问题（§5）
- "母带 EQ 后 250–500 从 12% 掉到 7%" → **逐轨阶段已经清理过，母带又砍了一遍，重复处理**

**经验：低中频清理只能做一次。** 逐轨阶段动了之后，母带就只做轻微塑形。

## 9. 分频动态的陷阱

`comp(lo) + comp(hi)` 用互补滤波相加重建时，**分频点附近会发生能量重分配**
（实测 120–250 Hz 涨了 9 个百分点，因为两个带各压各的、增益不再互补）。

更稳的写法：**只对要控制的那个频段做动态，其余原样通过**：

```python
lo = sosfilt(butter(4, 160/(SR/2), 'low', output='sos'), mix, axis=0)
hi = mix - lo                       # ← 相减，保证 lo+hi == mix
mix = comp(lo, ...) + hi
```

## 10. 响度与真峰

- 用 `pyloudnorm` 测 integrated LUFS，`resample_poly(x, 4, 1)` 测真峰
- 纯器乐/钢琴曲：**−14 LUFS / 真峰 ≤ −1.0 dBTP**，动态余量（peak−RMS）14–17 dB 属正常
- 若要与客户已有版本响度对齐，另出一版（改目标 LUFS 后重新限幅即可），
  不要为了响度牺牲动态——多 1 dB 响度约等于少 1–2 dB 动态

## 11. 交付前验证清单

- [ ] 真峰 ≤ −1.0 dBTP（转 MP3/AAC 后不过冲）
- [ ] 逐级频段表没有异常跳变
- [ ] 与参照物的偏差集中在"该改的地方"，低频与超高频不应大幅偏离
- [ ] 首尾无咔哒（0.02 s 淡入）、尾音自然（按 −60 dB 处截断再 2.6 s 淡出）
- [ ] 同时给 WAV(24bit) 与 MP3
- [ ] 给客户 **A/B 片段**：同一段「旧版 → 静音 → 新版」，并**按 LUFS 对齐响度**，
      否则听者只会觉得"更响 = 更好"
