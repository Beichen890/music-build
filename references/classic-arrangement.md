# 经典编曲与配器法（传统声部写作）

> **来源**：B 站公开教程 / 专栏 / 测评整理（采集 2026-11-11，973 条去重视频、8 个课程视频下载抽帧）。逐条来源见文末「来源索引」，学习清单见 `bilibili-study-map.md`。
> **制作口径**：默认在 DAW 里作曲编曲（MIDI + 采样音源 + 合成器 + 自动化 + 混音）；真实乐器、采样、合成器音色都是合法音色来源，不做「原声 vs 电子」的出身审查。
> **范围分流**：不默认做吵闹的电子舞曲风格（EDM / House / Techno / Trap / Dubstep / 鼓机 drop / riser / 泵感侧链 / supersaw lead），这类内容单独收在 `references/electronic-styles.md`，主线不混。
> **主用途**：情绪驱动 + 场景感双轴 + 钢琴 / 小提琴 / 手风琴三件套；合成器在这里是色彩与空间层（pad / bell / soft lead / 铺底），不是舞曲骨架。
> **用法**：数值是起点不是法则，以耳朵为准；与本技能既有硬规则冲突时，以技能规则为准。
> **情绪驱动**：按情绪查配方 `emotion-arrangement-recipes.md`、按情绪查和弦 `emotion-chord-index.md`、钢琴/小提琴/手风琴写法 `core-instruments.md`。
> **标注**：【源】/【事实】= 可核实；【验】= 交叉验证；【经验】/【通用理论补充】= 惯例或未单条核实，可放心改。

## §1 总纲：配器法到底解决什么

| 要点 | 可执行结论 | 标注 |
|---|---|---|
| 定义 | 配器法又称"管弦乐法""乐器法"，解决三件事：①各乐器发声原理、音色、音量、演奏法；②乐器间的音量匹配关系；③正确选用乐器表现主题与风格 | 【源】《作曲必备的6条基础理论》cv3316595 |
| 减法原则 | 业界前辈原话："尽可能删除所有一切不必要的音符"；丰满不靠叠加音符，靠**泛音列**的应用——按每件乐器在各频段能产生的泛音来设计旋律线条 | 【源】《90%编曲新手干过的迷惑操作》cv6652896 |
| 黄金法则 | 任一时刻只有**一个**最重要的乐器占据核心频段与听感焦点，其余乐器"避让"；避让在配器阶段完成，不靠混音时削 EQ | 【验】吴颖音乐工作室《编曲中如何避免"乐器打架"》wyyyw.cn/news/7428.html |
| 边界依据 | 原文："电声乐器的发音、音色、功能特点及演奏技巧等都与传统乐器迥异，自成体系，故**传统配器法基本不适合于纯电声乐队**"——这正是本文档不收电子编曲的理由 | 【源】《作曲必备的6条基础理论》cv3316595 |

## §3 管弦乐编制表

交响乐队编制以**木管组数量或小号数量**为参照定档；改任一组数量时，为保持组间音量比不变，其他组要同步增减。下为四档完整人数：【源】栗锦文《【栗子音乐笔记】『配器法』单/双/三/四管编制》cv17584806（WebFetch 核实）

| 档位 | 木管组 | 铜管组 | 弦乐组（VI I / VI II / VAL / VC / CB） |
|---|---|---|---|
| 单管 | 长笛1 双簧管1 单簧管1 大管1 | 圆号2–3 小号1 | 10 / 8 / 6 / 4 / 2 |
| 双管 | 长笛2 双簧管2 单簧管2 大管2 | 圆号4 小号2 长号3 大号1 | 14 / 12 / 10 / 8 / 6 |
| 三管 | 2长笛+1短笛 2双簧+1英国管 2单簧+1低音单簧 2大管+1低音大管 | 圆号4–6 小号3 长号3 大号1 | 16 / 14 / 12 / 10 / 8 |
| 四管 | 3长笛+1短笛 3双簧+1英国管 3单簧+1低音单簧 3大管+1低音大管 | 圆号4–6 小号4 长号3 大号1 | 18 / 16 / 14 / 12 / 10 |

**流行 / 录音弦乐的灵活编制**（不必套标准管弦编制）：`86442` = 一提8 / 二提6 / 中提4 / 大提4 / 低音提2；`64221` = 6/4/2/2/1；`6422` = 去掉低音提琴；`1111` = 弦乐四重奏；`2222` = 双四重奏。**人数决定音响**：同样一条旋律，1 人、2 人、10 人演奏声音不同；要宏大就加人，要轻盈细腻就减人，据此去选音源。【源】《【编曲】弦乐的编曲配置和声相定位》bilibili.com/read/mobile/15114990

**五声部角色分工**：一提 = 主旋律；二提 = 旋律转换 + 更丰富的和声配合；中提 = 高音与低音区之间的衔接；大提 = 人声般音色，也广泛用于旋律声部；低音提琴 = 和声支撑 + 节奏控制，为全团打根基。【源】《GYSO弦乐声部Q&A》bilibili.com/read/mobile/10680414

**音量平衡原理**：从小提琴到低音提琴体积增大、响度提高，因此**靠增加高音乐器数量来平衡**（标准另一套人数：一提16–18 / 二提14–16 / 中提10–12 / 大提10–12 / 低音提8–10；或 14/12/10/8/6）。【验】百度百科「弦乐」、【源】音律屋《「理论」管弦乐由哪些乐器组成》
**声相**：常见摆位把一提放最左、大提 / 低音提放右侧，符合舞台摆位，但听感上小提琴会过于靠左、略偏沉——可按需要收窄声像。【源】bilibili.com/read/mobile/15114990

## §4 木管与铜管的写法

| 结论 | 数值 / 顺序 | 出处 |
|---|---|---|
| 乐器性格表 | 小号 = 铜管组最高、明亮尖锐、仪式感，弱音器增神秘感，爵士中用法丰富；圆号 = 最难演奏易"冒泡"，3 米管道 / 4 个八度 / 十多个自然泛音；长号 = 唯一滑管乐器；大管 = 木管组低音；双簧管自亨德尔起成独奏性乐器；单簧管由 2 键改革到 6 键 | 【源】《"配角"乐器也能C位出道》cv3337760 |
| 影视织体模板 | 「高音持续 + 很 dark / holy 的铜管上下对比」，参考雅尼《Santorini》与 BrandXMusic《Battle for dawn》；此处理配一个四级和弦很有味道 | 【源】《商业宣传片中的管弦配乐是怎样写成的》BV1UU4y1e7CP |
| 过渡段写法 | 用长笛 + 短笛以极快速度"划奏"做过渡，比硬怼滚镲好 | 【源】BV1UU4y1e7CP |
| 利底亚色彩 | 突出 4 音、考虑 4→7 的连接；在大调基础上借中古调式特征和弦 / 特征音程增色，不做纯中古（风格化过强不适合商业配乐） | 【源】BV1UU4y1e7CP |
| 呼吸段 / 动态 | 第二段前留一大段"呼吸空间"适合升调；需要对比时把动态幅度做大；铜管高力度下的震颤可用高通 EQ 凸显 | 【源】BV1UU4y1e7CP |
| 固定音型 | Ostinato（固定音型）承担"让人记住"的功能；若全曲无大段重复又不旋律驱动，会听完记不住 | 【源】BV1UU4y1e7CP |
| 配器表清单范式 | 按组罗列：木管（1短笛 2长笛 2双簧 2单簧 2大管 + 哨笛 / 爱尔兰长笛 / 肘风笛）、铜管（4圆号 3小号 2长号 1低音长号 1大号）、有音高打击（木琴 / 管钟 / 康特勒琴 / 匈牙利扬琴 / 定音鼓）、无音高打击、按键（钢琴 / 竖琴）、按弦、人声、弦乐（一二中大低 + Fiddle） | 【源】《HOYO-MiX 的顶级配乐思维？雪浪驰逐管弦乐扒谱》BV1bGaZzGEnQ |

**音色叠置三组合**（按发声方式分弹拨 / 拉弦 / 吹管后再组合）：弹拨 + 拉弦 = 音色自然、音量相当；吹管 + 拉弦 = 旋律强有力；吹管 + 拉弦 + 弹拨 = 音色协调、音响坚实圆润丰满。【源】音律屋《关于和声、流行、摇滚编配的心得分享》cv20292333

## §5 弦乐组写法

| 结论 | 可执行顺序 / 数值 | 出处 |
|---|---|---|
| 编写顺序 | ①先用长音做和声填充内声部（最基础，但通篇如此会呆板）→ ②写副旋律，**不得干扰主旋律**否则喧宾夺主 → ③做到与主旋律前呼后应、相辅相成、声部平稳流畅丰满 → ④熟练后加入复调对位增加推动力 | 【源】音律屋 cv20292333 |
| 副旋律 5 条 | ①必须符合目标乐句情绪；②除要强调的那段外尽量不做变化；③副旋律要像"一首歌"，不只是和弦音连接；④一小节内别太多相同律动（如第 2–3 小节在第四拍加连接音，避免四拍长音无聊）；⑤反向 / 同向 / 平行三度 / 六度都可用但要布局、不要无限撑；偶尔留白偶尔增量 | 【验】紫藤音乐书店《流行歌曲的「弦樂副旋律」如何編寫》、【源】B 站示范 BV1tS4y1B7h8 |
| 两部写作注意 | 写 Vln.1 + Vln.2 时不要套"四部概念"追问下方为何不是根音——其他乐器会补；两声部都要是优美旋律，且进行时是优美和声关系；试听时可把弦乐整体提高八度 | 【验】紫藤音乐书店（同上） |
| 分部与叠置 | 一提 / 二提可齐奏使声音混厚、提升响度；中提常与一提或大提做旋律叠奏，一提奏主旋律时中提可奏副旋律；低音提琴多在低八度重复大提琴 | 【验】音律屋《管弦乐由哪些乐器组成》、百度百科「弦乐」 |
| 演奏法清单 | 连弓 Legato（抒情）、顿弓 Staccato、跳弓 Spiccato、重断弓 Marcato、颤弓 Tremolo、颤音 Trill、拨奏 Pizzicato；编写时"缓急"搭配——温柔舒缓旋律 + 速度感节奏性乐句，才均衡 | 【验】百度百科「弦乐」、【源】bilibili.com/read/mobile/15114990 |
| 音区让位实例 | 和声层与管乐层若都在高声部且音区接近，必须做区分与取舍：第一段主歌乐队薄、小提琴旋律是主角时，**主旋的和声优先于编曲加花旋律**；第二段层次更丰富时，**乐器声部优先于和声层**；音区间隔小、音色区别小时靠不同触键区分声部 | 【源】《用价值千万乐器演奏华晨宇〈小镇里的花〉》BV1jw4m1Q7Yk |
| 复调推动实例 | 第二遍副歌内声部保留第一遍副歌的音高节奏，上层加入小号旋律与主旋律形成复调，在主旋律基本相同的前提下增加推动力与渲染力 | 【源】BV1jw4m1Q7Yk |
| 六阶段课程顺序 | ①和弦设计（和声进行）→ ②即兴旋律创作（副旋律）→ ③对位旋律创作 → ④四重奏编写 → ⑤木管 / 铜管 / 打击乐应用 → ⑥配乐练习 | 【验】紫藤音乐书店（同上） |

## §6 流行乐队四大件分工

四大件 = **钢琴、吉他、Bass、鼓**（流行 / 民谣基础编制；摇滚在此基础上加电吉他）。【源】《看完这个视频你就会编6/8拍的流行和民谣歌曲了》BV1qc9gYhECr

| 声部 | 频段 / 音区 | 职责 | 编写要点 | 出处 |
|---|---|---|---|---|
| 鼓 | 底鼓 20–120Hz；军鼓 / 通鼓 800Hz–4kHz；镲片 4kHz 以上 | 律动骨架、强弱与段落转折 | 军鼓节奏基本固定，底鼓可不间断切分增加摇滚感；主歌用典型拍型，最后一次副歌加掉镲与停顿同步切 | 【验】吴颖 7428、【源】cv20292333、BV1qc9gYhECr |
| Bass | 20–120Hz（与底鼓重叠区，须避让） | 低音声部、和声地基、与鼓共同决定曲风 | 定弦 `E A D G`（比吉他后四弦低一个八度）；**先配好四部和声与鼓节奏，再跟着四部和声低声部画根音**；重音跟底鼓或走底鼓间隙；一般弹根音，特殊时弹五音 / 三音制造不协和情感；音太高或太低都不自然 | 【源】《6-3编曲（流行曲四大件——贝斯）》bilibili.com/read/mobile?id=67320 |
| 吉他 / 键盘 | 节奏吉他 / 钢琴左手 200–800Hz；中高频到 4kHz | 和声支撑、织体填充 | 钢琴负责中低音区和弦、吉他负责中高音分解，两者频段错开不打架；钢琴可弹和弦转位避开人声主频段 | 【验】吴颖 7428、【验】今日头条《编曲配器基础》 |
| 人声 / 主奏 | 800Hz–4kHz | 清晰度与临场感、听感焦点 | 编曲永远服务人声；顶层旋律乐器只在换气、间奏出现 | 【验】吴颖 7428、今日头条（同上） |

**频段让位表**（配器阶段就划定活动区间，不依赖混音 EQ）：`20–120Hz` 底鼓 / 贝斯（地基）→ `200–800Hz` 节奏吉他 / 钢琴左手 / 中频弦乐（和声支撑）→ `800Hz–4kHz` 人声 / 主奏 / 军鼓 / 通鼓（清晰度）→ `4kHz 以上` 镲片 / 高频打击 / 空气声（光泽空间）。**具体雷区**：贝斯与底鼓若都在 `60–100Hz` 发力，低端必然浑浊。【验】吴颖 7428

**四类"打架"维度**（逐一排查）：频率重叠、动态冲突、声像拥挤、节奏功能重复（如钢琴和吉他弹相同切分音符）。避让三法：①频段避让（上表）；②动态避让——长音"定住"和声、短音出颗粒感，弦乐拉长音 + 钢琴轻快断奏 = 动静结合；两长音并用时主奏强奏、背景自动降动态；③声像避让——编曲阶段就规划左右，全挤中央会"堵"。【验】吴颖 7428

**摇滚 / 重金属 / 迷幻摇滚配器要点**：传统摇滚用双吉他（木吉他扫弦 + 电吉他在二、四拍弱拍奏和弦改变重音），Bass 用力度强的 Peak Bass 基本与底鼓一致强化强拍；重金属 Bass 厚重、失真吉他偏重低音区、两把失真吉他作和声乐器扫弦与长音结合、注重音色的颗粒感铺满低声部层；迷幻摇滚两把清音吉他柱式节奏互补、声像一左一右，Bass 用柔和指弹与底鼓一致。**通则：强拍尽量用协和音程，不协和音程放在弱拍过渡处**。【源】音律屋 cv20292333

**真实乐队编制范例（9 人）**：Vocal、钢琴、电吉他、木吉他、小提琴、大提琴、架子鼓、贝斯 + 编曲/混音。这是"四大件 + 弦乐色彩"的落地形态。【源】沫音座_offcial《【最全编制】全站首发〈Avid〉Hi-res 超高品质乐队翻奏》BV1bps6e2Eep（编曲 Kalyoile，WebFetch 核实）

## §7 织体类型：单声 / 主调 / 复调 / 支声

| 类型 | 定义 | 判别与写法 | 出处 |
|---|---|---|---|
| 单声织体 | 全曲只有一个声部 | 多人齐唱同一旋律**仍是单声织体**（如格里高利圣咏、无伴奏二胡独奏《二泉映月》） | 【源】《圣咏的旋律被称为定旋律》cv21454285、【验】360 百科「织体」 |
| 主调织体 | 若干声部明显分出主要旋律 + 伴奏声部 | 其余声部处于相对伴奏地位；合唱"音层式写法"（女高与女低在同样和声背景上用完全相同节奏型）突出主调性 | 【验】360 百科、【源】《音乐的主调性与复调性分析》cv25426225 |
| 复调织体 | 两条以上各自独立的旋律同时结合，地位平等 | 分**对比式**（不同旋律叠置）与**模仿式**（同旋律隔一、两拍先后追逐）；卡农可相隔两拍严格模仿；赋格 = 主题 + 对题，主题在不同声部轮流出现 | 【验】360 百科、【源】cv25426225、《诸律的谐奏》BV17w411271V |
| 支声（heterophony） | 同一基本旋律的**不同变体**同时展开，声部"时而分离为多声、时而汇合为单声" | 见下方专项 | 【验】百度百科「支声音乐」、中文百科《支聲復調》、单词鸭 heterophony |

**四类并列关系**：支声复调与单音音乐、对比复调、主调音乐共同构成多声织体四大基本类型；支声常归入复调，但**更重声部的横向关系**。【验】中文百科《支聲復調》newton.com.tw
**主调性 / 复调性是对立统一**：复调化织体里也有相对主要的旋律，主调化织体里也隐伏复调层；**节拍异质性越大，该旋律的复调性越强**。【源】cv25426225
**早期复调数值**：公元 9 世纪奥尔加农（Organum）——在圣咏（定旋律）上方或下方加一条**平行四度或五度**的旋律线；后续变体允许新增旋律自由变化或与圣咏反向进行。【源】cv21454285

**支声专项（中国风 / 民乐合奏核心）**——三种写法：①分支声部与主要曲调节奏、骨干音相同，仅作音调变化；②作为主要曲调的**加花装饰**，围绕主曲调作华彩；③作为**简化形式**，只奏大致轮廓、省去细节。【验】百度百科「支声音乐」
江南丝竹四条可执行规则（写成数值化对照）：【验】华音网《江南丝竹即兴演奏探索》、单词鸭《中花六板》案例
- **你繁我简**：声部 A 旋律复杂 / 节奏密集 / 强弱起伏多，声部 B 平稳简洁、节奏流畅，突出 A 的华彩即兴。
- **你高我低**：声部 A 走高音区，声部 B 走中低音区，音区 + 音色双向对比。
- **嵌挡让路（抢挡）**：A 加花装饰时，B 用简化旋律或空拍让路衬托 A。
- **加花减字**：以"母曲"骨干音为基础，加花扩充、减字缩减；即兴建立在既定"板位 / 板眼"结构上。项祖华总结为"大集体中有小自由的灵活性"（大集体 = 整体结构与骨干音，小自由 = 个人即兴）。

## §8 四部和声连接规则

**四个声部**：高音（女高 / 旋律声部）、中音（女低）、次中音（男高）、低音（男低）。上三部 = 高/中/次中；外声部 = 高 + 低；内声部 = 中 + 次中。音域见 §2。【源】《4-1和声（四部和声法则、和声排列法）》cv22767

| 规则 | 数值 / 判定 | 出处 |
|---|---|---|
| 重复音优先级 | I / IV / V **重复根音最好 > 其次五音 > 尽量不重复三音**；ii / iii / vi 可重复三音（三音为 4、5、1，称"优级音"）；**不重复导音**（大调 7、小调 ♯5）。三和弦只有 3 个音，做四部和声必重复 1 个音 | 【源】cv22767 |
| 密集排列 | 上三部每相邻两部相隔 **3 度或 4 度**（不能低于 3 度、不能高于 4 度）；听感较狭窄；旋律位置有密根 / 密三 / 密五 | 【源】cv22767、《古典四部和声必学知识》cv6433812 |
| 开放排列 | 上三部每相邻两部相隔 **5 度或 6 度**（另一说"五度以上含五度"）；听感宽广；开根 / 开三 / 开五 | 【源】cv22767、cv6433812 |
| 低音与次中音 | 距离**不受排列法限制**，可从同度到两个八度（有时更远） | 【源】cv22767 |
| 超开放排列（避免） | 上三部相邻声部音程 **超过八度**，或次中音与低音 **超过十五度** → 音响散、不平衡 | 【验】中音在线《四部和声写作教学的几点思考（二）》 |
| 和声连接法 | 两和弦有共同音时，**把共同音保持在同一声部** | 【源】cv6433812 |
| 旋律连接法 | 共同音不在同一声部、或两和弦无共同音时使用 | 【源】cv6433812 |
| 声部进行 | 各声部尽量**级进**、避免大跳；导音（VII）倾向进行到主音（I） | 【验】tsight.io、好和弦 nicechord.com |
| 和声进行 | 正格进行 `V→I`（D→T，最强终止式）；变格进行 `IV→I`（S→T）；总规律"稳定→不稳定→稳定" | 【源】cv6433812 |

**禁忌清单**（逐条排查，附例外）：【源】cv22767、cv6433812、【验】好和弦 nicechord.com/post/four-part-harmony-101/、中音在线

| 禁忌 | 判定 | 允许的例外 |
|---|---|---|
| 平行八度 / 平行五度 | 同样两个声部连续出现完全八度 / 五度 | 同度或八度的同音反复例外；减五度→纯五度一般也避免 |
| 四部同向 | 连续两和弦四个音全往上或全往下 | 至少一个声部持平或反向即可 |
| 声部交越 / 超越 | 连接时某声部跨过前一和弦相邻声部的音域 | 无，需重排 |
| 声部交错 | 纵向排列上下方声部高于上方声部 | 无 |
| 隐伏八度 / 五度 | **两外声部同向进入完全八 / 五度，且高声部跳进 ≥ 3 度**（两个条件须同时满足） | 上声部级进时可用；发生在内声部可用 |
| 反向八度 / 五度 | 与平行无质的区别，同样避免 | **终止处可用反向八度**表示力量感 / 圆满终止 |

**正误示例**：`C G E C → D A F D` 同时犯平行五度（C-G）与平行八度（C-C）；改成 `C G E C → D F D A` 即合规。【验】好和弦（同上）

## §9 密度与音区分配、段落配器模板

**分层写入顺序（由底层到顶层）**：①鼓 + 贝斯搭律动骨架 → ②钢琴 / 吉他填和声底色 → ③弦乐等拉情绪 → ④细碎点缀。**硬性规则：点缀乐器不能持续长段出现，只做短暂填充**，否则打乱主次。【验】今日头条《编曲配器基础：从粗糙 Demo 到完整商业成品》

| 段落 | 鼓 | 贝斯 | 和声层（钢琴 / 吉他） | 顶层（弦乐 / 主奏） | 出处 |
|---|---|---|---|---|---|
| 主歌 1 | 轻 / 典型拍型 | 只弹根音 | 分解和弦、音符稀疏 | 仅长音铺垫或留空 | 【验】吴颖 7636、今日头条 |
| 主歌 2 | 稍加密 | 根音 + 少量过渡 | 加入闷音 / 拍和，比主歌 1 稍密 | 少量点缀 | 【源】《MW〈追赶春天〉片尾曲分析》cv20141238 |
| 预副歌 | **再次安静下来**（反衬） | 简化 | 收薄 | 可加二重唱和音增加层次 | 【源】cv20141238 |
| 副歌 1 | 简单清晰、无太多花色 | 与底鼓一致 | 柱式和弦加厚 | 跟进铺垫、弦乐齐奏 | 【源】BV1qc9gYhECr、cv20141238 |
| 副歌 2 / 最后副歌 | 火力全开、掉镲增加、停顿同步切 | 和弦切换前加快音符 | 钢琴 8 度、电吉他同旋律 | Solo / 小提琴渐强 / 全体齐奏 | 【源】BV1bps6e2Eep、BV1qc9gYhECr |
| 桥段 | 抽掉部分鼓组只留底鼓，制造空灵感后逐步回升 | 音量压低 | 高音区单音点缀 | 小提琴高音线条制造转折 | 【验】今日头条 |
| 尾段 | 全改 open hihat 抒发尾声 | — | 拨弦改扫弦 | 全体齐奏后，人声最后一音**全体戛然而止**；或安静结束重复间奏 | 【源】BV1bps6e2Eep、BV1qc9gYhECr |

**完整逐段模板（《Avid》乐队翻奏，最值得照抄的一条）**：慢速副歌前奏"钢琴 + 弦乐"开场 → 主歌 1 沿用纯钢琴，由电吉他 + 大提琴带入副歌 → 副歌 1 把木吉他改为电吉他，同时引入 bass 与架子鼓 → 主歌 2 把鼓点改为**传统架子鼓**，随人声引入电吉他与木吉他，木吉他用快速闷音提升律动 → 副歌 2 架子鼓用 close/open hihat 交错带动律动，bass 在和弦切换前用快速音符提律动；**故意先不引入大提琴，把厚重低音留到后面以保留情绪提升空间** → 后段引入大提琴低音 + 钢琴 8 度 + 电吉他与钢琴一致旋律 → 小提琴渐强引入收尾 → 尾段全改 open hihat → 全体齐奏 → 电吉他拨弦改扫弦 → 人声最后一音全体戛然而止。【源】沫音座_offcial BV1bps6e2Eep

**段落对比铁律**：主歌少 / 副歌多，主歌松 / 副歌紧，主歌安静 / 副歌爆发；没有对比就没有高潮。乐器应"进进出出"、带入能量、不断制造转折，即便细微变化也能带来新意；编曲的本质就是**对每个段落中配器的甄选**，先挑出全曲最重要的 1–2 个元素让听者始终关注。【验】吴颖《新手编曲常见的7个误区》wyyyw.cn/news/7636.html；【源】Waves《分解音乐制作6个阶段》cv6143503（仅取段落编排原则）

**音区分配一句话**：贝斯低频、钢琴中低频、人声中频、吉他中高频、镲片高频，每件乐器有自己的地盘，不要都挤在中央 C 附近。【验】吴颖 7636
**呼吸空间**：第二段前留一大段呼吸空间，很适合升调，很多曲子采用此处理。【源】BV1UU4y1e7CP

**风格数值**：Swing Feel = 音符长短对比 + 重音错位。Big Band 1910 年代初起源、1940 年代初 Swing 最流行时主导市场。【源】bilibili.com/read/mobile?id=18281573
**两大范式**：Duke Ellington = "Jungle Sound" 铜管 Wah-Wah 音效、为明星乐手量身定做、受录音技术限制成"三分钟曲式大师"；Count Basie = 简单轻快的 Riffs、浓郁 Blues 色彩、节奏声部占主导，核心只有 Swing。【源】同上
**写法**：按每声部音色特点分配旋律与和声任务，用萨克斯组与铜管组**交替演奏**形成音色对比，用和声叠加制造恢弘；在编曲预留段落给小号 / 萨克斯独奏即兴。【验】单词鸭 bigband

## §13 一条可复用的编写顺序（SOP，全部带数值）

1. **定编制**：从 §3 选单 / 双 / 三 / 四管（如双管 = 木管各 2、圆号 4、弦乐 14/12/10/8/6），或选四大件（钢琴 / 吉他 / Bass / 鼓）、Big Band（5 萨克斯 + 4 小号 + 4 长号 + 节奏组）、民乐编制（§10）。
2. **写四部和声骨架**：按 §8 重复根音、选定密集（相邻 3–4 度）或开放（相邻 5–6 度）排列，逐条排查 6 类禁忌。
3. **定织体类型**：单声 / 主调 / 复调 / 支声四选一（§7）；民乐合奏默认支声并按"你繁我简、你高我低、嵌挡让路、加花减字"分配。
4. **按频段表分音区**：20–120 / 200–800 / 800Hz–4kHz / 4kHz 以上四段各自归位；避开贝斯与底鼓同在 60–100Hz 发力。
5. **动态避让**：长音 + 短音互补；两长音并用时主奏强奏、背景降动态。
6. **排声像**：编曲阶段规划左右；弦乐按舞台摆位但可收窄避免一提过左。
7. **段落密度分层**：按 §9 表从主歌 1 → 主歌 2 → 预副歌 → 副歌 → 桥段 → 尾段逐段增减；留呼吸空间给升调。
8. **点缀 + 留白**：点缀乐器只做短暂填充；顶层旋律乐器只在换气、间奏出现。
9. **三遍检查**：整体 / 频率平衡 / 不同设备，再导出。
10. **能力建设顺序**：和弦设计 → 副旋律 → 对位 → 四重奏 → 木管铜管打击 → 配乐练习（§5 六阶段）。
