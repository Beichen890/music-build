# 情绪 × 场景感 组合矩阵

> **来源**：B 站公开教程 / 专栏 / 测评整理（采集 2026-11-11，973 条去重视频、8 个课程视频下载抽帧）。逐条来源见文末「来源索引」，学习清单见 `bilibili-study-map.md`。
> **制作口径**：默认在 DAW 里作曲编曲（MIDI + 采样音源 + 合成器 + 自动化 + 混音）；真实乐器、采样、合成器音色都是合法音色来源，不做「原声 vs 电子」的出身审查。
> **范围分流**：不默认做吵闹的电子舞曲风格（EDM / House / Techno / Trap / Dubstep / 鼓机 drop / riser / 泵感侧链 / supersaw lead），这类内容单独收在 `references/electronic-styles.md`，主线不混。
> **主用途**：情绪驱动 + 场景感双轴 + 钢琴 / 小提琴 / 手风琴三件套；合成器在这里是色彩与空间层（pad / bell / soft lead / 铺底），不是舞曲骨架。
> **用法**：数值是起点不是法则，以耳朵为准；与本技能既有硬规则冲突时，以技能规则为准。
> **情绪驱动**：按情绪查配方 `emotion-arrangement-recipes.md`、按情绪查和弦 `emotion-chord-index.md`、钢琴/小提琴/手风琴写法 `core-instruments.md`。
> **标注**：【源】/【事实】= 可核实；【验】= 交叉验证；【经验】/【通用理论补充】= 惯例或未单条核实，可放心改。

## 0. 两条轴怎么接 + 符号 + 裁决规则

| 轴 | 管什么 | 从哪查 |
|---|---|---|
| **情绪轴**（12 类，行） | 效价/唤醒 → **调式、BPM、和弦进行、弧线位置、终止式、力度峰值** | `emotion-arrangement-recipes.md` §1 速查 / 卡 01–12；`emotion-chord-index.md` §1 |
| **场景感轴**（12 类，列） | **音区中心、RT60/pre-delay、HPF、8–12kHz 亮度、织体层数、留白** | 本文件 §1 质感轴表（+ `scene-texture-recipes.md`） |

- **一句话裁决**：**情绪定调式与弧线，场景感定音区与空间**。效价→调式、唤醒→BPM；想调「痛不痛」动调式，想调「激不激动」动速度，别搞反【事实，`emotional-expression.md` §2.1】。**感层只动六杠杆（①音区分布 ②织体 ③和声色彩 ④空间 ⑤动态 ⑥时间形状）、不改调式与 BPM**（`15-scene-texture.md` §2）；本文件 §1 表内出现的调式名与级数只标「与该情绪组合时的典型搭配」，不构成感层定义。
- **冲突优先级**：① 调式/BPM/和弦/终止式 **以情绪为准**（改了就不是那个情绪）；② 音区/混响/亮度/HPF/留白 **以场景感为准**；③ 力度曲线与层数 **取交集**，冲突时先保「高潮全曲只 1 次」【事实，`emotional-expression.md` §5.2】；④ **不要把两者各让一半，那会两个都不像**——例「悲伤 × 童真」冲突，保留小调与下行弧线（情绪优先），把童真只放在某一段的音区/断奏/短混响上（质感为辅），或改成「怀念 × 童真」。
- **符号**：`◎` 高频强组合（直接抄）｜`○` 可用（照常写）｜`△` 慎用（须改 1 个参数）｜`—` 冲突（不要硬凑，换相邻档或只放在 8 小节 Intro/Outro 做对照段）。每个 `△`/`—` 的一句原因见 §2.2。

## 1. 场景感（12 类）质感轴定义表

> **数值以 `15-scene-texture.md` Sxx 卡为准**（本表已按其 §4 相邻感判据对齐 3 个硬冲突）；全部【经验·通用理论补充】，是起点、以耳朵为准。六杠杆统一命名：**①音区分布 ②织体 ③和声色彩 ④空间 ⑤动态 ⑥时间形状**（15 号 §2）。`密度` 为每小节音符数（4/4 计）。
> **口径 A（调式 / 和弦级数 / 终止式归情绪层）**：感层只动六杠杆、不改调式与 BPM；「③和声色彩」列只给**和弦类型 / 注册 / 和声节奏**（如 maj7 挂留、增三、每几小节换），列中的调式名、级数与终止式仅是「与该情绪组合时的典型搭配」，不构成感层定义。这三项对应 `11-emotion-recipes.md` §2 映射表第 1（调式）/ 第 2（和声复杂度）/ 第 12（终止式）项与每张卡的和弦骨架，一律由情绪层 `emotion-arrangement-recipes.md` 卡 01–15 定；感层写「常与 a 小调搭配」没问题，写成「感的定义」就会和 11 号冲突。
> **口径 B（「织体密度」两义拆开，归感层与归情绪层不冲突）**：① **归感层**的是单点/单场景的「织体质感厚度」——某一感下音色层数手感、音区占用、疏密手感、时间形状，是**质感描述、不是全曲预算**；② **归情绪层且不可被覆盖**的是**全曲密度曲线预算**＝Intro/Verse/Build/Climax/Outro 各段的 `层/件/每小节音符数` 及其增减序列（每卡「织体/密度曲线」表 + `11-emotion-recipes.md` §2 映射表第 6/7 项），它绑定**段落弧线的小节结构**、是情绪起承转合的硬约束。**统一句（与 `15-scene-texture.md` §2 字面一致）**：卡内层数/每小节音符数是该感的织体质感典型值，全曲密度曲线预算以情绪层为准；感层可以描述某段「听起来厚/薄」，但**不要改写这段的层件数与音/小节数字**。
> **引用格式**：15 号无独立「感→和弦」条目编号，引用写「`15-scene-texture.md` Sxx 卡 ③和声色彩」；具体和弦实体回查 `chord-library.md` / `13-emotion-chord-index.md`。速查表在 15 号 §1、相邻感判据在 §4、叠加 4 步在 §2。`亮度 8–12kHz` 一列是本文件补充（15 号仅 S01 失败模式与 S11 明确给），属补充不冲突、保留。

### 2.2 每个 △ / — 的一句原因（37 条，全）

| 坐标 | 符 | 一句原因 |
|---|---|---|
| 含蓄×宏大 | △ | 含蓄「只撤不推」，宏大要逐级加到全奏；要「悲壮」请改用崩溃档。 |
| 含蓄×黎明 | △ | 黎明必须音区逐级抬升，含蓄弧线只下行不抬；须破例允许一次抬升。 |
| 含蓄×童真 | — | 效价/唤醒/奏法三项全反（级进连奏 vs 跳进断奏）；童真的方整 2+2 小节与大调 I–V 会抵消「压抑不说破」。 |
| 崩溃×梦幻 | — | 崩溃要贴脸强揉弦+短混响，梦幻要远场弱奏+长尾，空间与力度双反。 |
| 崩溃×空灵 | △ | 空灵 1 层 pp 削低频，崩溃 5–6 层 ff 八度低音；只可作宣泄后的回落 8 小节。 |
| 崩溃×压抑 | △ | 崩溃要 ff 释放，压抑锁 mp 不解决；压抑只能是崩溃前 8–16 小节的 Build。 |
| 崩溃×童真 | — | 效价与唤醒双反，且断奏/连奏相反。 |
| 宏大×空灵 | △ | 宏大满编全频，空灵 1 层削低频；只可作 Intro 单音 drone 的前 8 小节。 |
| 宏大×压抑 | — | 宏大 12–18dB 渐强到 ff，压抑锁 mp 只加层不加量，动态曲线正相反；压抑要窄音域 ≤1 八度、宏大要 ≥5 八度，两个杠杆互相拆台。 |
| 怀念×宏大 | △ | 怀念 3/4 近场 4 层，宏大 4/4 大厅 6–8 层；须换拍号并扩编制。 |
| 孤独×宏大 | — | 孤独 2 层 pp 自然消散，宏大 6 层 ff 全奏；层数/力度/结尾三冲突，4–6 层齐奏会填掉孤独赖以成立的留白。 |
| 孤独×压抑 | △ | 孤独忌规律 pulse，压抑靠十六分 ostinato；一加固定音型就「有人陪」了。 |
| 孤独×童真 | — | 效价相反，且孤独结尾只减不加、童真要干净收。 |
| 孤独×黎明 | △ | 孤独结尾「只许减不许加、不渐强」，黎明必须逐级抬升；结尾规则直接冲突。 |
| 温暖×悲壮 | — | 效价/唤醒/终止式全反（完全终止 vs 半终止）。 |
| 温暖×神秘 | — | 温暖要 `sus4→3` 明确解决，神秘要属七挂住不解决；短混响+半音簇与温暖的开放三度、软起音冲突。 |
| 温暖×空灵 | △ | 温暖靠 60–80Hz 的体温低频，空灵 HPF 100–150Hz 削光；只留中音区可用。 |
| 温暖×苍凉 | — | 温暖是 C 大调全七的「有人陪」，苍凉是五声空五度的「没人」。 |
| 温暖×压抑 | △ | 温暖要 release 与不抢拍，压抑要憋着十六分推进；节奏语法相反。 |
| 升华×神秘 | △ | 升华要 `V7–I` 完全终止+转调坐实，神秘要悬而不解；只可作转调前的桥。 |

## 3. 高频组合配方卡（12 组，用户点名优先）

> 每张卡字段固定：坐标/裁决 → BPM/调式 → 和弦（条目名+级数+C 大调/a 小调具体和弦）→ 三件套分工与音区 → 织体层数与密度曲线 → 空间/动态 → 8 小节进出 → 才成立的手法 → 参考（**典型场景 + 可抄手法**，不标作者/专辑/编号）。密度曲线写作 `层数 / 每小节音符数`，段序 Intro→Verse→Build→Climax→Outro，8 小节版按卡内进出压缩。C4=60；小提琴 G3(55)–C6(84)、手风琴右手 C4–C6(60–84)/左手 C2–C4(36–60)【事实，`emotion-arrangement-recipes.md` §3.0】。和弦构成与级数为【事实】；BPM/混响/dB/密度为【经验】起点。

### 卡 1　悲伤·含蓄 × 梦幻（用户点名①）
- **坐标/裁决**：负/低。情绪给 a 小调 + 只撤不推的弧线；梦幻给高音薄织体 + 远场混响。
- **BPM/调式**：60–72｜a 自然小调（Dorian 变体「悲中有光」）｜4/4。
- **和弦**：`i–VI–III–VII = Am–F–C–G`（§2.4 6251 小调版）；`line cliché = Am–Am(maj7)–Am7–Am6`（§1.9，顶声部 A–G#–G–F# 半音下沉）；可改用 `Am9–Fmaj7(#11)–Dm9–Esus4` 加九/sus 类（每 2 小节换一次）。
- **三件套**：钢=主旋律 C4–C5(60–72) legato 半踏板、vel 35–55、句尾 non-legato；小=加弱音器长音 G3–D4(55–62) 每 4 小节才动一次；手=左手 A2(45) 每小节 1 次 + 右手气声，不进中高音区抢旋律。
- **织体/密度**：1→2→2→3→1 层；4–6→8–12→10–16→12–20→2–4 音；留白 30–40%。
- **空间/动态**：RT60 由卡01 的 1.2–1.8s **拉到 2.2–3.0s（S01 梦幻）**｜pre-delay 30–50ms｜HPF 100–130Hz｜段落差 6–8dB / LRA 6–10LU｜8–12kHz −2～−3dB｜留尾音。
- **8 小节进出**：1–2 钢 `pp` 单声主题+Hall 长尾 → 3–4 小加弱音器长音「飘入」（新音色事件，靠混响不靠音量）→ 5–6 手气声进、钢下移 C3 → 7 全停 1 拍 → 8 小 G4 悬在 3 音不解决、留 3s 尾。
- **才成立**：**只把混响拉远、力度仍锁 `pp`**——「远而不响」才是梦幻；一推音量就变成宣泄。加一条：**主和弦不落地**（去掉 V–I、用加九/sus 消解功能），才会有「梦里的悲伤」。
- **参考**：典型场景「褪色旧照片蒙太奇」｜可抄：高音区单音+半踏板叠合+句尾不解决；典型场景「雨夜窗玻璃特写 / 独白式片尾」｜可抄：HPF 100Hz 削低频只留中高音 + 3s 尾。

### 卡 2　悲伤·崩溃 × 宏大（= 悲壮，用户点名②；亦等价于 宏大叙事 × 悲壮）
- **坐标/裁决**：负/高。崩溃给和声小调 `E7` 的 G# 撕裂 + 全曲唯一高点；宏大给 6 层全奏与 `bVI–bVII–I` 台阶（效价翻负即悲壮）。
- **BPM/调式**：76–96（进行曲取向可压到 60–76）｜a 和声小调｜4/4（可插 1 小节 2/4 抽气）。
- **和弦**：`i–iv–V–i = Am–Dm–E7–Am`（§2.4，G#→A 半音解决）；`I–IV–iv–I = C–F–Fm–C`（§2.2/§3-11，A→Ab→G 半音刺痛）；收尾用 `iv–bVI–bVII–I = Fm–Ab–Bb–C`（§2.3 肃穆台阶）或停 `E7` 半终止（§2.7）。
- **三件套**：小=主旋律 **G3–C5(55–72) 中低音区**宽揉 legato、强奏但不冲极端高音（S03 悲壮压中低；A5–E6 是崩溃/宏大，不是悲壮）；钢=低音+支点 C2–C4 八度低音+柱式和弦强击 vel 95–115、踏板每和弦换；手=和声墙，右手全簧片长音+风箱强推（16'+8'+4' 全注册 / bellows shake）、左手柱式和弦。
- **织体/密度**：1→2→3→4→2 层（S03 上限 4–5 层）；4–6→8–14→16–22→24–32→4–8 音；附点节奏、低音每 2 小节下行半音。
- **空间/动态**：RT60 2.5–3.2s（S03）｜pre-delay 25–45ms｜HPF 40–60Hz（留八度低音）｜段落差 12–16dB / LRA 12–16LU｜留 2–3s 高潮尾｜渐强 8 小节、高潮只一次。
- **8 小节进出**：1–2 钢 `pp` 埋动机 → 3–4 小提琴进（+1 层）→ 5–6 手风琴墙进、力度每轮 +12、低音半音下行 → 7 **全部声部撤空 2 拍**（抽空）→ 8 全奏爆发：小高八度主题+八度低音砸+风箱满推到 `ff`，镲 swell 早半拍，接 `iv–i` 变格终止。
- **才成立**：**高潮前必须先撤空**——悲壮是「憋到极限才裂」，不是从头就响（卡02 失败模式①）；且**附点 + 匀速低音是「壮」的来源，去掉就只剩「哀」**；**音区以感层为准**——即使崩溃情绪想要 A5–E6 高音宣泄，悲壮感也把主奏压回 G3–C5，否则写出来的是「宏大/崩溃」。
- **参考**：典型场景「战败独白 / 葬礼蒙太奇 / 送别」｜可抄：全停 1 小节后全奏 + 小提琴高八度；典型场景「片尾牺牲字幕 / 失败后的站立」｜可抄：`Fm–Ab–Bb–C` 平行台阶 + 定音鼓滚奏 + 2.5s 尾。

### 卡 3　孤独 × 空灵（用户点名③）
- **坐标/裁决**：负/低。孤独给 a 羽五声 + 1 件乐器 + 不渐强消散；空灵给 HPF 削低频 + 3.5–5.0s 旷野混响。
- **BPM/调式**：rubato / <56｜a 羽五声（A C D E G，少 F/B）｜无明确拍号。
- **和弦**：`羽调式 6-5-4 = Am7–Gsus2–Fmaj7`（§2.5）；`主音 pedal = Am–Dm/A–E7/A–Am`（§2.6，低音 A 不动）；可改 `Asus2–Cmaj7(no3)–Dsus2` 回避三音、用开放五度。
- **三件套**：小（或手）=唯一主旋律 **C5–C6(72–84)，C4 以下不住音（S05）** 极慢长音、几乎不揉弦、大量气口（可用泛音 / sul tasto）；钢=每 4–8 小节才 1 个单音/空五度 `C–G` 于 C5 以上，不弹和弦；手=极远单簧片长音 + 左手 A2 一次，**几乎不出现 / 空灵时完全休止**。
- **织体/密度**：1→1–2→2→2→1 层；2–4→4–6→6–8→6–10→1–3 音；留白 35–50%。
- **空间/动态**：RT60 3.5–4.5s（S05）｜pre-delay 40–80ms｜**HPF 100–150Hz（几乎无低频，可到 200Hz）**｜段落差 3–5dB / LRA 4–8LU｜8–12kHz −2～−4dB｜自然消散、留混响尾。
- **8 小节进出**：1–2 一件乐器单旋律 + 1 个踏板音 → 3–4 只加 1 个极轻事件（一个钢琴音）→ 5–6 一次风箱起伏，**不加层不加量**→ 7 全停 2 拍 → 8 主题变奏孤独重现、**只减不加**，末音让混响尾自己填满。
- **才成立**：**结尾不渐强、不收主和弦**——孤独一旦被「解决」（`V7–I` 或 fade 前推 fader）就变「有人陪」；且**低音缺席**，一加 bass 就变「苍凉」而不是「空灵」。
- **参考**：典型场景「雪原 / 太空远景长镜头 / 醒来空无一人」｜可抄：单声旋律 + HPF 120Hz + 4s 尾 + 无规律 pulse；典型场景「空屋清晨」｜可抄：每 8 小节只加 1 个钢琴单音、不弹和弦。

### 卡 4　希望·升华 × 宏大（= 史诗升华，用户点名④）
- **坐标/裁决**：正/中→高。升华给末段 +2 半音 + 主题满载回归；宏大给每 8 小节加 1 层 + 大厅混响 + `bVI–bVII–I`。
- **BPM/调式**：84–108（或 68→84）｜C 大调，末段转 D 大调（+2 半音）；亦可同主音 a 小调 → C 大调互换｜4/4。
- **和弦**：`卡农 15634145 = C–G–Am–Em–F–C–F–G`（§1.4）；`bVI–bVII–I = Ab–Bb–C`（§2.3 凯旋收尾）；末段 `pivot + 新调 V7–I`：Am 作 pivot 接 `D7–G`（§2.8，C→G 例；D 大调则用 `A7–D`）。前 4 小节可 `Am–F–Dm–Esus4`，后 4 小节 `C–G/B–Am–F→C`（转大调不换主音）。
- **三件套**：小=主旋律（主题回归）G4–E5 起、Climax 上跳八度到 E6、连弓渐强；钢=和声支点 C3–C4 分解转柱式、踏板随升 key 换干净；手=中音区和声层 C4–C5 长音渐密、风箱随 crescendo 推大、末段全注册。
- **织体/密度**：1→2→3–4→5–6→3 层；4–6→8–12→16–20→20–26→8–12 音；**每 4 小节加一层、抬一个音区**。
- **空间/动态**：RT60 2.0→3.2s 自动化（大厅 2.5–3.5s）｜pre-delay 30–60ms｜HPF 40–70Hz｜段落差 12–18dB / LRA 12–18LU｜8–12kHz −1→+2dB｜留长尾｜vel 35→100、渐强 16 小节。
- **8 小节进出**：1–2 主题以暗织体埋一次（离场 ≥60s 才回归）→ 3–4 加 1 层、音区抬 1 音级 → 5–6 再进 1 长音色 + 撤 2 小节 → 7 **主题以更满配器回归**（chills 点）→ 8 **整段 +2 半音转调再现**，立刻用新调特征音 F# 坐实，收 `V7–I` 留长尾。
- **才成立**：**pivot 后立刻给新调特征音**（D 大调的 F#）+ 新调 `V7–I`——只移调不坐实，听感仍停在旧调（§2.8 的坑）；**调式互换放在第 5 小节**，比换和弦更有「天亮了」的听感。
- **参考**：典型场景「终章全员集结 / 登顶镜头 / 重逢破晓」｜可抄：每 8 小节加 1 层 + 末段升 key 再现；典型场景「凯旋片尾」｜可抄：`Ab–Bb–C` 平行上行 + 八度叠奏 + 3s 长尾。

### 卡 5　怀念 × 梦幻（用户点名⑤）
- **坐标/裁决**：正/低（效价正负混合）。怀念给 3/4 华尔兹 + 1645 + 借一次 `IV→iv`；梦幻把近场 1.5–2.2s 换成远场、音区上移。
- **BPM/调式**：72–88（或 66–78）｜C / F 大调，大调加六/加九｜3/4 华尔兹。
- **和弦**：`I–vi–IV–V = C–Am–F–G`（§1.2 1645）；`I–IV–iv–I = C–F–Fm–C`（§2.2，Fm=53/56/60，一瞬苦涩）；可改 `C6/9–Am9–Fmaj7–Gsus4` 加九/挂留类。
- **三件套**：手=主旋律 C4–C5(60–72) 右手 legato、风箱平稳带呼吸感（可用 8' 或轻 musette，detune ≤10 cent）；钢=和声 C3–C4 分解 `低–高–中–高`（§1.3）、轻踏板；小=副旋律 D4–A4(62–69) 慢宽揉弦、句尾叹息下行、不抢拍。
- **织体/密度**：1→2→3→4→2 层；4–6→8–12→12–16→14–18→4–8 音；留白 25–35%。
- **空间/动态**：RT60 由 1.5–2.2s **拉到 2.6–3.4s**（怀旧版略收短到 2.4–3.0s）｜pre-delay 30–50ms｜HPF 70–90Hz｜段落差 4–7dB / LRA 6–9LU｜8–12kHz −1～−2dB｜留尾音；「旧」感靠**不抢拍 + 风箱呼吸**。
- **8 小节进出**：1–2 手风琴独奏主题 → 3–4 钢琴分解伴奏进（新音色事件）→ 5–6 小提琴副旋律首次进、第 6 小节借一次 `Fm` → 7 主题原样回归但**换钢琴音色**（确认期待=释然）→ 8 逐件退场、手独奏收、`IV–iv–I` 后留 1 拍空 + 3s 尾。
- **才成立**：**年代感只靠奏法**（风箱呼吸 / 踏板换法 / 慢宽揉弦），不靠任何电子化「做旧」音效——一加处理类音色就越界（卡04 失败模式②）；**大调加六度是怀旧的签名音，换成小三度就变悲伤**。
- **参考**：典型场景「老照片翻页 / 旧街道 / 多年后重逢」｜可抄：3/4 手风琴 + 分解伴奏 + 一次 Fm；典型场景「成年主角回到老屋」｜可抄：主题原样回归只换音色、不抢拍。

### 卡 6　庄严 × 圣洁（用户点名⑥）
- **坐标/裁决**：正/低。庄严给 52–68 + 附点 + 音区不抬升（靠「不动」）；圣洁给变格终止 + 3.5–5.0s 教堂长混响 + Lydian 光晕。
- **BPM/调式**：52–68（或 56–72）｜C 大调（副部 Lydian #4）/ 教会调式｜4/4 或 3/2。
- **和弦**：`IV–I（变格）= F–C`（§2.7「阿门」）；`K46–V7–I = C/G–G7–C`（§2.7 完全终止定格，C/G=55/60/64/67）；`I–II（Lydian #4）= C–D`（§2.2 借用 / 通用理论补充，漂浮）；`持续音 pedal = C–F/C–G/C–C`（§2.6）。
- **三件套**（作骨架，可扩原声管风琴/长号）：钢=和声支点 C2–C4 全音符柱式和弦、踏板每和弦换干净；小=副旋律/长音 G3–D4 **无揉弦**连弓、平行三度 legato、附点节奏、弱拍绝不抢；手=低音+和声层 左手 C2 全音符、右手 8' 长音簧片（管风琴般持续）、风箱匀速不抖、**不用 musette**。
- **织体/密度**：1→2–3→3–4→5–7→2 层；2–4→4–8→6–10→8–12→2–4 音（**每小节 ≤12 音**）；乐句 8 小节、留白 15–25%。
- **空间/动态**：RT60 3.2–4.5s（大教堂 3.5–5.0s）｜pre-delay 50–80ms｜HPF 30–40Hz｜段落差 8–12dB / LRA 8–12LU｜vel 50–80、渐强 16 小节｜留 4s 以上长尾、末音后静默 2s。
- **8 小节进出**：1–2 钢+手低音全音符起（只给主题前 2 音预告）→ 3–4 进 1 个长音色（小提琴→长号/管风琴）→ 5–6 附点节奏统一进入、**音区整体不移高**→ 7 唯一一次全奏 `f` 随即 `K46–V7–I` 定格 → 8 `F–C` 变格终止、留 4s 长尾 + 静默 2s。
- **才成立**：**Climax 只加长音层不加 pulse**，且避开 `G7` 的导音 B（用 `IV–I` 变格与 `I–II` 平行）——一给属七导音就变「要解决的流行」（卡15 失败模式①）；**禁止宽揉弦与 musette 颤音**，两者都会把「圣洁」拉回人间。
- **参考**：典型场景「教堂仪式 / 加冕 / 众赞歌」｜可抄：`F–C` 变格 + 全音符长音 + 4s 尾 + 末音后静默；典型场景「光从穹顶落下」｜可抄：Lydian `C–D` + 只上不下的主题 + 只加长音层。

### 卡 7　悬疑 × 神秘（用户点名⑦）
- **坐标/裁决**：负/中。悬疑给减七/四度叠置/属七挂住不解决；神秘给「异常空间」（超短或超长混响）+ 大量留白。
- **BPM/调式**：66–92（或 60–80）｜c 小调 / 全音阶 / 无稳定调性感｜4/4 或自由；前 8 小节不出现主和弦原位。
- **和弦**：`四度叠置 = C–F–Bb = 60/65/70`（§2.6，非三度叠置、中性诡异）；`减七等音 Bdim7 = B–D–F–Ab = 59/62/65/68`（§2.8，两组三全音）；`增三 line = C–Caug–C6`（§1.9，顶声部 G–G#–A 半音上行「不对劲」）；`Cdim7–Caug–Fm(maj7)` 减七/增三/小大七类，半终止或不解决。
- **三件套**：钢=点状动机 C3–C4（低音区 C2–G4）单音/小二度碰撞 + pizzicato 式短断奏、大量休止；小=高音悬置长音 A5(81) 极弱 或 col legno 弓杆敲 / sul ponticello 点音；手=气声与 pedal 左手 C2 持续、右手走调般半音长音（8' 单簧、风箱不稳、**不用 musette**、不加任何处理音色）。
- **织体/密度**：1→2→3→4→1 层；2–4→6–10→10–14→12–16→2–4 音，**密度几乎不涨**；同时发声 ≤4 音、留白 ≥40%。
- **空间/动态**：RT60 **0.4–0.8s 或 2.5–4.0s**（异常短/异常长=本能警觉；或 1.6–2.6s）｜pre-delay **0–10ms 或 60–100ms**｜HPF 80–120Hz｜段落差 3–6dB / LRA 5–9LU｜vel 30–65｜8–12kHz −2～−4dB｜留尾音但尾音要「空」。
- **8 小节进出**：1–2 钢琴小二度单音 + 1 个踏板音 → 3–4 一次拨奏/增三点描微事件 → 5–6 一次减七移位、**密度不涨**、不规则乐句（3/5 小节）→ 7 全停 1–2 拍（抽空）→ 8 四度叠置 + 减七悬在半空**开放结尾**，绝不给 `V7–I`。
- **才成立**：**只留 1–2 层 + 异常空间 + 大量留白**，靠「意外」而非音量制造警觉；给一个明确的 `V7–I` 就等于谜底揭穿（卡12 失败模式①）；**回避主和弦 + 不规则乐句**是神秘的核心。
- **参考**：典型场景「空走廊 / 门后未知 / 密室」｜可抄：小二度点音 + 0.6s 干混响 + 每 4 小节 1 个微事件；典型场景「真相揭晓前一瞬 / 逼近的未知」｜可抄：减七等音移位 + 属七挂住不解决 + 开放结尾。

### 卡 8　抗争 × 悲壮（用户点名⑧）
- **坐标/裁决**：负/高。抗争给 140–168 + 同音 unison riff + 停属不给归宿；悲壮给 6–7 层全奏 + 全曲唯一一次 `ff` + 2–3s 尾。
- **BPM/调式**：140–168（悲壮/进行曲版可压到 84–108 或 66）｜e / d 小调·Phrygian(♭2) / a 和声小调｜4/4。
- **和弦**：`i–V–i（和声小调）= Am–E7–Am`（§2.4，导音硬拽回去）；`i–♭II = Am–Bb`（§2.2 那不勒斯味，♭2 半音摩擦）；`Am–Bb–E7–Am` 或 `i–iv–V` 反复；收尾 `…–E7` 半终止（§2.7）。
- **三件套**：钢=节奏/低音引擎 C2 八度同音反复 unison riff / 左手八度+柱式、断奏、vel 100–120；小=主旋律 **G3–C5(55–72) 中低音区（S03 悲壮压中低）** 强弓、快窄揉弦、détaché 分弓、大量下弓重音（可扩弦乐组齐奏）；手=和声撞击 右手柱式和弦短促风箱冲 + 16' bass / sforzato、左手低音同音，做「墙」不铺长音。
- **织体/密度**：2→3–4→4→5→2–3 层（S03 上限 4–5 层）；8–12→16–20→24–28→28–32→8–12 音；附点与三连音、vel 70→115。
- **空间/动态**：RT60 **2.5–3.2s（S03）**（悲壮要「余痛」不是「切断」；纯抗争版可略干到 1.8–2.4s）｜pre-delay 20–40ms｜HPF 50–70Hz｜段落差 8–12dB / LRA 8–12LU｜留 2s 尾但**末音仍骤停定格**｜宽度 120%。
- **8 小节进出**：1–2 钢琴八度 riff / 低音 ostinato 直接起（不铺 intro）→ 3–4 每 4 小节加 1 层 + 军鼓滚奏进、主题 → 5–6 同音 unison 齐奏、半音上行推进、不解决 → 7 全奏 `ff` + sforzato + 定音鼓/镲，**密度到顶但音量不再涨**→ 8 全乐队**骤停**、停在 `E7` 不给主和弦，留 2s 混响尾或转调。
- **才成立**：**愤怒靠密度与断奏、不靠音量**（卡11 失败模式①）；悲壮与纯抗争的差别只在**混响尾**——纯抗争 0.6s 切断是「决绝」，给 2–3s 尾才成「悲壮」；**ostinato 不变、上方每次换一层**：不可改的宿命 + 不断挣扎。
- **参考**：典型场景「冲锋 / 巷战 / 对峙 / 拒绝屈服」｜可抄：八度 unison riff + 每 4 小节加 1 层 + 停属；典型场景「牺牲后定格」｜可抄：全奏后骤停 + 2.5s 尾 + 不给主和弦。

### 卡 9　紧张 × 压抑（用户点名⑨）
- **坐标/裁决**：负/高。紧张给十六分 ostinato + 属 pedal + 半终止；压抑把整体钉在 `mp`「只加层不加量」+ 0.6–1.2s 干近场。
- **BPM/调式**：80–110（不快但压人）｜c 小调 / Phrygian 味｜4/4。
- **和弦**：`line cliché = C–Cmaj7–C7–C6`（§1.9，顶声部 C–B–Bb–A 半音下行）；`属音 pedal = C/G–Am/G–F/G–G`（§2.6，低音 G 不动）；`…–G` 半终止（§2.7 停 V）。
- **三件套**：钢=节奏引擎 C3–C4 十六分固定音型 ostinato、断奏、**力度锁 `mp` 不涨**；小=长音/震音 G3–D4 tremolo 或 A5 悬置长音；手=低音 pedal 左手 G2(43) 持续不发、右手偶尔小二度碰撞 `Bb–B`。
- **织体/密度**：1→2→3→5→2 层；8→16→20→24–28→8 音，**逐层加但整体仍 `mp`**。
- **空间/动态**：RT60 **0.6–1.2s**｜pre-delay **0–15ms**｜HPF 60–80Hz｜段落差 **4–6dB** / LRA 5–8LU｜**不留尾音**（切断，尾音会泄压）｜8–12kHz −2～−4dB。
- **8 小节进出**：1–2 钢 ostinato 单独起步 → 3–4 每 4 小节加 1 层（只加层不加量）→ 5–6 小震音 + 手 pedal 进、低音运动从「走动」改「持续」→ 7 密度到 28 音/小节、**仍不解决**、停 `G` 半终止 → 8 全停 1 小节（抽空）、末音硬切不收主和弦。
- **才成立**：**整体钉在 `mp`，把预算全给层数与十六分密度**——一靠「变响」就变成噪（卡08 失败模式①）；延迟解决别超 1 小节但**别真解决**。
- **参考**：典型场景「倒计时 / 监视器画面」｜可抄：十六分 ostinato + 锁 `mp` + 0.8s 干混响；典型场景「暴风雨前的静默」｜可抄：属 pedal 不动 + 半终止停 V + 末音硬切。

### 卡 10　孤独 × 苍凉（破败，用户点名⑩「破败×苍凉」）
- **坐标/裁决**：负/低。孤独给 1 件乐器 + 无规律 pulse + 不渐强；苍凉/破败给 a 羽五声空五度 + 中低音区 + 较干混响 + 残缺留白。
- **BPM/调式**：rubato / 52–60（或 52–68）｜a 羽五声 / a 自然小调（小调 + 增二度 / 减和弦）｜4/4 极松。
- **和弦**：`i–VII–VI–VII = Am–G–F–G`（§2.4，下行叹息后原地打转）；`空五度 4–5–6 = F5–G5–Am5`（§2.5，撤三音）；`I–IV–iv–I = C–F–Fm–C`（§2.2，破败的「缺角」半音）；`Am–Bdim–F–E7(♭9)` 低音持续 A。
- **三件套**：小=唯一主旋律 G3–D4(55–62) 低把位长音、几乎不揉弦、句尾下行（独奏孤线）；钢=每 4–8 小节 1 个空五度或单音 C3–C4，低中音区稀疏、不弹三和弦；手=极远单簧片长音 + 左手 A2 一次，**几乎不出现**；破败版可用 musette 微失谐 ±15–30 cent。
- **织体/密度**：1→1–2→2→2→1 层；2–4→4–6→6–8→6–10→1–3 音，且**每 4 小节留 1–2 拍全空**（破败的缺角）；起音错开 30–80ms（不齐）、留白 30–45%。
- **空间/动态**：RT60 **1.8–2.8s**（破败版 2.6–3.8s，比空灵干、比含蓄远）｜pre-delay 30–50ms｜HPF 100–130Hz｜段落差 3–5dB / LRA 4–8LU｜vel 40–65｜**8–12kHz −3～−5dB**｜几乎不渐强、尾音要「空」、自然消散。
- **8 小节进出**：1–2 小提琴低把位单旋律 + A2 pedal → 3–4 一次空五度钢琴音（撤三音）→ 5–6 借一次 `Fm` 半音「缺角」、留 2 拍全空 → 7 全停 2 拍 → 8 主题变奏孤独重现、`Am–G–F–G` 原地循环不解决、只减不加。
- **才成立**：**撤掉三音只留空五度 + 高频砍到 −4dB + 每 4 小节挖 1–2 拍全空**——「破败」不是加噪音，是**把和弦与织体挖出缺口**（§2.5 空五度 + §5.3 留白）；**失谐 + 不齐的起音**，太齐就变「怀旧圆舞曲」。
- **参考**：典型场景「战后废墟 / 荒村空镜 / 废墟战后荒村」｜可抄：空五度 + 五声无偏音 + 每 4 小节留白；典型场景「废弃旧宅推门」｜可抄：一次 `Fm` 半音缺角 + −4dB 暗高频 + 1.8s 尾 + 微失谐。

### 卡 11　温暖 × 黎明（用户点名⑪）
- **坐标/裁决**：正/低→中。温暖给 C 大调全七 + 一个和弦坐 2–4 小节 + `sus4→3` 慢解决；黎明给音区逐级抬升 + 亮度自动化 + 末段转亮/升 key。
- **BPM/调式**：76–92｜C 大调（末段可转 D 大调 +2 半音，§2.8）｜4/4。
- **和弦**：`ii7–V7–Imaj7 = Dm7–G7–Cmaj7`（§1.6 回家感）；`Imaj7–vi7–IVmaj7–V7 = Cmaj7–Am7–Fmaj7–G7`（§1.2 全七变体）；`宫五声 add9/sus2 = Cadd9–Fmaj9–Gsus2`（§2.5，三音不急着出现）。
- **三件套**：钢=主旋律+和声 C4–C5(60–72) `sus4→3` 慢解决、轻踏板每 2 小节换；手=和声铺底 C4–C5 长音 legato、风箱均匀（像体温）、不弹快音；小=副旋律 D4–A4(62–69) 慢宽揉弦、只在乐句尾出现一次，末段上移到 A4–E5。
- **织体/密度**：1→2→3→4→2 层（S11 上限 4 层）；4–6→8–12→12–16→14–18→4–6 音，**音区每 8 小节抬 1 个音级**。
- **空间/动态**：**RT60 3.0→1.5s 自动化**（S11 核心：宏大是已撑开的静态尺度、黎明是正在撑开的过程，差别就在混响在变）｜pre-delay **60→25ms**｜**8–12kHz −2→+2dB 自动化**｜**层数 1→4**、每小节 4→16 音、留白 35%→10% 一起动｜HPF 60–80Hz｜段落差 4–6→8–10dB / LRA 5–8→8–10LU｜留长尾。
- **8 小节进出**：1–2 钢琴独奏主题、第 2 小节 `Gsus4→G` 延迟解决 → 3–4 手风琴长音铺底进、亮度 −1dB → 5–6 小提琴副旋律首次进、加一次 `Cadd9`、音区抬到 A4 → 7 主题原样回归（确认期待）+ 高频推到 +1dB → 8 末段 +2 半音 / 或 `ii–V–I` 完全终止、亮度 +2dB、`V7–I` 坐实、留 3s 长尾。
- **才成立**：**亮度和音区要「逐级」抬，不要一步到位**——黎明是过程不是开关、**固定 RT60 不成立，必须让混响在变**；并保留一个 `maj7` 挂住防甜腻（卡06 失败模式②）。
- **参考**：典型场景「清晨窗帘拉开 / 晨光进屋」｜可抄：`sus4→3` 延迟解决 + 高频 −1→+2dB 自动化；典型场景「病愈出院 / 久别重逢」｜可抄：主题原样回归 + 末段升 key + 3s 长尾。

### 卡 12　庄严 × 宿命（悲壮收束，用户点名⑫「宿命×悲壮」）
- **坐标/裁决**：负/中（庄严的正效价被宿命拉向负）。宿命给 A2/C2 pedal 全曲不动 + 附点滚动 + 自然小调；庄严给慢速仪式 + 长音层；悲壮底色靠末段一次全奏 + 2–3s 尾。
- **BPM/调式**：60–76｜a / d 自然小调（**不用和声小调**，避免戏剧化）｜4/4。
- **和弦**：`i–VII–VI–VII = Am–G–F–G`（§2.4）；`主音 pedal = Am–Dm/A–E7/A–Am`（§2.6，低音 A 不动）；`小调卡农变体 63451 = Am–Em–F–G–C`（§1.4 变体②）；收尾可用 `iv–bVI–bVII–I = Fm–Ab–Bb–C`（§2.3 肃穆台阶）。
- **三件套**：手=主音 pedal 左手 A2(45) 全曲不动、右手附点长音（Stradella bass + 风箱匀速不抖）；钢=附点滚动 C3–C4 三连音/附点音型每小节重复、全音符柱式和弦作支点；小=副旋律 G3–D4 长音级进、乐句整体下行、不揉弦、弱拍不抢。
- **织体/密度**：1→2→3→4→1 层（S12 上限 3–4 层）；2–4→8–12→12–16→14–18→2–4 音，附点密度每 8 小节 +2 音。
- **空间/动态**：RT60 2.0–2.8s（S12）｜pre-delay 30–50ms｜HPF 30–50Hz（pedal 要留、上方声部做 HPF 防糊）｜段落差 6–10→10–14dB / LRA 7–11→10–14LU｜8–12kHz −1～−3dB｜留尾音、停在 pedal 不解决。
- **8 小节进出**：1–2 A2 pedal 单独起步、上方只 1 个和弦 → 3–4 每 8 小节加 1 层 + 附点 +2 音、**低音始终不动**→ 5–6 唯一一次 pedal「呼吸」（上方和弦故意不含 A，制造摩擦）→ 7 回到 pedal、附点滚到顶、唯一一次全奏 `f`（悲壮底色）→ 8 逐层退、**仍停在 A2 pedal 不解决**、留 2–3s 尾。
- **才成立**：**全程自然小调、导音 G 不升 G#**（一用 `E7` 就变「戏剧」不是「宿命」，卡14 失败模式②）；且 pedal 只在第 5–6 小节「呼吸」一次，撑太久不解决会变单调。
- **参考**：典型场景「命运不可改的加冕 / 审判」｜可抄：A2 pedal 全曲不动 + 附点滚动 + 只减不加；典型场景「史诗终章的失败定格」｜可抄：自然小调 `Am–G–F–G` 循环 + 末段一次全奏 + 停在 pedal 不解决。

## 4.「我要 X 情绪 + Y 感」5 步决策顺序

1. **定情绪**：效价（正/负）× 唤醒（高/低）× 强度（含蓄/宣泄）→ 查 `emotion-arrangement-recipes.md` §1 速查 / 卡 01–12，换出**调式**（管效价）、**BPM**（管唤醒）、弧线位置、终止式。**想调「痛不痛」动调式，想调「激不激动」动速度，别搞反**【事实，`emotional-expression.md` §2.1】。
2. **定场景感**：从 `scene-texture-recipes.md` §1（或本文件 §1）选 **1 主 + 最多 1 副，两个以上必糊**；由此定音区中心、RT60/pre-delay、HPF、8–12kHz 亮度、织体层数、留白。情绪只给骨架，感给「镜头与空间」。
3. **查本矩阵（§2）**：看这一对是 ◎ / ○ / △ / —；△ 与 — 按 §2.2 原因与 §0 裁决处理，不要硬叠。**冲突优先级**：① 调式/BPM/和弦/终止式以情绪为准；② 音区/混响/亮度/HPF/留白以场景感为准；③ 力度与层数取交集，冲突时先保「高潮全曲只 1 次」【事实 §5.2】；④ 标 `—` 换相邻档（含蓄↔崩溃、空灵↔苍凉、圣洁↔压抑）或只放在 8 小节 Intro/Outro 做对照段；⑤ 标 `△` 只允许「改 1 个参数」解决。

## 5. 三件套角色切换表

> 同一件乐器在不同「情绪 × 感」下角色会翻转。**低唤醒 + 远场感 → 退到「几乎不出现」或长音；高唤醒 + 满编感 → 升为主旋律或和声墙；感若要求「悬而不解」→ 主奏乐器改点状/拨奏，不写完整旋律线。**

### 5.1 钢琴

| 情绪×感 | 角色 | 音区 | 奏法/力度 | 备注 |
|---|---|---|---|---|
| 悲伤·含蓄×梦幻 | 主旋律 | C4–C5(60–72) | legato 半踏板、vel 35–55、句尾 non-legato | 只撤不推；半踏板分解 C4–C6 亦可 |
| 悲伤·含蓄×神秘 | 点状动机 | C2–G4 / C3–C4 | 短断奏 + 小二度碰撞、大量休止 | **不弹和弦** |
| 宏大叙事×梦幻 | 和声支点/光晕 | C2 八度 + C4–C5 分解 | 踏板每 2 小节换、vel 60–75 | 不抢小提琴主题，高音区留给 Lydian |
| 宏大叙事×悲壮 | 低音+支点 | C2 八度 + C3–C4 柱式 | 强击 vel 95–115、踏板每和弦换 | 与定音鼓分频：钢占 40–60Hz |
| 庄严×圣洁 | 和声支点 | C2–C4 全音符 | 每和弦换干净、弱拍不抢 | **不作主旋律** |
| 孤独×空灵 | **几乎不出现** | C4 单音 / 空五度 | 每 4–8 小节才 1 个音 | 一出现就「有人陪」 |

### 5.2 小提琴

| 情绪×感 | 角色 | 音区 | 奏法/力度 | 备注 |
|---|---|---|---|---|
| 悲伤·含蓄×梦幻 | 副旋律（加弱音器） | G3–D4(55–62) | 慢宽揉弦、每 4 小节动一次 | con sordino |

### 5.3 手风琴

| 情绪×感 | 角色 | 音区 | 奏法/力度 | 备注 |
|---|---|---|---|---|
| 悲伤·含蓄×梦幻 | 低音 + 气声 | 左手 A2(45)、右手 C4 极稀疏 | 风箱轻推、8' 单簧长音、每小节 1 次 | **不进中高音区抢旋律** |
| 悲伤·含蓄×神秘 | 气声与 pedal | 左手 C2 持续、右手中音区 | 走调般半音长音、vel ≤40、风箱不稳 | 不用 musette、不加任何处理音色 |
| 宏大叙事×梦幻 | 中音区光晕层 | C4–C5 | 长音 legato、风箱匀速 | 只铺长音、不加 pulse |
| 宏大叙事×悲壮 | 和声墙 | 右手全簧片 + 左手柱式 | 16'+8'+4' 全注册、bellows shake、风箱强推 | 做「被声音裹住」 |
| 庄严×圣洁 | 低音 + 持续层 | 左手 C2 全音符、右手 C4–C5 | 8' 长音、风箱匀速不抖（管风琴般） | 不用 musette、仪式不可动摇 |
| 孤独×空灵 | **完全休止 / 几乎不出现** | 左手 A2 一次 | 极远单簧片长音 | 出现即破坏「一个人」 |

> 【硬规则】任一时刻**只有一个焦点声部**；120 Hz 以下只有钢琴左手与手风琴 16' bass **二选一**为主，其余声部 HPF 切掉（`core-instruments.md` §7、`SKILL.md` 硬规则 9）。相邻声部至少隔 1 个八度，低音/和声/旋律各占一个八度带（`arrangement.md` §4）。
> 按组合族速查：悲伤×梦幻/空灵 → 钢主（半踏板分解）+ 小副（con sordino）+ 手铺底或休止；宏大/希望升华 → 钢或小二选一当主（八度）+ 手全注册和声；悲壮/抗争/宿命 → 钢左手八度作地基 + 小中音区宽揉主题 + 手 Stradella bass 附点/shake 作引擎；神秘/悬疑/压抑 → 钢低音点描 + 小 sul ponticello 点音 + 手 8' 长音 vel ≤40；怀念/浪漫/童真 → 手（8' 或 4' 单音旋律，轻 musette）可当主 + 钢分解/断奏 + 小短句对位。

## 6. 冲突诊断（常见「情绪和质感打架」）

| # | 听感症状 | 具体修正数值 |
|---|---|---|
| 1 | **写悲壮却用了太亮的高音区 + 短混响**：像凯旋/进行曲，痛感没了、只剩吵；或听着却空灵 | 8–12kHz 由 +2dB 砍到 **−1～−2dB**；RT60 由 0.8s 拉到 **2.0–2.8s**（空灵化则压回 2.0–2.6s）；宽度由 >150% 收到 **130%**；pre-delay **25–45ms**；补 C2 八度低音；收尾改停 `E7` 半终止不给主和弦 |
| 2 | **写梦幻却把力度推到 `f` / 听着像流行抒情**：变宣泄或 functional 太强，不漂浮 | 力度锁 `pp`（vel **30–50**）；层数由 4 压到 **1–2**；RT60 2.5–3.2s **但音量不涨**；HPF 提到 **100–130Hz**；和声去掉 `V–I` / 完整 4536251，改加九 / sus / 并列和弦、每 2 小节换一次 |
| 3 | **写压抑却做了 12dB 渐强**：压力泄光、变普通铺垫 | 整体钉在 `mp`、段落差压到 **4–6dB** / LRA **5–8LU**；预算全给层数（1→5 层）与十六分密度（8→28 音/小节）；RT60 **0.6–1.2s**、末音硬切不留尾 |
| 4 | **写空灵却加了 bass 与规律 pulse**：立刻「有人陪」、孤独被解决 | HPF 提到 **100–150Hz**（可到 200Hz）；删掉一切规律 pulse 与八度低音；每小节音符数压到 **1–3**；手风琴休止；结尾删掉渐强、只减不加，让 **4s** 混响尾自己填满 |
| 5 | **写圣洁却用了 `G7` 导音 + 节奏打击**：变「要解决的流行/凯旋」，漂浮感消失 | 避开 `V7` 导音 B，改 `IV–I`（`F–C`）变格与 `I–II`（`C–D`）Lydian 平行；Climax 只加长音层、每小节压到 **8–12 音**、不加 pulse；RT60 **3.5–5.0s**、pre-delay **50–80ms**、末音后静默 2s；禁宽揉弦与 musette 颤音 |
| 6 | **写宏大却只是「厚」**：音域挤在 C3–C5、和声每小节都换 | 两端各补一个八度（低音 C2 八度 + 高音 C6 叠奏）；和声节奏放慢到**每 4 小节换一次**；开放排列、高潮前先减层（`arrangement.md` §1） |
| 7 | **写神秘却听着压抑 / 两轴都不像**：层数 4–5、留白 <15%、低音持续不断；或主感 ≥3 个、两轴各让一半 | 神秘：层数压到 **≤3**、留白 **≥40%**、低音改点描、同时发声 ≤4 音。两轴都不像：只留 **1 主 1 副**，按 §0 裁决规则让情绪管调式、场景感管音区与空间，**不要各让一半** |

| 8 | **梦幻写成空灵 / 空灵写成梦幻**：把梦幻放 C5–C6、空灵放 C4–C5，两感直接互换（柔焦暖往下沉 vs 透明冷往上飘） | 按 `15-scene-texture.md` §4 组1：梦幻 **C4–C5 + RT60 2.2–3.0s**；空灵 **C5–C6、C4 以下不住音 + RT60 3.5–4.5s** |
| 9 | **悲壮写成宏大 / 黎明写成静态尺度**：悲壮用 C5–C6 高音双端 + 5–6 层全奏；黎明给固定 RT60 | 悲壮改 **G3–C5 + C2 持续、4–5 层、RT60 2.5–3.2s**（§4 组2）；黎明改 **RT60 3.0→1.5s 自动化** + pre-delay 60→25ms + 亮度 −2→+2dB + 层数 1→4 + 留白 35%→10%（§4 组6） |

> 越界提醒：还有一类高频错误是「写破败却加噪音/失真做旧」——修正不是加效果，而是**撤三音留空五度 + 8–12kHz −4dB + 每 4 小节留 1–2 拍全空 + 起音错开 30–80ms**（卡10）。任何处理类音色都属电子边界，一律不写。
