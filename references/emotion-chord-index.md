# 情绪 → 和弦进行索引

> **来源**：B 站公开教程 / 专栏 / 测评整理（采集 2026-11-11，973 条去重视频、8 个课程视频下载抽帧）。逐条来源见文末「来源索引」，学习清单见 `bilibili-study-map.md`。
> **制作口径**：默认在 DAW 里作曲编曲（MIDI + 采样音源 + 合成器 + 自动化 + 混音）；真实乐器、采样、合成器音色都是合法音色来源，不做「原声 vs 电子」的出身审查。
> **范围分流**：不默认做吵闹的电子舞曲风格（EDM / House / Techno / Trap / Dubstep / 鼓机 drop / riser / 泵感侧链 / supersaw lead），这类内容单独收在 `references/electronic-styles.md`，主线不混。
> **主用途**：情绪驱动 + 场景感双轴 + 钢琴 / 小提琴 / 手风琴三件套；合成器在这里是色彩与空间层（pad / bell / soft lead / 铺底），不是舞曲骨架。
> **用法**：数值是起点不是法则，以耳朵为准；与本技能既有硬规则冲突时，以技能规则为准。
> **情绪驱动**：按情绪查配方 `emotion-arrangement-recipes.md`、按情绪查和弦 `emotion-chord-index.md`、钢琴/小提琴/手风琴写法 `core-instruments.md`。
> **标注**：【源】/【事实】= 可核实；【验】= 交叉验证；【经验】/【通用理论补充】= 惯例或未单条核实，可放心改。

---


> **用途**：给「情绪驱动型编曲」用。原 `chord-library.md` 按**手法/曲风**组织，查「我现在要写悲伤 / 宏大叙事，该用哪条进行」不方便；本册把同一批进行**重排成按情绪检索**，并补改写手册、弧线调度、三件乐器 voicing。
> **信条**：所有建议都给可执行的数值和顺序，不给废话。表格优先，给具体音名与级数，区分事实与经验。
> **标注**：【事实】= 和弦构成/音名/MIDI 可逐音验证（来自 `chord-library.md`）；【经验】= 段落、情绪、参数惯例，可改；**需复核** = 本册推导、源册未单条给出的写法；**通用理论补充** = 功能/曲式/配器通识，无单条 B 站视频可核。
> **约定**：罗马数字＝功能级数，阿拉伯数字＝简谱级数，`b`＝降号，小写＝小三和弦，`°`/`dim`＝减三，`ø`＝半减七，`7`＝属七。`C4 = 60`（GM 标准）。C 大调实现按顺阶和弦读；A 小调实现是**功能等价改写**（不是逐音移调）。
> **「大调专属」说明**：`chord-library.md §2.2/§2.3` 等借用/降六级手法按源册说明只在**大调**语境成立；此类行的 A 小调栏给「顺阶承接方案」并注明，不臆造小调借用。
> **来源**：进行条目名、C 大调 / A 小调构成、MIDI 数值全部回抄 `chord-library.md`（原素材为 B 站专栏，cv 号见该册 §5.1）。本册出现的 **BV 号**均取自 `_bili_research/verified_bv.json` 且在 `bili_search_raw.json` 中复核存在，仅用于标注和声/曲式/配器/弦乐背景教程，不声称某视频逐条讲了本册某和弦；纯理论结论标「通用理论补充」。

## 0. 一页读懂：功能与张力符号

| 符号 | 含义 | 张力 |
|---|---|---|
| T（主） | I / vi / iii，稳定、落地 | 低 |
| SD（下属） | IV / ii，离开主、铺开 | 中 |
| D（属） | V / V7 / vii° / 副属，要回家 | 高 |
| 借用 / 减七 / pedal | 色彩与悬置，不属单一功能 | 可变 |

**通用声部纪律（【经验】，贯穿全册，源册 §0.2）**：① 相邻和弦保留共同音，其余声部级进 ≤2 半音，bass 可跳四/五度；② 转位优先让 bass 成级进线条；③ 重复音优先「根音 > 五音 > 三音/tension」，低音区不塞三音与延伸音；④ pad ≤5 音，2–3 音更通透，120 Hz 以下 mono；⑤ 和弦起音错开 5–30 ms，力度 ±10–20，别全 127。
