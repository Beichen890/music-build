# 场景与感受塑造配方库（梦幻 / 宏大 / 悲壮 / 神秘）

> **来源**：B 站公开教程 / 专栏 / 测评整理（采集 2026-11-11，973 条去重视频、8 个课程视频下载抽帧）。逐条来源见文末「来源索引」，学习清单见 `bilibili-study-map.md`。
> **制作口径**：默认在 DAW 里作曲编曲（MIDI + 采样音源 + 合成器 + 自动化 + 混音）；真实乐器、采样、合成器音色都是合法音色来源，不做「原声 vs 电子」的出身审查。
> **范围分流**：不默认做吵闹的电子舞曲风格（EDM / House / Techno / Trap / Dubstep / 鼓机 drop / riser / 泵感侧链 / supersaw lead），这类内容单独收在 `references/electronic-styles.md`，主线不混。
> **主用途**：情绪驱动 + 场景感双轴 + 钢琴 / 小提琴 / 手风琴三件套；合成器在这里是色彩与空间层（pad / bell / soft lead / 铺底），不是舞曲骨架。
> **用法**：数值是起点不是法则，以耳朵为准；与本技能既有硬规则冲突时，以技能规则为准。
> **情绪驱动**：按情绪查配方 `emotion-arrangement-recipes.md`、按情绪查和弦 `emotion-chord-index.md`、钢琴/小提琴/手风琴写法 `core-instruments.md`。
> **标注**：【源】/【事实】= 可核实；【验】= 交叉验证；【经验】/【通用理论补充】= 惯例或未单条核实，可放心改。

---


> **定位**：`emotion-arrangement-recipes.md`（研究稿 `11-emotion-recipes.md`）管**情绪坐标**（效价 × 唤醒 × 强度，决定痛不痛、激不激动）；**本册管「质感层」**——梦幻 / 宏大 / 悲壮 / 神秘这类「感」，不是效价–唤醒能覆盖的，而是**空间 / 音色 / 织体 / 音区 / 时间形状**共同塑造的结果。一张卡 = 一个感 = 一份可直接落进工程的处方。
> **信条**：所有建议都给可执行的数值和顺序，不给废话。**数值是起点不是法则，以耳朵为准。**
> **标注**：【事实】＝有出处、可核实（音域与 Hz、和弦构成、调式定义、混响类型语义，引 `classic-arrangement.md` / `chord-library.md` / `mixing.md` / `12-core-instruments.md`）；【经验】＝业界惯例 / 参数起点；【通用理论补充】＝跨来源综合、未核实到单条 BV 的配器常识。**卡内所有具体数值（秒 / ms / velocity / dB / 层数 / % / 小节数）默认【经验】起点，不逐格重复标注**；和弦构成、调式、音域数值为【事实】。
> **口径**：中央 C = **C4 = MIDI 60 = 261.63 Hz**，A4 = 440 Hz（沿用 `chord-library.md` §0 / `12-core-instruments.md` §0）。音名后括号内为 Hz 区间。钢琴 A0–C8、小提琴 G3–E7、手风琴右手 F3–A6 / 左手 Stradella C2–B3【事实】。力度用 MIDI velocity（pp≈30–45 / p≈45–60 / mp≈60–75 / f≈90–110 / ff≈110–127）【经验】。

## 1. 感 → 一页速查（12 个感）

> 「最关键 1 个参数」= 该感一旦改错就不成立的那一个旋钮；混响为 RT60 秒数。

|---|---|---|---|---|---|---|---|

## 2. 情绪 + 场景感 怎么叠加（4 步决策顺序）

> **分工**：情绪是「里子」（调式 / BPM / 和弦骨架 / 密度曲线 / 段落弧线），场景感是「面子」（空间 / 音色 / 织体 / 音区 / 时间形状）。**同一情绪可换多套感**（悲伤 → 空灵 / 苍凉 / 压抑 / 破败），**同一感可服务多情绪**（宏大感 → 正高唤醒的升华，也可 → 负向的悲壮）。两者冲突时**以情绪层的调式与 BPM 为准，感层只动六个杠杆**。

1. **先锁情绪坐标，别先挑「感」**。定「效价（正/负）× 唤醒（高/低）× 强度（含蓄/宣泄）」→ 查 `emotion-arrangement-recipes.md` 拿**调式、BPM、和弦进行、密度曲线、段落弧线、动态范围**。**想调「痛不痛」动调式，想调「激不激动」动速度，两个别搞反**【事实，`emotional-expression.md` §2.1】。这一步的成果是一张情绪卡，先填完再往下走。
2. **再选 1 个主「感」+ 最多 1 个副「感」**。用 §1 速查表选，再用 §4 相邻感对照表**排除最易混淆的那个**（写梦幻别写成空灵、写宏大别写成悲壮）。感层**不改调式、不改 BPM**——那是情绪层的裁判；感只决定空间 / 音色 / 织体 / 音区 / 时间形状。副感只做点缀（如「宏大 + 一丝神秘」），不叠加两套完整六杠杆，否则层数与混响会打架。
3. **按顺序抄六个杠杆，顺序不能跳**：**音区 → 织体 → 和声色彩 → 空间 → 动态 → 时间形状 → 落三件套**。和声色彩这一步只改**和弦类型 / 注册（簧片 8'/16'/4'）/ 和声节奏（每几小节换）**，**不换调式骨架**；空间与动态放最后，先有骨架再有质感再有混音（`arrangement.md` §1 / SKILL.md 十条硬规则）。三件套分工写明谁主旋律、谁铺和声、谁做低音 / 副旋律。**边界**：卡内「织体层数 / 每小节音符数」是该感的织体质感典型值；**全曲密度曲线（层/件/每小节音符预算）、调式 / BPM、和弦级数骨架、段落弧线小节结构、终止式选择以情绪层 `emotion-arrangement-recipes.md` 为准，不被感层覆盖**；可被 15 号细化的是混响秒数、pre-delay、HPF、音区高度、奏法、音色、时间形状等质感参数（与 `11-emotion-recipes.md` §4.5 口径一致）。
4. **微调 + 试听闭环**。用每卡「调强 / 调弱旋钮表」调强度（**优先动旋钮，不是先加一层乐器**），过「两个失败模式」，再做 **8 小节 loop** 试听；情绪或感在 loop 阶段不成立，先回第 1 步换情绪卡或第 2 步换感，**别硬写 3 分钟**【经验，`instrumental-production.md` §2】。每首都过：满编 ≤ 全曲 30–40%、高潮只 1 个、段落转换有可听见的事件、混响 send 随段落做自动化。

## 3. 六个杠杆的通用口径（读卡前先看）

> 每张卡都按这 6 行给**具体数值**，不写形容词。除注明外均为【经验】起点。

| 杠杆 | 必填字段 | 事实 / 经验分界 |
|---|---|---|
| ① 音区分布 | 主音区（音名 + Hz 区间）、上留白、下留白、**是否用极端音区** | 音名 ↔ Hz 换算【事实】；具体区间【经验】 |
| ② 织体 | 层数、同时发声数、声部间距、节奏密度（每小节音符数）、**是否同度 / 八度叠置** | 三层法、声部间隔 ≥1 八度【事实，`arrangement.md` §4】；数值【经验】 |
| ③ 和声色彩 | 调式 / 和弦类型（挂留、加九、大七、小大七、增三、全音阶、五声、持续音）、功能性强弱、**和声节奏（每几小节换）** | 和弦构成、调式、终止式定义【事实，`chord-library.md`】；换和弦频率【经验】 |
| ④ 空间 | 混响 RT60（秒）、pre-delay（ms）、**early/late 比**、立体声宽度（%）、**是否用长尾与逆向渐入** | 混响类型语义（Room 0.4–0.8 / Plate 1.5–2.5 / Hall 3.0+ s）、pre-delay 口诀、混响走 send【事实，`mixing.md` §4】；具体数值【经验】 |
| ⑤ 动态 | 力度区间（velocity 或 p/mp/f）、渐强时长（小节数）、段落音量差（dB）、**LRA 倾向** | LRA / 纯音乐动态目标【事实，`instrumental-production.md` §6】；区间【经验】 |
| ⑥ 时间形状 | 起音软硬（ms / 奏法）、延音 / 踏板 / 风箱、尾音长度（秒）、**留白比例（%）**、乐句长度（小节） | 留白三用法、Legato/Staccato 情绪指向【事实，`emotional-expression.md` §3/§5.3】；数值【经验】 |

> **空间两条口诀**【事实，`mixing.md` §4】：「贴脸但有大空间」＝**短 pre-delay + 长 decay**；「远」＝**长 pre-delay + 短 decay + 高 wet**。混响 return 做 HPF 600 Hz + LPF 10 kHz；**逆向渐入**只在需要「声音先于来源」的感里用，属通用 reverse 空间处理，不是电子音色。

## 4. 相邻感区分对照表（最易写混的 8 组）

> 写卡前先过这张表；「一句话判据」是闭眼试听时用来裁判的那一个差别。

| 组 | 感 A | 感 B | 一句话判据 | 最容易改错的 3 个数值 |
|---|---|---|---|---|
| 1 | 梦幻 | 空灵 | **梦幻 = 柔焦 + 糖（暖、糊、往下沉、有和声）；空灵 = 透明 + 空（冷、清、往上飘、几乎无和声）** | 主音区 C4–C5 ↔ C5–C6｜和声 maj7/add9 ↔ 五声纯五｜半踏板 CC64 40–70 ↔ 不踩踏板 |

| 3 | 神秘 | 压抑 | **神秘 = 不给答案但有缝隙（点状、稀疏、留白多、力度轻、中高频冷音色）；压抑 = 给压力不给出口（满、闷、低中频堆、不留缝、力度被按平）** | 留白 35–50% ↔ 0–5%｜RT60 1.8–2.6 s ↔ 0.8–1.4 s｜每小节 4–8 音 ↔ 16–24 音 |
| 4 | 苍凉 | 破败 | **苍凉 = 大且空（完整、连续长音、横向留白、旷野）；破败 = 碎且残（断奏、休止、失谐、缺音和弦、纵向断裂、废墟）** | 和声 8 小节不换 ↔ 1 小节内碎换｜连续长音 ↔ 大量休止｜无失谐 ↔ ±15–30 cent |
| 5 | 梦幻 | 圣洁 | 梦幻横向铺、往下沉、柔焦；圣洁纵向叠、只上不下、教堂长音 + 变格终止 | 主音区 C4–C5 ↔ C3–C5｜RT60 2.2–3.0 ↔ 3.5–4.5｜maj9 挂留 ↔ Lydian #4 / IV–I |
| 6 | 宏大 | 黎明 | 宏大是**已经撑开**的静态尺度；黎明是**正在撑开**的过程（音区/层数/混响都在变） | 混响固定 2.8–3.8 s ↔ 3.0→1.5 s 自动化｜层数固定 5–6 ↔ 1→4｜动态阶梯 32 小节 ↔ 16 小节 |
| 7 | 压抑 | 宿命 | 压抑是**同时挤满中低频、放不出来**；宿命是**低音不动、上方怎么变都逃不掉**，织体并不挤 | 声部间距故意 ≤1 八度 ↔ ≥1 八度｜LRA 3–5 ↔ 6–9 LU｜留白 0–5% ↔ 10–20% |
| 8 | 神秘 | 破败 | 神秘音色「冷而不对劲」但结构完整；破败结构「本身就断了」，音色钝、失谐、带噪声残留 | 和声 3–4 小节才换 ↔ 1 小节碎换｜点状 staccato 干净 ↔ 残片 + 击槌/键噪｜尾音 1–2 s 切净 ↔ 尾音后硬切 |

## 5. 场景感配方卡（12 张；S01–S04 为点名感，写最细）

### S01　梦幻感（点名 · 最细）
> **一句话**：像隔着一层柔光看东西，轮廓软、边界化开、不落地，且带一点和声糖分。｜**区分**：柔焦 + 糖，别写成「透明 + 空」的空灵（§4 组 1）。

**六杠杆**【经验】起点，以耳朵为准
| 杠杆 | 具体参数 |
|---|---|
| ① 音区 | 主 **C4–C5（261–523 Hz）**；上留白到 C6（1047 Hz）不填实、只放 1 层泛音光泽；下留白 C3（131 Hz）以下不住音，仅 m1 一个 A2（110 Hz）触点；**不用极端音区**（用了就变冷、变空灵） |
| ② 织体 | **3 层**（旋律 / 铺底 / 低频点）；同时发声 **4–6 音**；声部间距 **≥1 八度**；每小节 **6–10 音**；**旋律不叠同度**，偶尔高八度轻叠（叠层 velocity 减半，如 55→28） |
| ③ 和声 | 大调 Ionian / Lydian；**maj7、add9、maj9、6/9、sus4→maj7 挂留不解决**；功能性**弱**；和声节奏 **2–4 小节换 1 次**【和弦构成【事实】`chord-library.md`】 |
| ④ 空间 | RT60 **2.2–3.0 s**（Plate→Hall）；pre-delay **40–70 ms**（远）；early/late **20/80**（后期为主，糊得柔）；宽度 **80–95%**；**用长尾 + 逆向渐入**（把厅堂尾音提前露出，通用 reverse 空间处理，非电子音色） |
| ⑤ 动态 | velocity **40–65（p–mp）**；渐强 **8–16 小节极缓**（每 8 小节 +5–8）；段落差 **4–6 dB**；LRA **5–8 LU**（压平，别有起伏把人叫醒） |
| ⑥ 时间形状 | 起音**软**（钢琴半踏板、弦乐 flautando 慢起 **80–150 ms**）；踏板 **每 2–4 小节半踏换**、风箱换向留 **60–80 ms** 气口；尾音 **2–4 s 不切**；留白 **20–30%**；乐句 **4–8 小节** |

**三件套配置**
| 乐器 | 音区 / 奏法 / 角色 / 力度 / 踏板·风箱 |
|---|---|
| 钢 | **主旋律 + 和声**，C4–C5；半踏板 CC64 **40–70** + 弱音踏板 una corda；legato vel **40–60**；琶音内音起音错开 **25–40 ms**（低音先落） |
| 小 | **铺和声 / 氛围长音**，D4–A4（294–440 Hz）；sul tasto / flautando + con sordino；慢宽揉弦 **4–5 Hz / ±15 cent**；每 4 小节才动一次，vel **40–55** |
| 手 | **低频点 + 气声**，左手 16' A2（110 Hz）单音每 **2 小节 1 次**；右手 8' 极稀疏长音；风箱轻推、换向留 **60–80 ms** 气口；vel **35–50** |

**调强 / 调弱旋钮**
| 可调项 | 调强 | 调弱 |
|---|---|---|
| 混响 RT60 | 3.0–3.6 s | 1.6–2.0 s |
| 半踏板深度 CC64 | 70–90 | 20–40 |
| 和声延伸音 | maj9 / 6-9 / 双挂留 | 纯三和弦 |
| 每小节音符数 | 4–6 | 10–14 |
| 起音软化 | 120–200 ms | 40–60 ms |

**两个失败模式**：① **写成模糊一团**（轮廓全糊、听不出旋律）→ **修正**：保住一条旋律层用近场短混响（RT60 **1.2 s** / pre-delay **20 ms**），只把铺底层推到 **2.8 s**；**层间混响时间差 ≥1 s**，旋律永远别和铺底泡进同一个 send。② **写成空灵 / 圣洁**（太冷太亮太稀）→ **修正**：主音区压回 C4–C5、加 maj7/add9 糖分、起音软化到 120 ms、尾音别切干净；**8–12 kHz 降 1–2 dB** 去冷光泽。

**8 小节微型织体**（C 大调 / 4/4 / 72 BPM / 半踏板）
| 小节 | 和弦 / 音型 | 每层进出 |
|---|---|---|
| 1–2 | Cmaj9（每和弦 2 小节） | m1 钢半踏板琶音 E4–G4–B4–D5（错开 30 ms）+ 手 A2 单点；m2 小 flautando 长音 G4 进（全 2 小节） |
| 3–4 | Am9 | 小上移 B4 长音；钢右手加高八度 D5 轻叠 vel 减半；手右手 8' E4 长音进 |
| 5–6 | Fmaj7 | 钢左手落 F2（**全曲唯一低频**）、半抬踏板换一次；三声部尾音 overlap 不切 |
| 7–8 | Gsus4（挂住，不解决到 G） | 钢旋律停 9 音 D5、m8 留 **2 拍全空**；混响尾 **3 s** 自然消散 |

### S02　宏大感 / 壮阔（点名 · 最细）
> **一句话**：空间被上下撑开、两端占满、有抬升但不必悲，是**尺度感**不是情绪痛感。｜**区分**：尺度 ≠ 尺度 × 代价；别写成小调半终止的悲壮（§4 组 2）。

**六杠杆**【经验】起点，以耳朵为准
| 杠杆 | 具体参数 |
|---|---|
| ① 音区 | 主 **C3–C6（131–1047 Hz）全铺**；上到 C6–E6（1047–1319 Hz）光泽层；下到 **C2（65 Hz）** 地基；**用极端两端**（低 C2 + 高 E6），但**中间不空**（C3–C5 有和声填满） |
| ② 织体 | **5–6 层**（低音 / 和声 / 副旋律 / 主旋律 / 色彩 / 节奏）；同时发声 **8–14 音**；声部间距 **≥1 八度**，两端可八度叠；每小节 **20–32 音**；**主旋律八度叠奏**（低八度同 vel、高八度 vel −10） |
| ③ 和声 | 大调 Ionian / **Lydian(#4)**；I–V–vi–IV → **bVI–bVII–I** 英雄收尾；柱式 / 四部和声；功能性**中→强**；和声节奏 **1–2 小节换 1 次**【【事实】`chord-library.md` §1.5 / §2.3】 |
| ④ 空间 | RT60 **2.8–3.8 s**（Hall）；pre-delay **20–35 ms**（短 pre-delay + 长 decay＝贴脸但大空间）；early/late **30/70**；宽度 **90–100%**；**用长尾、不用逆向渐入**（要清晰起音宣告） |
| ⑤ 动态 | velocity **55→115（pp→ff 阶梯）**；渐强 **16–32 小节**（每 8 小节 **+10–15**）；段落差 **12–18 dB**；LRA **12–18 LU**（要听得见渐强） |
| ⑥ 时间形状 | 起音**硬**（钢八度硬击 vel **110–127**、弦乐整弓 détaché、定音鼓滚奏）；踏板 **每和弦换**；尾音 **3–5 s**；留白 **5–10%**（仅高潮前 1 小节抽空）；乐句 **8–16 小节** |

**三件套配置**
| 乐器 | 音区 / 奏法 / 角色 / 力度 / 踏板·风箱 |
|---|---|
| 小 | **主旋律**，A5–E6（880–1319 Hz）；整弓连奏 + 上跳八度 + 快揉弦 **6–8 Hz**；可扩弦乐组齐奏；vel **90–115** |
| 钢 | **低音 + 和声支点**，C2–C4；八度低音 + 柱式和弦硬击；vel **100–120**；踏板每和弦换 |
| 手 | **和声墙**，全注册 **16'+8'+4'** 柱式和弦 + 句尾 bellows shake；风箱满推 + crescendo；vel **85–115** |

**调强 / 调弱旋钮**
| 可调项 | 调强 | 调弱 |
|---|---|---|
| 层数 | 6–7 | 3–4 |
| 主旋律音区 | C6–E6（1047–1319 Hz） | C5–G5（523–784 Hz） |
| 渐强长度 | 32 小节 | 8 小节 |
| 八度叠置 | 主旋律 + 低八度全叠 | 只留单旋律 |
| 段落差 | 18 dB | 8 dB |

**两个失败模式**：① **从头就满编 → 高潮「大不起来」** → **修正**：从**单音 drone** 起步每 8 小节加 1 层，**高潮前 4–8 小节减层撤到 2 层**；全奏 ≤ 全曲 **30–40%**；高潮全曲只来 1 次。② **只推音量不推密度 / 音区 → 响而不壮阔** → **修正**：按三层法逐层开合（Climax 层数给到 5–6），主旋律**上跳八度**、低音保持 C2，把「宽」交给 **C2–C6 音区跨度**而不是 fader。

**8 小节微型织体**（D 大调 / 4/4 / 96 BPM / Build 段）
| 小节 | 和弦 / 音型 | 每层进出 |
|---|---|---|
| 1–2 | D（每和弦 2 小节） | m1 钢左手 D2 八度 drone（vel 60）+ 手 16' D2 长音；小 D5 单音主题起｜m2 小上跳 A5，钢右手 D–F#–A 柱式（vel 75） |
| 3–4 | A/C# | 手全注册 +8' 进、每 2 小节 1 次 bellows shake；钢柱式转八度 |
| 5–6 | Bm → G | 小主题高八度 **D6** 齐奏，钢八度低音 D2+D3，vel **95** |
| 7–8 | G → 准备 bVI–bVII–I | m7 **全声部全停 1 拍**（抽空）｜m8 全注册 + 小 D6 + 钢八度硬击 vel **115** 进 Climax |

### S03　悲壮感 / 壮烈（点名 · 最细）
> **一句话**：大尺度 + 明确的代价 / 牺牲感，往前行进但不凯旋，像「明知不可为而为之」。｜**区分**：宏大是亮的大调凯旋，悲壮是暗的小调行进 + 半终止不解决（§4 组 2）。

**六杠杆**【经验】起点，以耳朵为准
| 杠杆 | 具体参数 |
|---|---|
| ① 音区 | 主 **G3–C5（196–523 Hz）中低区**；上到 **G5（784 Hz）只做「最后一次抬升」一次即收**；下到 **C2（65 Hz）持续低音**；**不铺满高频光泽**（C6 以上不住音）；**不用极端高音区** |
| ② 织体 | **4–5 层**；同时发声 **6–10 音**；声部间距 **≥1 八度**；每小节 **12–20 音**（附点节奏为主）；**低音八度叠**加厚，**主旋律不叠高八度**（避免太亮） |
| ③ 和声 | 自然 / **和声小调**；i–iv–V–i、i–VII–VI–VII、**主音 pedal**；bVI–bVII 收尾但**停半终止 V 不给归宿**；功能性**中**；和声节奏 **2 小节换 1 次**【【事实】`chord-library.md` §2.4 / §2.7】 |
| ④ 空间 | RT60 **2.5–3.2 s**（Hall）；pre-delay **25–40 ms**；early/late **30/70**；宽度 **70–90%**（收，不飘）；**用长尾**（牺牲感靠尾音拖住）、**不用逆向渐入** |
| ⑤ 动态 | velocity **50→105（mp→ff，但封顶 105 留「沉」）**；渐强 **16–24 小节**；段落差 **10–14 dB**；LRA **10–14 LU** |
| ⑥ 时间形状 | 起音**中硬**（附点 + 弦乐 martelé 顿弓、portamento **80–200 ms**）；踏板 **每 1–2 小节换**、弦乐长音 **4–8 拍**；尾音 **3–4 s**；留白 **10–15%**（句尾抽 1 拍「哽住」）；乐句 **8 小节** |

**三件套配置**
| 乐器 | 音区 / 奏法 / 角色 / 力度 / 踏板·风箱 |
|---|---|
| 小 | **主旋律 / 哭喊**，D4–A5（294–880 Hz），从 **G 弦厚区**起；整弓 + portamento + 快揉弦 **6–8 Hz**；vel **70–100** |
| 钢 | **低音 + 和声**，C2–C4；八度低音持续 + 柱式和弦 + 附点；vel **80–105**；踏板每和弦换 |
| 手 | **地基 + 行进**，左手 16' bass 附点 oom-pah + 右手 8' 柱式；风箱重推 + 句尾 bellows shake；vel **75–100** |

**调强 / 调弱旋钮**
| 可调项 | 调强 | 调弱 |
|---|---|---|
| 调式 | 和声小调 V（导音 G# 收紧） | 自然小调（无导音，更认命） |
| 附点密度 | 每小节 2–3 组 | 每小节 1 组 |
| 终止 | 半终止停 V | 完全终止 V7–i |
| 主旋律上抬 | 到 G5 一次即收 | 不超过 D5 |
| 低音 | C2 持续不动 | 每小节动一次 |

**两个失败模式**：① **写成宏大凯旋**（太亮、大调、完全终止）→ **修正**：换小调、撤 C6 以上高频光泽、末句**停 V 不解决**、主旋律压回 G3–C5 中低区。② **写成单纯悲伤**（尺度没了）→ **修正**：保留 4–5 层与 **C2 持续低音**、加附点行进、渐强给到 **16 小节**——「哭」要站在「队伍」上。

**8 小节微型织体**（d 小调 / 4/4 / 84 BPM / 附点，pedal D2 全 8 小节不动）
| 小节 | 和弦 / 音型 | 每层进出 |
|---|---|---|
| 1–2 | Dm（每和弦 2 小节） | 钢左手 D2 八度持续 + 右手附点 Dm 柱式；手 16' D2 oom 进 |
| 3–4 | B♭ | 小 G 弦 D4 起主题（附点 D–F–A，vel 75），portamento 到 A4 |
| 5–6 | F | 手右手 8' 柱式 + 句尾 bellows shake；小上抬到 D5 |
| 7–8 | C（停 V，不回 Dm） | m7 小最后一次上跳 **G5** 后即下行、钢八度硬击 vel **100**｜m8 停 C 柱式 + **全声部留 1 拍空**，小悬 A4 **不解决**，混响尾 **3.5 s** |

### S04　神秘感 / 诡谲（点名 · 最细）
> **一句话**：有东西藏着、方向不明、和声不落地，音色带一点「不对劲」的冷感。｜**区分**：不给答案**但有缝隙**（点状、稀疏、留白多、力度轻）；别写成满、闷、不留缝的压抑（§4 组 3）。

**六杠杆**【经验】起点，以耳朵为准
| 杠杆 | 具体参数 |
|---|---|
| ① 音区 | 主 **A3–E5（220–659 Hz）中高区**；上到 **C6（1047 Hz）** 只放泛音 / 靠琴马点；下到 **C2 只留 1 个持续音**；**用极端高音区做点状色彩**（自然泛音、sul ponticello），不铺满 |
| ② 织体 | **2–3 层**（点状 / 持续 / 低音）；同时发声 **3–5 音**；声部间距**宽 ≥1 八度**，常用空五度 / 四度叠置；每小节 **4–8 音**（稀疏点状 + pizzicato）；**不同度叠、不八度叠**（避免太实） |
| ③ 和声 | 无稳定调性 / c 小调 **Phrygian 味**；**增三、减七、全音阶、四度叠置、三全音 line、属七挂住不解决**；功能性**弱→无**；和声节奏 **3–4 小节才换 1 次**或 pedal 不动【【事实】`chord-library.md` §1.9 / §2.6 / §2.8】 |
| ④ 空间 | RT60 **1.8–2.6 s**（Room→Plate）；pre-delay **50–90 ms**（远、把主音推后）；early/late **40/60**（早期反射多＝「空间里有动静」）；宽度 **60–80%**（别太宽，留暗处）；**短中尾 + 偶尔逆向渐入**（声音先于来源，通用 reverse 空间处理） |
| ⑤ 动态 | velocity **30–55（p，被按住）**；渐强**几乎无**（≤4 小节微 +10）；段落差 **3–5 dB**；LRA **4–7 LU**（平） |
| ⑥ 时间形状 | 起音**点状硬但短**（pizzicato、staccato note length **30–50%**、col legno）；踏板**浅 CC64 0–20 或不踩**；尾音 **1–2 s 切干净**（留「没说完」）；留白 **35–50%**（每 4 小节 1–2 拍全空）；乐句 **2–4 小节**（短、不完整） |

**三件套配置**
| 乐器 | 音区 / 奏法 / 角色 / 力度 / 踏板·风箱 |
|---|---|
| 钢 | **点状 / 持续**，C3–C5；staccato 增三 / 减七分解 vel **35–55** + **预备泛音**（silent depression 共振）；踏板几乎不踩 |
| 小 | **色彩**，D4–A5；泛音 / **sul ponticello** / col legno、pizzicato 点音；**无揉弦**（冷）；vel **30–50** |
| 手 | **低音持续 + 气声**，左手 16' C2 单音长音（每 4 小节才动）；右手 4' musette 单簧极稀疏（诡异疏离）；风箱极轻推几乎不动 |

**调强 / 调弱旋钮**
| 可调项 | 调强 | 调弱 |
|---|---|---|
| 和声解决 | 完全不解决（增三 / 全音阶） | 偶尔 V→i 解决一次 |
| 起音 | note length 30% 点状 | legato 80% |
| 留白 | 50% | 25% |
| 冷音色 | sul ponticello + 泛音 | sul tasto |
| pre-delay | 90 ms | 30 ms |

**两个失败模式**：① **写成压抑**（太满太闷）→ **修正**：撤层到 2–3、每小节砍到 **4–6 音**、留白拉到 **40%**、除 1 个 C2 持续音外全部 **HPF 120 Hz**，把「缝隙」还回来。② **写成恐怖片音效堆砌**（全是噪音没了音乐）→ **修正**：保住 **1 条可跟的 2–4 音短动机**，和声 **3–4 小节才换一次**，点状色彩只做点缀不持续。

**8 小节微型织体**（c 小调 / 无调性 / 4/4 / 72 BPM）
| 小节 | 和弦 / 音型 | 每层进出 |
|---|---|---|
| 1–2 | C 增三（C–E–G#）持续 4 小节 | m1 钢 staccato 分解 C4–E4–G#4（vel 40，note length 40%）不踩踏板｜m2 小 sul ponticello 长音 G4（vel 35 无揉弦）+ 手 16' C2 持续进 |
| 3–4 | 同上 | m3 **全空 2 拍** → 钢高音预备泛音 C6 单点｜m4 手 4' musette 单音 E5 气声，风箱不动 |
| 5–6 | 减七（B–D–F–A♭）2 小节 | 小 col legno 点状 + 钢 staccato，每小节留白 1 拍 |
| 7–8 | F# 三全音 pedal 2 小节（不解决） | 只留手 16' + 钢 C2 单音，其余全撤；尾音**切干净 1.5 s**，停三全音不解决 |

### S05　空灵 / 缥缈
> **一句话**：冷、清、稀、往上飘，几乎没有和声，像声音从很远的地方浮出来。｜**区分**：透明 + 空，别写成柔焦 + 糖的梦幻（§4 组 1）。

**六杠杆**【经验】起点
| 杠杆 | 具体参数 |
|---|---|
| ① 音区 | 主 **C5–C6（523–1047 Hz）**；上到 E6–G6（1319–1568 Hz）泛音；下 **C4 以下完全不住音**（仅起点 1 个 C3 触点）；**用极端高音区** |
| ② 织体 | **1–2 层**；同时发声 **2–3 音**；间距 **≥2 八度**；每小节 **2–4 音**；**不叠置** |
| ③ 和声 | 五声（宫 / 羽）或 Lydian；纯五 / 大二为主、**几乎无三音**；功能性**无**；**4–8 小节不换**或单音 pedal |
| ④ 空间 | RT60 **3.5–4.5 s**（Hall）；pre-delay **60–100 ms**；early/late **15/85**；宽度 **90–100%**；**超长尾 + 逆向渐入**（让音「从空间里浮出来」） |
| ⑤ 动态 | velocity **25–45（pp）**；**无渐强**；段落差 **2–4 dB**；LRA **3–6 LU** |
| ⑥ 时间形状 | 起音**极软**（泛音、flautando 慢起 **200 ms+**）；无踏板 / 风箱极慢；尾音 **4–6 s 不切**；留白 **50–65%**；乐句 **8–16 小节** |

**三件套**：**钢**＝高音区单音 / 预备泛音 C5–C6 vel 30–45、不踩踏板；**小**＝Harmonics 自然泛音 / flautando 高把位 vel 25–40、无揉弦；**手**＝4' 单簧极稀疏长音或**全撤**，风箱几乎不动。
**调强 / 调弱**：混响 4.5–5.5 s ↔ 2.8–3.2 s｜留白 65% ↔ 40%｜主音区 C6–G6 ↔ C5–C6｜每小节 2 音 ↔ 5 音｜起音 250 ms ↔ 80 ms。
**两个失败模式**：① 写成梦幻（有和声糖分、往下沉）→ **修正**：删三音与延伸音、主音区抬到 C5 以上、尾音不切、留白拉到 60%。② 写成「什么都没听见」→ **修正**：保住 1 条 2–3 音可辨动机，每 8 小节出现 1 次，别全程只有混响尾。
**8 小节微型织体**（C 宫五声 / 自由拍 ≈56 BPM）：m1 钢预备泛音 C6 单点｜m2 小自然泛音 G6 长音进（2 小节）｜m3–4 **全空**｜m5 钢 C6–D6 二度点（vel 35）｜m6 手 4' E6 单音气声｜m7–8 只留混响尾 5 s 自然消散，**不渐强、不解决**；pedal C3 仅 m1 触一次。

### S06　苍凉 / 荒芜
> **一句话**：大而空、完整、像旷野，靠**横向留白**而不是纵向断裂。｜**区分**：大且空 ≠ 碎且残的破败（§4 组 4）。

**六杠杆**【经验】起点
| 杠杆 | 具体参数 |
|---|---|
| ① 音区 | 主 **G3–D5（196–587 Hz）**；上到 A5（880 Hz）只放 1 个孤零零的音；下到 **G2（98 Hz）空旷低音**；**用低音区宽度但不铺满**；不用极端高音区 |
| ② 织体 | **2 层**（一支独奏旋律 + 1 个持续低音）；同时发声 **2–3 音**；间距 **≥2 八度**；每小节 **2–5 音**；**不叠置** |
| ③ 和声 | 羽五声 / Dorian；**pedal 持续音**、平行四五度；功能性**无**；**8 小节不换** |
| ④ 空间 | RT60 **3.0–4.0 s**；pre-delay **50–80 ms**；early/late **20/80**；宽度 **80–95%**；**用长尾**（风声般），不用逆向渐入 |
| ⑤ 动态 | velocity **30–50**；**无渐强**（可渐弱）；段落差 **3–5 dB**；LRA **4–7 LU** |
| ⑥ 时间形状 | 起音**软**（长弓 150 ms+）；风箱慢推每 4 小节换向、留 60 ms 气口；尾音 **4–6 s**；留白 **45–60%**；乐句 **8–16 小节**；**结尾自然消散、不渐强** |

**三件套**：**小**（或手）＝独奏主旋律 G3–D5、长弓 legato vel 35–50、慢宽揉弦；**手**＝左手 16' G2 单音长音每 4 小节 1 次、风箱极慢；**钢**＝几乎全撤，只在中段 C4 一个单音点（vel 30–40）。
**调强 / 调弱**：混响 4.0–5.0 s ↔ 2.2–2.8 s｜留白 60% ↔ 30%｜主音区 G3–D5 ↔ C4–G5｜每小节 2 音 ↔ 6 音｜层数 2 ↔ 3。
**两个失败模式**：① 写成破败（加断奏 / 失谐 / 缺音和弦）→ **修正**：删所有休止型断裂、和声改回 8 小节不换的 pedal、旋律改连续长弓。② 写成孤独但「小」了 → **修正**：混响拉到 3.5 s+、低音放到 G2、留白拉到 50%，「旷野」靠空间尺寸不靠音符数。
**8 小节微型织体**（a 羽五声 / 4/4 / 60 BPM）：pedal 手 16' A2 全 8 小节｜m1–2 小 G 弦 A3 长音主题（vel 40，2 小节不动）｜m3–4 **留 2 拍全空**后小上到 C5｜m5–6 钢 C4 单音点 1 次（vel 35）｜m7–8 小回 A3 渐弱到 pp，**尾音 5 s 自然消散、不渐强**。

### S07　圣洁 / 神性
> **一句话**：教堂长音、只上不下、变格收束，纵向叠而不横向铺。｜**区分**：别写成往下沉、柔焦的梦幻（§4 组 5）。

**六杠杆**【经验】起点
| 杠杆 | 具体参数 |
|---|---|
| ① 音区 | 主 **C3–C5（131–523 Hz）**；上到 C6 只放泛音光泽；下到 C2（65 Hz）管风琴式地基；**不用极端高音区做旋律**；主题**逐级抬高** |
| ② 织体 | **5–6 层但节奏稀**（长音为主）；同时发声 **6–10 音**；间距 **≥1 八度**；每小节 **6–12 音**（附点长音）；**低音八度叠**、主旋律不叠 |
| ③ 和声 | **Lydian(#4)**；柱式四部、**IV–I 变格终止**、K46–V7–I；功能性**中→强**；和声节奏 **2–4 小节换 1 次**【【事实】`chord-library.md` §2.7】 |
| ④ 空间 | RT60 **3.5–4.5 s**（教堂 / Hall）；pre-delay **30–50 ms**；early/late **20/80**；宽度 **85–100%**；**长尾、弱拍不抢**、不用逆向渐入 |
| ⑤ 动态 | velocity **45–85（p→f）**；渐强 **16–24 小节**；段落差 **8–12 dB**；LRA **8–12 LU** |
| ⑥ 时间形状 | 起音**软中带庄严**（整弓长音、附点）；踏板 **每 2 小节换**、风箱满推匀速；尾音 **4–5 s**；留白 **15–25%**；乐句 **8 小节** |

**三件套**：**手 / 钢**＝管风琴式长音和声墙，C3–C5 全注册 16'+8' 柱式长音 vel 55–80；**小**＝主旋律 D5–A5、只上不下、整弓 vel 65–85、慢宽揉弦；**钢左手**＝C2 八度地基 vel 60–75。
**调强 / 调弱**：混响 4.5–6.0 s ↔ 2.5–3.0 s｜层数 6–7 ↔ 3–4｜主题抬升 每 4 小节 +2 半音 ↔ 不抬｜Lydian #4 保留 ↔ 改自然大调｜段落差 12 dB ↔ 6 dB。
**两个失败模式**：① 写成宏大凯旋（bVI–bVII–I、ff、八度齐奏）→ **修正**：换 **IV–I 变格终止**、力度封顶 f（vel ≤85）、撤八度齐奏改长音叠。② 写成梦幻（sus 挂留不解决、往下沉）→ **修正**：给一次明确的变格终止、主题只上不下、起音加附点庄严感。
**8 小节微型织体**（C 大调·Lydian / 4/4 / 64 BPM）：m1–2 钢 + 手长音 C 柱式（vel 55）｜m3–4 小主题 E5→F#5（#4 提亮，只上不下，vel 70）｜m5–6 换 F（IV）柱式长音、钢左手 C2 八度进｜m7–8 **IV–I 变格终止**回 C，全声部长音 + 混响尾 4.5 s，**弱拍不抢**。

### S08　压抑 / 窒息
> **一句话**：满、闷、低中频堆、力度被按住放不出来，**不给缝**。｜**区分**：给压力不给出口 ≠ 不给答案但有缝隙的神秘（§4 组 3）；也别写成低音不动的宿命（§4 组 7）。

**六杠杆**【经验】起点
| 杠杆 | 具体参数 |
|---|---|
| ① 音区 | 主 **C2–C4（65–262 Hz）中低堆**；上留白 **C5 以上几乎不进**；下到 C2；**不用极端高音区**（用了就有出口） |
| ② 织体 | **4–5 层但全挤中低频**；同时发声 **8–12 音**；声部间距**故意 ≤1 八度**（挤）；每小节 **16–24 音** 十六分 ostinato；**同度 / 八度叠置加厚** |
| ③ 和声 | 小调 / **Phrygian**；**line cliché**（Am–Am(maj7)–Am7–Am6）、pedal；功能性**弱**；和声节奏 **1 小节换 1 次或不换**【【事实】`chord-library.md` §1.9】 |
| ④ 空间 | RT60 **0.8–1.4 s**（Room，近、干、闷）；pre-delay **10–20 ms**；early/late **50/50**；宽度 **30–50%**（窄）；**无长尾、不用逆向渐入**（闷住） |
| ⑤ 动态 | velocity **55–75** 但**被按住**（不渐强）；渐强 **0 小节**；段落差 **2–4 dB**；LRA **3–5 LU**；母线轻压 GR **4–6 dB** 压平【经验】 |
| ⑥ 时间形状 | 起音**钝**（con sordino、una corda、低音区、note length 80–95%）；**踏板长不换**（叠糊）、风箱匀速**不换气**；尾音 **0.5–1 s 切**；留白 **0–5%**；乐句 **4 小节循环 ostinato** |

**三件套**：**钢**＝中低区 ostinato 十六分 C2–C4 vel 55–70 + una corda、踏板 2 小节不换；**小**＝G 弦 con sordino **震弓 tremolo** 低音区 vel 50–65、无揉弦；**手**＝16' bass + 8' 柱式挤中低、风箱匀速不换向、vel 55–70。
**调强 / 调弱**：留白 0% ↔ 10%｜LRA 3 LU ↔ 7 LU｜声部间距 ≤1 八度 ↔ ≥1 八度｜每小节 24 音 ↔ 12 音｜RT60 0.8 s ↔ 1.8 s。
**两个失败模式**：① 写成神秘（留白多、点状、冷高音）→ **修正**：砍留白到 0–5%、每小节加回 16–24 音、撤 C5 以上音、混响压到 1.2 s。② 写成「只是难听的浑」→ **修正**：中低频虽挤但**保留 1 条可辨 ostinato 动机**，200–500 Hz 只让一件乐器主奏、其余 −2–3 dB（`mixing.md` §6），闷而不糊。
**8 小节微型织体**（a 小调 / 4/4 / 80 BPM / 4 小节循环 ×2）：钢左手 A2 十六分 ostinato（vel 60）全 8 小节不换｜m1 手 16' A2 + 8' 柱式进（vel 60）｜m3 小 G 弦 con sordino tremolo A3 进（vel 55）｜m5 line cliché 顶声部 A→G#→G→F# 半音下沉、**和声每小节微换但 pedal 不动**｜m8 **不渐强、尾音 0.8 s 硬切**，无出口。

### S09　童真 / 童话
> **一句话**：明亮、跳进、点状、脆；留一个挂音防甜腻。｜**区分**：别写成十六分 ostinato + 小调的紧张。

**六杠杆**【经验】起点
| 杠杆 | 具体参数 |
|---|---|
| ① 音区 | 主 **C4–C6（261–1047 Hz）中高**；上到 C6 钟琴 / 钢片琴点；下到 C3（131 Hz）轻低音；**用一点极端高音区做点状**，不铺满 |
| ② 织体 | **3–4 层**；同时发声 **4–6 音**；间距 **≥1 八度**；每小节 **12–20 音**；**跳进多于级进**（单次 ≥纯四度 5 半音）；**不叠八度**（保持脆） |
| ③ 和声 | 大调 / **宫五声**；1645、I–V–vi–IV；三和弦 + **1 个 maj7 挂住防甜腻**；功能性**中**；和声节奏 **1–2 小节换 1 次**【【事实】`chord-library.md` §1.2 / §1.5】 |
| ④ 空间 | RT60 **1.0–1.6 s**（Room / Plate，干、近）；pre-delay **15–30 ms**；early/late **40/60**；宽度 **60–80%**；**短尾、不用逆向渐入** |
| ⑤ 动态 | velocity **55–85（mp–f）**；渐强 **4–8 小节**；段落差 **6–10 dB**；LRA **6–10 LU** |
| ⑥ 时间形状 | 起音**脆**（staccato note length **40–60%**、spiccato、钟琴点音）；踏板**短换**、风箱轻快每 2 小节换向；尾音 **0.8–1.5 s**；留白 **15–25%**；乐句 **4 小节** |

**三件套**：**钢**＝主旋律 staccato + 高音点 C5–C6 vel 60–80、踏板每和弦换；**小**＝spiccato 跳弓副旋律 D5–A5 vel 60–75；**手**＝8' 轻 oom-pah 或**全撤**，**musette 别全开**（全开＝甜腻破坏童真）。
**调强 / 调弱**：跳进 纯五–八度 ↔ 级进为主｜note length 40% ↔ 70%｜每小节 20 音 ↔ 8 音｜RT60 1.0 s ↔ 2.0 s｜maj7 挂音保留 ↔ 删（更甜）。
**两个失败模式**：① 写成甜腻儿歌（全三和弦、musette 全开、无挂音）→ **修正**：留 1 个 maj7 或 sus4 挂住、手风琴只开 8'、加一次跳进。② 写成紧张 → **修正**：换大调 / 宫五声、每小节降到 12–16 音、staccato 改 spiccato 轻跳。
**8 小节微型织体**（C 大调 / 3/4 / 116 BPM）：m1–2 钢 staccato 主旋律 C5–G5 跳进（vel 70，note length 50%）｜m3 钟琴 / 钢高音 C6 点音进｜m4 小 spiccato 副旋律 E5–A5｜m5–6 换 F（IV）、手 8' 轻 oom-pah 进｜m7 **挂一个 Cmaj7（B4 挂住）** 防甜腻｜m8 回 C、留 1 拍空、尾音 1.2 s 切干净。

### S10　破败 / 废墟
> **一句话**：结构本身碎了——断奏、休止、失谐、缺音和弦、纵向断裂。｜**区分**：碎且残 ≠ 大且空的苍凉（§4 组 4）；也别写成结构完整、冷而不对劲的神秘（§4 组 8）。

**六杠杆**【经验】起点
| 杠杆 | 具体参数 |
|---|---|
| ① 音区 | 主 **C3–G4（131–392 Hz）中低碎片**；上到 D5（587 Hz）只放 1 个单点残响；下到 C2 断；**不用极端高音区** |
| ② 织体 | **2–3 层但断裂**；同时发声 **2–4 音**；间距**不规则**（故意不整齐）；每小节 **3–7 音**（大量休止）；**故意失谐 ±15–30 cent**；**无叠置** |
| ③ 和声 | 小调 / 全音阶 / 减和弦 / 增四；**和声「缺音」**（三和弦缺三音或五音）；功能性**瓦解**；和声节奏 **1 小节内碎换**【减七 / 增三构成【事实】`chord-library.md` §2.8】 |
| ④ 空间 | RT60 **2.0–3.0 s** 但**早期反射杂乱**；pre-delay **30–60 ms**；early/late **45/55**；宽度 **50–70%**（不整齐）；**中长尾 + 突然切断**（残），可用逆向渐入做「来源不明」 |
| ⑤ 动态 | velocity **35–60（弱、无力）**；**无渐强**（渐弱）；段落差 **4–6 dB**；LRA **6–9 LU** |
| ⑥ 时间形状 | 起音**钝 / 断**（staccato + 长休止、col legno、**保留击槌与踏板噪声**）；踏板**不换**让残响糊；尾音 **1–2 s 后硬切**；留白 **40–55%（结构性断裂）**；乐句 **2–3 小节不完整** |

**三件套**：**钢**＝中低区残片单音 / 缺音和弦 C3–G4 vel 35–55、保留击槌 / 踏板噪声、踏板不换；**小**＝col legno / sul ponticello 断音 vel 30–50；**手**＝musette **detune ±20 cent** 单音 + 4' 残响，风箱抖动**无规律**。
**调强 / 调弱**：失谐 ±30 cent ↔ ±8 cent｜留白 55% ↔ 25%｜每小节 3 音 ↔ 8 音｜缺音和弦 ↔ 完整三和弦｜尾音硬切 1 s ↔ 留 2.5 s。
**两个失败模式**：① 写成苍凉（连续长音、8 小节不换和声）→ **修正**：加大量休止、改 1 小节内碎换、加 ±20 cent 失谐与缺音和弦。② 写成「弹错了的脏」→ **修正**：失谐只给**一件**乐器、其余保持准；保留 1 个可辨的 2–3 音残片动机，别全程无音高。
**8 小节微型织体**（c 小调 / 4/4 / 66 BPM）：m1 钢 C3 缺三音和弦（C–G，vel 45）+ 击槌噪声｜m2 **全空 2 拍**｜m3 小 col legno 断音 E♭4｜m4 手 musette detune ±20 cent 单音 G4（vel 40）｜m5 全音阶碎片 C–D–F#（vel 35，休止 1 拍）｜m6 **全空**｜m7 钢减和弦残片 B–D–F 硬切｜m8 只留混响尾 **1.5 s 突然切断**，无解决。

### S11　黎明 / 初升
> **一句话**：由暗到亮、由远到近、音区逐级抬升，是「正在撑开」的过程。｜**区分**：过程 ≠ 已经撑开的静态尺度（宏大，§4 组 6）。

**六杠杆**【经验】起点
| 杠杆 | 具体参数 |
|---|---|
| ① 音区 | 起点 **C3–C4（131–262 Hz）**，16 小节内**逐级抬到 C5–C6（523–1047 Hz）**；上留白随抬升打开；下从 C2 pedal 起、末段撤；**末段用一点极端高音区**（初升光泽） |
| ② 织体 | **1 层 → 4 层**（每 4 小节 +1 层）；同时发声 **2 → 8 音**；间距 ≥1 八度；每小节音符 **4 → 16 音**；末段主旋律**轻叠八度**（vel −10） |
| ③ 和声 | 大调 / **Lydian**；**sus4 → 大三解决**（云开）；柱式由稀到满；功能性**弱→中**；和声节奏 **2 小节换 1 次** |
| ④ 空间 | RT60 **3.0 s → 1.5 s 自动化**（全曲唯一的时间形状杠杆）；pre-delay **60 → 25 ms**；early/late 20/80 → 35/65；宽度 **70 → 90%**；**长尾渐收**，8–12 kHz **−2 dB → +2 dB**；不用逆向渐入 |
| ⑤ 动态 | velocity **35 → 85**；渐强 **16 小节**（每 4 小节 +10–12）；段落差 **10–14 dB**；LRA **10–14 LU** |
| ⑥ 时间形状 | 起音**由软到清**（flautando → détaché）；踏板**半踏 → 每和弦换**、风箱由慢推到均匀；尾音 **4 s → 1.5 s**；留白 **35% → 10%**；乐句 **4 → 8 小节** |

**三件套**：**小**＝主题由 G4 逐级抬到 D6、flautando 起 → 整弓、vel 40→85；**钢**＝分解和弦 C3–C5 起步、末段柱式 + 高八度光泽、踏板由半踏到每和弦换；**手**＝m1 仅 16' C2 长音，m9 起 8' 长音渐入、风箱由慢到匀。
**调强 / 调弱**：混响 3.5→1.2 s ↔ 2.5→1.8 s｜抬升 16 小节 ↔ 8 小节｜层数 1→5 ↔ 2→3｜8–12 kHz −2→+3 dB ↔ 不动｜渐强 16 ↔ 8 小节。
**两个失败模式**：① 写成静态宏大（一上来就全铺）→ **修正**：m1 只留 1 层 + C2 pedal，把「变化」排进 16 小节自动化曲线，别跳步。② 写成「只是渐强」→ **修正**：**同时**动混响时间、pre-delay、高频亮度、踏板换频、音区高度 5 条，只有 fader 渐强听不出「天亮」。
**8 小节微型织体**（C 大调·Lydian / 4/4 / 80 BPM，取前 8 小节）：m1 手 16' C2 长音（vel 35）+ 钢 C4 单音｜m3 小 flautando G4 主题进（vel 45）｜m5 加钢分解和弦 C–E–G（每小节 8 音）、换 **Fsus4→F** 第一次「云开」｜m7 手 8' 长音进、RT60 自动化由 3.0 收到 **2.2 s**、pre-delay 60→40 ms｜m8 小抬到 C5、留白由 35% 收到 25%；后 8 小节续抬到 C6 / RT60 1.5 s。

### S12　宿命 / 沉重
> **一句话**：逃不掉——主音低音全程不动，上方和声怎么变都回来。｜**区分**：低音不动 ≠ 同时挤满中低频的压抑（§4 组 7）。

**六杠杆**【经验】起点
| 杠杆 | 具体参数 |
|---|---|
| ① 音区 | 主 **G2–C4（98–262 Hz）低区**；上到 G4（392 Hz）不越过；下到 **C2（65 Hz）pedal 全程不动**；**不用极端音区** |
| ② 织体 | **3–4 层**；同时发声 **5–8 音**；间距 **≥1 八度**（不挤）；每小节 **8–14 音**；附点滚动 + **低音八度叠** |
| ③ 和声 | 自然小调；**i–VII–VI–VII**、**主音 pedal 全程不动**；功能性**弱**（上方变也逃不掉）；和声节奏 **4 小节换 1 次**【【事实】`chord-library.md` §2.4 / §2.6】 |
| ④ 空间 | RT60 **2.0–2.8 s**；pre-delay **30–45 ms**；early/late **30/70**；宽度 **50–70%**（收、不飘）；**中长尾**、不用逆向渐入 |
| ⑤ 动态 | velocity **50–80**；渐强 **16 小节但不释放**（到 mp 就压住、不推 ff）；段落差 **6–10 dB**；LRA **6–9 LU** |
| ⑥ 时间形状 | 起音**钝重**（附点 + 低音整弓）；踏板 **2 小节换**、风箱每 2–4 小节换向留 30–80 ms 气口；尾音 **2–3 s**；留白 **10–20%**；乐句 **8 小节循环** |

**三件套**：**手**＝16' bass 主音 pedal C2 全程不动 + 附点 oom-pah、风箱重推 vel 60–80；**钢**＝低音八度 + 柱式和弦 G2–C4 vel 55–75、踏板 2 小节换；**小**＝G 弦 D4–G4 副旋律 / 长音 vel 50–70、慢宽揉弦。
**调强 / 调弱**：pedal 全程不动 ↔ 每 4 小节动一次｜渐强封顶 mp（vel 80）↔ 推到 ff（vel 110，会变悲壮）｜附点 每小节 2 组 ↔ 1 组｜宽度 50% ↔ 80%｜和声 4 小节换 ↔ 2 小节换。
**两个失败模式**：① 写成悲壮（推到 ff、主旋律上跳 G5、半终止）→ **修正**：力度封顶 vel 80、主旋律不越 G4、pedal 不动、给完全终止也不「凯旋」。② 写成压抑（声部挤 ≤1 八度、LRA 压到 3 LU、留白 0）→ **修正**：声部间距拉回 ≥1 八度、LRA 回 6–9 LU、留白给 10–20%，「沉」靠低音不动不靠挤。
**8 小节微型织体**（a 自然小调 / 4/4 / 68 BPM / **pedal A2 全 8 小节不动**）：m1–2 手 16' A2 + 附点 oom 进、钢左手 A2 八度｜m3–4 小 G 弦 A3 长音副旋律进（vel 55）｜m5–6 上方换 **G（VII）→ F（VI）**（每 2 小节），**pedal 仍 A2 不动**｜m7–8 回 Am、钢柱式 + 小回 A3、vel 只到 **75**、尾音 2.5 s、留 1 拍空，8 小节后原样循环。
