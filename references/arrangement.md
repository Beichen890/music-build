# 编曲与配器

> **制作口径**：本技能默认在 DAW 里作曲编曲（MIDI + 采样音源 + 合成器 + 自动化 + 混音），真实乐器、采样、合成器音色都是合法音色来源。
> **范围分流**：不默认做吵闹的电子舞曲风格（EDM / House / Techno / Trap / 鼓机 drop / riser / 泵感侧链），这类内容见 `electronic-styles.md`。合成器作为色彩与空间层（pad / bell / soft lead / 铺底）在主线里正常使用。

## 1. 歌曲结构

**通用法则：段落长度取 4 / 8 / 16 / 32 小节**——听众是按 4 和 8 计数的。

| 段落 | 长度(bars) | 职能 | 手法 |
|---|---|---|---|
| Intro | 4–16 | 立 tempo、定调、留 mix 空间 | 鼓组+和弦铺底，或单一动机，**不带满编** |
| Verse | 8–16 | 铺陈、建立 groove 与人声身份 | **密度低于副歌**，减层 |
| Pre-chorus | 4–8 | 制造张力 | 抬旋律音高、抽薄鼓组、加弦乐 tremolo 渐强或和声层 |
| Chorus | 8–16 | 情绪与记忆点交付 | 简化歌词、加宽和声、满编 |
| Bridge | 8–16 | 对比与重置 | **换和弦/节奏/音区/织体，至少变两样** |
| Outro | 4–16 | 干净退场 | 抽掉主奏留节奏，或 fade |

> 电子舞曲专用段落（Intro 16–32 / Build-up / Drop / Breakdown）见 `electronic-styles.md` §1，主线不展开。

**流行常用顺序**：
```
Intro – Verse – PreChorus – Chorus – Verse – PreChorus – Chorus – Bridge – Chorus – Outro
```
摇滚把 solo 放在 bridge 位置，职能相同（最终回归前的对比）。

**流媒体时代趋势**：intro 极短甚至没有，**第一个副歌在 40 秒内出现**，总长常压到 3 分钟内。

### 四条硬规则

1. **每 8 或 16 小节必须改变一件明确的事**——加层、减层、换音色、换和弦都行，
   但不能什么都不变。
2. **副歌前先减后加**：进副歌前的 4–8 小节移除 1–2 个主要元素（抽 bass 或鼓），
   副歌回归时对比才成立。
3. **高潮前 4 小节递进**：高潮在第 64 小节，则 48/56/60 逐级加码
   （加层 → 加密 → 抬音区），第 63 小节达到最大张力。
   电子舞曲版（drop / riser / snare roll）见 `electronic-styles.md` §1。
4. **fill（加花）只出现在乐句翻转处**，不要当常态。

## 2. 动态与密度控制

- **能量曲线**：把歌想成一条 1–10 的能量线。副歌 8–10、主歌 4–6、bridge 2–3。
  **相邻段落能量必须不同**，否则听众感知不到结构。
- **三层法**：每段至少区分 `节奏层 / 和声层 / 旋律层` 三档开合。
  Verse 常只开"节奏+旋律"，Chorus 三层全开。
- **避免一直满编**：满编时段不超过全曲的 30–40%。留白是制造"大"的手段。
- **频谱互补**：同一时间不要让两件乐器占同一频段峰值。副歌加 pad 时，
  把吉他 1–2 kHz 挖 2–3 dB / Q=1.0 给人声让位。

## 3. 频率分工表

核心原则：**频段是稀缺地产，每件乐器只拿自己的主战场**；
两件乐器抢同一频段时，必须有一件让路。

| 频段 | 内容 | 用途 |
|---|---|---|
| 20–60 Hz | sub-bass、rumble | **除 kick 与 sub bass 外全部切掉** |
| 60–120 Hz | kick thump、bass body | "oomph" 区，勿过载 |
| 120–250 Hz | 丰满感 / mud | 减此区去浑，谨慎提升 |
| 250–500 Hz | body、boxiness | **人声/吉他的常见病灶区** |
| 500 Hz–1 kHz | presence、鼻音感 | 提清晰度；honky 时减 |
| 1–4 kHz | attack、clarity | snare crack、辅音、拨弦 attack |
| 4–8 kHz | brightness、sibilance | 加 air 或减齿音 |
| 8–12 kHz | air、shimmer | 轻微提升增开阔感 |
| 12–20 kHz | top-end air | 极少量即明显 |

**各乐器"住址"速查：**

| 乐器 | body | 特征区 | 需要处理的 |
|---|---|---|---|
| Kick | 60–80 Hz | attack 2–4 kHz | boxiness 200–400 Hz（cut） |
| Snare | 150–250 Hz | crack 3–5 kHz | air 8 kHz+ |
| Bass | 40–120 Hz | presence 800 Hz–1 kHz | mud 300–500 Hz |
| 电吉他 | 150–300 Hz | main 300 Hz–1.5 kHz | aggression 2–5 kHz |
| 人声 | — | presence 2–5 kHz | 100–250 Hz 可切、nasal 500 Hz–1.2 kHz、air 10 kHz+ |
| 钢琴 | 60–200 Hz | — | mud 200–500、harsh 2–4 kHz |
| 弦乐 | — | presence 1–4 kHz | mud 200–500、air 10 kHz+ |

## 4. 声部写作原则

1. **音区分离**：同时并行的声部，**相邻声部至少间隔一个八度**。
   低音、和声、旋律各占一个八度带。
2. **反向进行**：低音下行时上方声部上行，避免全同向导致"塌陷"。
3. **声部数量**：和声不超过 4 声部；**pad 超过 5 音易浑浊，2–3 音更通透**。
4. **低频单声道化**：**120 Hz 以下保持 mono**，立体声展宽只在 120 Hz 以上做。
5. **避免低音区平行五度/八度**堆叠（会导致低音空洞）。
6. **声部间距**：低音区可大（>八度），高音区收窄（<五度），符合泛音分布。

## 5. 快速自检

写完编曲，逐条过一遍：

- [ ] 相邻段落能量值不同吗？
- [ ] 每 8/16 小节都有明确变化吗？
- [ ] 有没有两件乐器抢同一频段？
- [ ] 满编时长占比是否超过 40%？
- [ ] 低频是否只有 kick 与 bass 在占（其他都做了 HPF）？
- [ ] 副歌的"大"是来自于**加层**还是来自于**前面减层**的对比？
- [ ] 120 Hz 以下是 mono 吗？
