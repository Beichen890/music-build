> 本文件由 B 站公开搜索结果整理（采集时间：2026-11-10 21:20:51，共 973 条去重视频），按主题与播放量排序。链接为 `https://www.bilibili.com/video/<BV号>`，
> **制作口径**：默认在 DAW 里作曲编曲（MIDI + 采样音源 + 合成器 + 自动化 + 混音）；真实乐器、采样、合成器音色都是合法音色来源，不做「原声 vs 电子」的出身审查。
> **范围分流**：不默认做吵闹的电子舞曲风格（EDM / House / Techno / Trap / Dubstep / 鼓机 drop / riser / 侧链泵感 / supersaw lead），这类内容单独收在 `references/electronic-styles.md`，主线不混。
> **主用途**：情绪驱动 + 场景感双轴 + 钢琴 / 小提琴 / 手风琴三件套；合成器在这里是色彩与空间层（pad / bell / soft lead / 铺底），不是舞曲骨架。
> 播放量为采集时快照，仅作筛选参考，**不等于教学质量**。带「合集」的是系列课，通常第一 P 免费。

## 怎么用

1. 先按当前任务找主题 → 2. 挑 1–2 个系统课补框架，1 个拆解课看手法 → 3. 把视频里的谱例/和弦抄进 `chord-library.md` 或 `theory-cheatsheet.md` 复用。
4. 技能内其它文件的规则与本文件的视频观点冲突时，以技能内规则为准（视频是素材，不是裁判）。

## 采集口径与已知偏差

- 来源：B 站公开搜索接口，关键词覆盖配器、乐理、和弦、音源、编曲思维等约 80 组，对每个关键词取综合排序第一页，再去重、过滤。
- 偏差 1：搜索排序偏向播放量高的老视频与长合集，**新出的优质小众内容会漏**。
- 偏差 2：标题党与软件教程会混入，已用关键词规则过滤但不保证 100%。
- 偏差 3：BV 号指向合集第一 P，课程内容要看分 P 列表。
- 需要重新采集时，运行工作区里的 `bili_search.py` / `bili_search_more.py`。
