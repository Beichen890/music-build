# 纯音乐制作：没有歌词时，歌由什么扛着

> 定位：**人声退场后，原先被歌词兼任的工作必须重新分配。**
> 本文件讲纯音乐（器乐）独有的制作决策：谁当"主唱"、段落怎么标记、
> 曲风要点、混音母带差异、交付物。
> 情绪层面的选择先看 `emotional-expression.md`，本文件管工程与执行。

## 1. 歌词退场后，五根柱子接管

有歌词的歌，歌词兼任了：叙事、报幕（段落标记）、记忆点、情绪直给。
纯音乐必须把这四件事分给五根柱子：

| 柱子 | 接管歌词的哪部分 | 关键动作 |
|---|---|---|
| **旋律/动机** | 记忆点、主唱 | 一句能哼出来的主题，反复变形出现 |
| **和声进行** | 情绪底色 | 和声自己会讲故事（见情感篇 §4） |
| **节奏律动** | 推进感、身体参与 | 没有歌词时 groove 是注意力的主锚 |
| **音色与织体** | 叙事、氛围、章节感 | **音色变化 = 纯音乐的"换段报幕"** |
| **结构** | 报幕、起承转合 | 段落职能靠配器进出标记（见 §3） |

**核心认知：纯音乐里"音色"的重要性被提到最高。** 人声在，听众注意人声；
人声不在，听众盯的是** textures 的变化**——加一层 pad、换一个 lead 音色，
就是"新的一段开始了"。

## 2. 从情绪卡到第一版草稿：工作流

```
① 填情绪卡（emotional-expression.md §1）——一句话情绪 + 三段弧线 + 参照锚点
② 写最小动机：4 小节以内，能哼出来；先想旋律或先想 groove 都行
③ 8 小节 loop 试情绪：情绪对了再往下；不对就换调式/速度/音色，别硬写
④ 标结构图：在工程里按时间轴标好段落名 + 每段的"进入事件"
⑤ 铺动机的第一次陈述（solo 音色，薄织体）
⑥ 按结构图做展开与变形（§3 的十种手法）
⑦ 混音只做一件事：确认主旋律在手机喇叭上听得见（§5）
⑧ 导出 stems 备用；成品导出一版"干净版"给 sync/授权用途
```

**纪律：③的情绪测试不能跳。** 纯音乐没有歌词兜底，情绪在 loop 阶段就不成立，
写到 3 分钟也只是更长的失败。

## 3. 动机与展开：一个 idea 的十种死法…活法

纯音乐时长越久，**展开能力越决定成败**。重复是记忆的朋友，也是无聊的根源。
以下手法可组合使用：

| # | 手法 | 说明 | 例 |
|---|---|---|---|
| 1 | 改尾音 | 同一动机，结尾落音改 1–2 个 | 疑问句→陈述句 |
| 2 | 变节奏 | 音高不变，节奏拉伸/压缩/附点化 | 同一轮廓，步态从走到跑 |
| 3 | 换音区/八度 | 移高八度=尖锐兴奋；移低=沉重 | 再现部常用 |
| 4 | 换乐器 | 钢琴主题交给弦乐/口琴/合成器 pad | 等于换一个角色复述；合成器是合法音色来源 |
| 5 | 加/减音 | 三音动机扩成五音、七音 | 密度升级 |
| 6 | 倒影/逆行 | 轮廓镜像或反向 | 对抗、阴霾段落 |
| 7 | 改和声 | 同一旋律配完全不同的和弦走向 | 小调主题配大调终止=救赎感 |
| 8 | 截断/裁片 | 只取动机的前 2 音反复，制造执念 | 悬疑、偏执 |
| 9 | 加速/减速 | 时值按比例缩放（augmentation/diminution） | 从漫步到狂奔 |
| 10 | 叠加自身 | 原动机 + 高八度/低八度/卡农式延迟进入 | 瞬间变"满" |

**练习（每周一次，一小时）：一动机十变奏。** 一个 2 小节动机，列出 10 个版本，
每个版本换至少两样（乐器/音区/奏法/节奏/和声）。这是从"会写 loop"到"会写曲子"
的分水岭。

**判断标准**：变形后的版本，第一遍听仍能认出"是同一个东西"——认不出是乱写，
完全一样是没写。

## 4. 没有歌词的结构标记法

人声歌用"进唱"标记段落；纯音乐必须用**配器进出 + 织体突变**标记。
每次段落转换必须有一个**可听见的事件**，事件库：

```
新音色首次进入（一个全曲没出现过的音色）
全奏 hit（所有声部同发一个重音）
全停（silence 1–2 小节）
调性转移（尤其同主音大小调互换）
鼓组进出（加鼓/抽鼓是最强的段落信号）
低音运动模式改变（持续音→走动）
音区跳变（整体上移/下移一个八度）
```

### 4.1 常用纯音乐结构

| 结构 | 形态 | 适用 |
|---|---|---|
| **A-B-A** | 主题 – 对比段 – 主题回归 | 最短小可靠的器乐形式 |
| **Intro–Development–Return** | 引入 – 多层展开 – 主题满载回归 | 电影 cue、后摇滚 |
| **Theme & Variation** | 主题 + N 个变奏，速度/配器递进 | 古典传统、极简 |
| **Loop-based** | 4/8 小节 loop，靠音色分层进出 | 游戏 / 影视循环配乐（电子舞曲循环见 `electronic-styles.md`） |
| **Through-composed** | 无明显重复，持续发展 | ambient、长篇电影段落 |
| **Rondo** | A–B–A–C–A | 主题反复回归，中间插对比 |

### 4.2 长度参考

| 场景 | 时长 | 说明 |
|---|---|---|
| 单曲/流媒体 | 2:30–4:30 | 前 30 秒必须出现主题或核心 loop |
| 游戏循环 BGM | 1:30–3:00 | 设计无缝 loop 点；首尾接缝要藏 |
| 影视 cue | 按画面 | 先对 hit point（画面切换/台词点），再写 |
| 专辑 intro/outro | 0:30–1:30 | 气氛为主，可以无主题 |
| Ambient 长篇 | 8 分钟+ | 无段落也行，但必须有微事件防止睡着 |

**流媒体硬规则：前 15–30 秒决定完播率**——纯音乐没有"等副歌"的惯例，
主题/核心音色必须在开头 30 秒内至少出现一次（哪怕是预告式的片段）。

## 5. 纯音乐混音专项

混音的通用规则看 `mixing.md`，这里只讲**纯音乐特有的坑**：

1. **没有主唱锚定频谱**。人声在时，2–5 kHz 天然是"主角频段"；人声不在，
   这段容易被 pad/lead/军鼓抢成一锅。**明确指定一件乐器做"临时主唱"**，
   给它 2–5 kHz 的优先权，其他乐器在这段让位。
2. **motif 手机测试**：纯音乐的记忆点在 small speaker 上丢 = 白做。
   中频（500 Hz–4 kHz）不干净的纯音乐，手机上就是一团糊。做完必测。
3. **饱和代替 EQ**：给 lead 上轻饱和/激励，让它在流媒体低码率下还能"穿墙"——
   纯音乐没有歌词帮忙抓耳，这一步更重要。
4. **sidechain 混音的克制使用**：ambient pad 用 sidechain 轻轻躲 lead
   （ducking 2–3 dB），lead 存在感立刻上升，织体不丢。轻闪避主线也可用；
   泵感式侧链（release 跟 1/8 或 1/16 走）见 `electronic-styles.md` §3。
5. **混响自动化 = 情绪杠杆**：同一动机，verse 近（短混响低 send）、
   bridge 远（长混响高 send）——"距离变化"是纯音乐最便宜的叙事手段。
6. **空间分工**：不同音色放不同"房间"（短房间=私语，长厅=旷野），
   纯音乐没有词分散注意力，空间层次会被听得很清楚——要做好。
7. **低频纪律照旧**：120 Hz 以下 mono；没有 kick 的 ambient 曲子，
   检查 sub 与 bass 是否在互相掩蔽。

## 6. 纯音乐母带专项

1. **动态是内容的一部分**：crescendo 是情绪手段（见情感篇 §5），
   母带压太死 = 把作品的弧线压平。**纯音乐母带的目标是"听得见渐强"**，
   响度战争那套不适用；LUFS 达标即可，别追响。
2. **平台目标**（与 `mastering.md` 一致）：流媒体约 −14 LUFS 集成响度，
   true peak ≤ −1 dBTP；检查"渐强段落"在平台音量归一化后还能不能听出来。
3. **中频空洞检查**：没有 vokes 的曲子在 300 Hz–1 kHz 容易发空，
   用频谱分析确认这段有内容在（通常是和声层/节奏乐器）。
4. **响度对齐 A/B**：和参考曲比时先做 LUFS 对齐，再判断频段与动态。

## 7. 分曲风制作要点

### 7.1 独奏钢琴（Solo Piano）

- **弱点**：单乐器，容易平。**解法全在奏法与踏板**：rubato 速度、
  non-legato 断句、延音踏板制造的和声叠合、力度对比（pp 到 ff）。
- 录音/采样：一个房间 mic 位置 = 一半音色；mid-side 或 spaced pair
  比单点拾音更有"体温"。
- 结构：A-B-A 加一个再现部的变奏收尾（见情感篇 §5.4）。
- 混音：HPF 可以很轻（钢琴有 legitimate 的低音）；主要修 200–500 Hz 的 mud。

### 7.2 Ambient / Drone / 冥想向

- 创作即"删减"：每加一层，先问能不能删掉别的东西。
- 无 kick 时用 sub sine 做 30–120 秒一次的缓慢起伏代替"心跳"。
- 长混响（3–5 s RT60）+ 反馈延迟；**滤波自动化（filter LFO）让静止的也呼吸**。
- 事件设计：每 30–60 秒一个"微事件"（一个 bell、一阵噪音 swell、一次调性微移），
  防止听众走神——但事件本身要轻。
- 母带最松，动态保留最多；响度可以低（−16 到 −20 LUFS 都成立）。

### 7.3 后摇滚 / Post-rock

- 套路（有效但要用出新意）：clean  guitar arpeggio 起 → 加 bass → 加鼓 →
  失真吉他墙 → 骤停 → 独奏复现 → 全奏高潮 → 衰减。
- **crescendo 是灵魂**：每 8 小节加一层，加四轮，第五轮全奏。
- 吉他墙：节奏吉他双轨录+分别硬左硬右；加 lo-fi 滤波防刺。
- 警惕：这个风格同质化严重，差异化靠**一个独有的音色或节奏花样**
  （如一个五拍的敲击pattern），不靠更大声。

### 7.4 Cinematic / Hybrid Orchestral

- 最小 viable idea 起步：一个音程、一个 pulse、一个 drone——
  围绕它的升级变形设计整部结构（Zimmer 方法）。
- 合成器 pad 垫在弦乐 / 铜管下面补 200–500 Hz 厚度，音量比弦乐低 6–10 dB，让音色边界模糊；这是主线的合法用法，不是舞曲骨架。
- ostinato 引擎：八分音符的弦乐 pulse 或 ticking percussion 制造"不可避免"。
- 动态范围是资产：ppp 到 fff 都用上；高潮前减层纪律见情感篇 §4.5。
- 音源选择看 `sample-instrument-swap.md`（换音源与 A/B）。

### 7.5 Lo-fi / Chillhop

- 核心不是"做得烂"而是"做得旧"：磁带饱和、黑胶噪音、降采样（12-bit 风味）、
  roll-off 的高频（<10–12 kHz）。
- 鼓：swing 化（hat 微晚、snare 微晚）+ 音量 Automation 让鼓"呼吸"；
  底鼓不必很强，lo-fi 的 kick 常是软的。
- 和声： maj7 / m7 / 9 和弦为主，速度 70–90。
- 旋律：电钢/Rhodes 或 bell 类音色；句与句之间留噪音"喘息"。
- 时长 2–3 分钟，loop 结构；**首尾要做成能接起来**。

### 7.6 电子舞曲纯音乐（内容已迁出）

本节原为「EDM Instrumental」：drop 记忆点由 lead 音色承担、鼓组当主唱、音色设计优先于旋律、mono 兼容性检查、loop 结构。
**完整内容见 `electronic-styles.md` §2**，主线不展开。
用户主用途（情绪驱动 + 场景感 + 三件套）不适用这套骨架；合成器作为色彩层在主线里仍正常使用。

### 7.7 Jazz / Fusion 纯器乐

- 即兴段 = 人声的"副歌"：solo 的结构也要设计（起-承-转-合），
  不能一吹到底；给伴奏组留呼应。
- comping（钢琴/吉他的即兴伴奏）在纯音乐里承担"第二叙事"，
  别弹满，给独奏留气口。
- 鼓的 dynamic 是情绪主控：brush → stick → 开放踩镲，三段递进。
- 混音：爵士客厅感——克制混响、中频优先、保留"现场空气"。

## 8. 交付物清单

| 交付物 | 规格 | 给谁 |
|---|---|---|
| 成品母带 | 44.1/16 bit WAV（+ 平台要求的格式） | 发行 |
| Clean version | 无特殊音效/无人声哼鸣的纯演奏版 | sync 授权、广告备用 |
| Stems 分轨 | 按乐器组导出（drums/bass/keys/lead/strings/fx） | 混音师、导演、后续加人声 |
| 30 秒剪辑版 | 主题浓缩、独立成立 | 短视频、preview |
| Loop 版（游戏/直播） | 无缝循环 + 尾版 | 游戏/直播平台 |

**Stems 规范**：从第一拍开始整曲长度导出（不要 trim），统一 24 bit/48 kHz，
命名 `曲名_STEM_乐器组.wav`；导出前确认总线处理已烘进各 stem。

## 9. 训练练习（每周挑一个）

1. **一动机十变奏**（§3）：一小时，2 小节动机 → 10 个版本。
2. **30 秒 hook**：一个动机 + 一次变化，导出当铃声。朋友问"这什么歌"= 成功。
3. **电影片段配乐**：找一段无对白的 90 秒画面，对着 hit point 写。
   练"音乐服务画面"的专注力。
4. **Loop and Layer**：4 小节 loop，每 30 秒只加一层，记录每层加什么、
   为什么情绪往哪走——把"加层决策"变成 conscious 的手艺。
5. **音色日记**：每周用一个新音色写同一段 8 小节主题，
   记录每个音色把情绪带向了哪里——攒自己的音色情绪词典。
6. **情绪覆写**：把一首自己满意的曲子，只改 tempo 和 mode，
   做四个情绪版本（快小调/慢小调/快大调/慢大调），
   亲耳听 §2.1 那两个轴有多大力气。

## 10. 自检清单（纯音乐版）

- [ ] 情绪卡填了吗？loop 阶段情绪就成立吗？
- [ ] 前 30 秒内，主题或核心音色出现了吗？
- [ ] 有一个明确的"临时主唱"乐器吗？它在手机喇叭上听得见吗？
- [ ] 每次段落转换都有可听见的事件吗？
- [ ] 每 8/16 小节都有明确变化吗？连续 16 小节唤醒值不变过吗？
- [ ] 高潮只出现一次吗？高潮前减层了吗？
- [ ] 全曲有 chills 点吗？有设计过的结尾吗（不是 fade 了事）？
- [ ] 120 Hz 以下 mono 吗？mono 播放（单声道）塌不塌？
- [ ] stems 导出了吗？命名和起点统一吗？
- [ ] 小音量、耳机、手机喇叭、车喇叭，四个场景都过了吗？

## 11. 常见错误

1. **把"加层"当"发展"**——层数在涨，动机原地踏步。发展是变形不是堆料。
2. **音色慈善**——舍不得删音色，怕空。**空是纯音乐的呼吸，不是缺陷。**
3. **段落无信号**——听起来"就是那么往下走了"，没有进入事件，
   听众失去地图（用 §4 的事件库修）。
4. **节奏缺位**——纯音乐没有歌词，很多人连 pulse 也不给，
   结果不是 ambient 是"没写完"。想要 pulse 就明确给。
5. **高潮通胀**——三个"最大"段落并列，等于没有最大。
6. **默认 fade out**——把"没决定怎么结尾"转嫁给衰减。
7. **手机失联**——细节全在中高频，手机上只剩轰鸣。混音阶段就测。
8. **忽视 mono 兼容**——wide 音色在单声道系统里互相抵消，能量凭空消失。
